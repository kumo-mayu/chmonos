# 公開の準備への申し送り（2026-10-07）

BOOTH での公開を担当するセッションが、作業の前に知っておくとよいこと。2026-10-07 までの点検・実機の確かめ・判断から拾った。
決め事そのものは `CLAUDE.md` と `docs/spec/`。ここは「公開の作業で踏みやすい所」と「まだ決めていない所」の一覧。

## 1. 配る物の形

- **配布の形は実行ファイル1つ**（`Chmonos.App/Properties/PublishProfiles/win-x64.pubxml`：`SelfContained`・`PublishSingleFile`・`IncludeNativeLibrariesForSelfExtract`・`PublishReadyToRun`）。
  組み方は `dotnet publish Chmonos.App -p:PublishProfile=win-x64 -o <出し先>`。出し先には `Chmonos.exe`・`LICENSE`・`NOTICE`・`THIRD-PARTY-NOTICES.txt`・`assets\`（同梱の辞書とカテゴリ表）が並ぶ。
- `publish\Chmonos-win-x64.zip` は **2026-09-28 の古い版**（無視されているフォルダ）。配るときは組み直す。
- **DLL を分けた形（`dotnet publish` の既定）は配らない**。スマート アプリ コントロールの入った PC で `Chmonos.Core.dll` が止められ、**窓もログも出ずに落ちる**（起動の失敗の窓より前で落ちるため）。
- 起動すると、実行ファイル1つの形は、中身の一部を `%TEMP%\.net\Chmonos` に展開する（.NET の仕組み）。消しても、次の起動で作り直される。

## 2. コード署名（保留中・判断が要る）

**署名の無い実行ファイルは、スマート アプリ コントロールに止められることがある。**同じ配布の形でも、組み直すたびに評判で判定され、2026-10-07 の別の PC では、1回目の版は通り、組み直した版は止められた（`docs/feedback/manual-check-2026-10-07.md`）。
SmartScreen の「発行元不明」の警告も出る。ユーザ判断は「配布の形で動くなら、いったん保留」。公開の前にもう一度決める必要がある。

| やり方 | 費用（2026年の調べ） | 日本の個人で使えるか |
|---|---|---|
| SignPath Foundation | 無料（オープンソース向け） | 使える見込み。条件はリポジトリの公開と、CI（GitHub Actions など）で中身から組むこと。Apache-2.0 なので条件に合う見込み |
| Certum のオープンソース向け | $49.99〜 | 使える |
| OV 証明書（Sectigo など） | 年 $219〜（DigiCert は年 $400）。鍵は専用の機器かクラウドの保管が必須（2023年6月から） | 使える |
| Azure Artifact Signing（旧 Trusted Signing） | 月 $9.99 | **使えない**（個人は米国・カナダだけ。個人の受付も2026年3月から止まっている） |

署名しても、評判が貯まるまで SmartScreen の警告は出ることがある（OV の場合）。

## 3. 使う人のデータの置き場（公開の説明に書く）

`docs/feedback/open.md`「記録のみ」の「公開の説明に、データの置き場と消し方を書く」（ユーザ判断 2026-10-07）：

- 設定とデータの既定の置き場は `%LOCALAPPDATA%\Chmonos`（使う人ごと・管理者の権限が要らない・OneDrive の同期の外）
- **インストーラが無いので、実行ファイルを消してもデータは残る。**消すときはこのフォルダも消す、と書く
- C ドライブが小さいときは、初めて起動したときの窓で保存先を選び直せる。後からは設定の「データ」の「場所を変える」
- 今の `README.md` は開発者向け（ビルドとテスト）。使う人向けの説明は別に要る

## 4. 実機で確かめた動き（説明やよくある質問に使える）

2026-10-07 に実機で確かめた（`docs/feedback/manual-check-2026-10-07.md`）：

- 強制終了・電源断：書き出し・引越し・戻すの途中で止めても、データは無事（写しかけは印で見分け、次に選んだときに片付けを聞く）
- USB メモリ（FAT32）の保存先：ふつうに動く。使っている最中に抜いても落ちない。つなぎ直せば戻る
- スリープからの復帰：問題なし（長く眠ったときと、BOOTH への問い合わせの途中で眠ったときは未確認）
- OneDrive の「オンラインのみ」・Googleドライブの保存先：動く。同期のアプリが止まっているときは「同期のアプリが動いているか、ネットにつながっているかを確かめてください」と出る。バックアップの書き出しは全部を読むので、オンラインのみのファイルを全部ダウンロードする
- Unity Hub・VCC・ALCOM の入っていない PC：入っていないと正しく見分け、開く前に止まる
- 2万件の商品：固まり（250ms 超）は無い。**メモリは予算を超える**（起動後 419MB・最大 652MB。ユーザ判断「記録のみ」。`docs/research/memory-budget.md`）

## 5. 変えてはいけない決まり（公開の作業で触りそうな所）

- **BOOTH への問い合わせは1本ずつ・1.5秒以上空ける**（`CLAUDE.md` の1。`BoothClient` のゲート1か所・PC で1つの門 `BoothMachineGate`）。README と `NOTICE` にも、フォークするときに残してほしいと書いてある
- 名前と非公式の表記：pixiv の登録商標のガイドラインに沿って、「非公式」「ピクシブ株式会社が作成・配布しているものではない」を README・初めの窓・設定の「このアプリについて」に出している（`docs/research/booth-terms.md` §3）。BOOTH のページの説明にも同じ旨を書く
- ライセンス：コード Apache-2.0・文書 CC BY 4.0。同梱の辞書（JMdict・KANJIDIC2）は CC BY-SA 4.0 で、出典の表示が要る（設定の「このアプリについて」に出している）。第三者のライブラリの許諾文は `THIRD-PARTY-NOTICES.txt` を配る物に添え、設定の「ライセンスを開く」から開ける

## 6. 配ってはいけない物

- 購入した実アセット：`DLforTest/`・`VRChat_Avatar/`・リポジトリの直下の zip と画像（無視されている）
- 友人のデータの写し（`%LOCALAPPDATA%\Chmonos-sandboxes\` の `friendtest`・`eval`・`tester` など）と、その名前・ファイル名・商品ID。BOOTH の説明の例や画面の撮影に使わない（撮るなら作り物の写し：`ui`・`small` の台本など）
- 本番の保存先（`%LOCALAPPDATA%\Chmonos`）。`location.json` は友人の写しを指している

## 7. 点検の状況

- 外部の点検（Codex）は2026-10-07 の21回目で止めた。直すのは「ふつうに使って当たる物」と「条件が重なると当たる×大」だけ、ほかは記録のみ（ユーザ判断）。記録のみの物は `docs/feedback/open.md`
- 次の確かめのおすすめは、友人に実際に使ってもらうこと
- 公開の直前に、配る形で組んだ実行ファイルを、スマート アプリ コントロールの入った別の PC で起動して確かめるとよい（LAN の別の PC を確かめに使える。つなぎ方は作業の記憶にある。報告と文書に、その PC のユーザ名・PC の名前・IP を書かない）

## 8. 古いデータの直し（公開とは別）

`tools/NullPriceFix`：前の版で額が空欄のまま保存された購入記録を0円に直す道具。友人のデータのために作った。2026-10-07 に今の作りでも動くことを確かめた。
アプリを閉じてから走らせる（開いていると止まる）。`--apply` で書き換え、書き換える前の控えを保存先の中に作る。公開前なので、古い形のデータに合わせる変更はアプリには入れない（`CLAUDE.md`「公開前は、古い形のデータに合わせる変更をしない」）。
