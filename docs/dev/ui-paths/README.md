# 画面ごとの操作の経路（2026-11-15・案）

配る前に画面の配置を決め直すための文書（plan 17）。画面ごとに「使う人が何をしたい時に、どこを、どの順に操作するか」を目的の単位で並べた。
手順は画面に出ている文言と場所で書き、AutomationId とファイルの行は各ファイルの後ろの「部品の一覧」にだけ書く。

- コードを読んで書いた物で、画面では確かめていない（[推測] の印が付いた所は特に）。手数はクリック・キー・打つ（1語）・ドラッグをそれぞれ1と数えた
- **頻度の列はユーザが付ける**（毎回／時々／まれ）。目的の言い方・足りない目的もユーザが直す
- 各ファイルの節：目的の表 → 画面の間の行き来（mermaid）→ 見るだけの部品 → 部品の一覧 → 気付いた事
- カード・リスト・右クリック・選択の帯は、検索・ショップ・フォルダなどで同じ部品。中身は [search.md](search.md) の「部品の一覧」
