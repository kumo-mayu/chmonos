# ショップの一覧：目的ごとの操作の経路（2026-11-15・案）

左のナビの「ショップ」で開く。ほかの画面からここへ来るボタンは無く、ショップの画面の左上の戻る（「← ショップに戻る」[推測：文言は前の画面の名前から作る]）か Alt+← で戻って来る。
コードを読んで書いた物で、画面で確かめていない。手数はクリック・キー・打つ（1語）・ドラッグをそれぞれ1。右クリックのメニューの子（▸）を開くのも1。
**頻度の列はユーザが付ける**（毎回／時々／まれ）。

場所：上の帯＝画面の一番上の「ショップ」「n ショップ」と説明の文がある行（右に「★ だけ」・探す欄・「対象：… ▾」・「表示順」・「読み直す」。狭い窓では右の塊が次の段へ折り返す）／取得の帯＝上の帯のすぐ下の水色の帯（アイコンを取っている間だけ）／一覧＝ショップのカードの並び／カード＝1つのショップの四角／星＝カードの右上の☆・★／右クリック＝カードの右クリックのメニュー

## 気付いた事

- 同じ事に経路が2つ以上：ショップを開く（カードを押す・右クリック「ショップを開く」）。星（カードの右上・右クリック・ショップの画面の名前の前）。BOOTH のショップのページ（ここは右クリックだけ・ショップの画面は上の帯のボタン）。
- 隠れて見つけにくい物：BOOTH のショップのページはこの画面では右クリックの中だけ。探す欄の書き方（-・""・OR）は乗せた時の吹き出しだけ。星は Tab で止まらず、キーボードでは Shift+F10 のメニューから。札「更新のあった商品が n 件」は押せそうに見えるが、カードを押したのと同じでショップの画面の先頭に出るだけ（絞りは向こうで掛け直す）。
- 手数が多い目的：メモで探す（A2）は「対象」のメニューを開いてチェックを切り替えて閉じるまで4〜5手。更新のあった商品へ（A17）は、こちらで「更新があるものだけ」に絞っても、ショップの画面ではもう一度「更新があるものだけ」を押す。絞りを全部やめる1つのボタンが無い。
- 文言の揺れ：同じお金が、カードと表示順では「支出」、ショップの画面では「購入総額」。星は「★ だけ」「星を付けたショップ」「お気に入りのショップ」の3通り。BOOTH を開く項目は、ここでは「BOOTHのショップページを開く」、検索の区切りの札の右クリックでは「BOOTHで開く」。0件の時の文は「「★だけ」」とスペース無しで、チェックの文言「★ だけ」と少し違う。
- 0件の時、絞って0件でも「「取り込み」で商品を読み込むと、ショップごとにまとまります。」がいつも下に付く。
- 「BOOTHのショップページを開く」が押せない時、吹き出しは押せる時と同じ文で、押せない理由を言わない。
