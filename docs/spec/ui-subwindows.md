# サブ画面の決め事（今の決め事）

> **要点**：サブ画面は、主の窓を塞がずに横で使う別の窓。主の画面（差し替えで開くのは常に1つ）とは別の枠で、**1種類につき開くのは1つ**。
> 主の窓を閉じる・畳むと一緒に閉じる・畳まれる。Esc と「閉じる」で閉じる。開いている間に記録が変わったら読み直す。
>
> **コード**：`App/Views/FilePoolWindow.xaml(.cs)`・`App/ViewModels/FilePoolViewModel.cs`・`MainViewModel.FilePool.cs`・`Core/Storage/ItemRepository.Written`
>
> **経緯**：plan 30（ユーザ案・判断 2026-11-11「最初からサブ画面で作って良いと思う」）。このアプリで初めてのサブ画面。今あるのはファイルの割り振り（[file-pool.md](file-pool.md)）だけ。

## 主の画面・小窓との関係

- **主の画面は今までどおり差し替え**（[ui-rules.md](ui-rules.md)「開くのは常に1つ」・戻るは画面の履歴）。サブ画面は主の画面の履歴に積まない。
  サブ画面から主の画面を動かすとき（商品を押すと商品ページを開く）は、人が主の窓で開くのと同じ道（`MainViewModel.ShowItem`。離れる画面の書きかけを控え、履歴に積む）を通る。
- **小窓（ダイアログ）は主の窓を止めて聞く**（`ShowDialog`・[ui-dialogs.md](ui-dialogs.md)）。サブ画面は止めない（`Show`）。サブ画面から出す確認の窓は、そのサブ画面が持ち主になる（`Notice` は手前の窓を持ち主にする）。

## 何をサブ画面にするか

- 主の画面と**見比べながら・行き来しながら**続ける作業だけ（ファイルの割り振りは、選んだ商品のページを主の窓で開いて中身を見ながら付け外しする）。
- 1回答えれば済む問い・選ぶだけの物は小窓。1つの物を開いて読む・直すだけの物は主の画面。迷ったら主の画面にする（窓が増えると、どこに何があるかを人が覚えることになる）。

## 開く・閉じる

- **1種類につき1つ**。開いていてもう一度開く操作をしたら、新しく作らずに今の窓を前に出す（畳んでいれば戻す）。
  開くときの中身（選んだ商品）が前と違えば、同じ窓のまま中身を入れ替える。同じなら入れ替えない（付ける先・チェック・開いた組を残す）。主の窓が1つだけ控える（`MainViewModel.FilePool`）。
- 持ち主は主の窓：主の窓の手前に出て、主の窓を畳むと一緒に畳まれる。タスクバーには出さない。
- **主の窓が閉じる・隠れるときは、主の側から明示して閉じる**（`App.OnMainWindowClosing` → `MainViewModel.CloseSubWindows`）。持ち主に任せると、画面を出さない起動から開いた窓は閉じても隠すだけ（[headless.md](headless.md)）なのでサブ画面が残り、保存先を運んだ後の開き直しでは古い保存先のまま残り得る。書きかけを聞いて「キャンセル」したときは閉じない。
- 閉じるのは右下の「閉じる」・Esc・×。閉じたら置き場の知らせを外す（置き場はアプリの間生きている）。
- 大きさは変えられる（最小 680×420）。位置と大きさはアプリを閉じるまで覚え、`ui-state.json` には書かない（形を変えない）。最初は主の窓の中央に 940×640（表示の大きさを掛ける）。
- 中の左右の比率は境目（`PaneSplitter`。主の画面の境目と同じ部品）のドラッグで変え、ダブルクリックで元に戻す。比率（＊の比）も位置と同じくアプリを閉じるまで覚え、`ui-state.json` には書かない（主の画面の `paneWidths` とは別）。
- フォーカス：サブ画面で商品を押しても、フォーカスはサブ画面に残す（主の窓を前に出すと、続けて割り振れない）。

## 開いている間

- **記録が変わったら読み直す**：ほかの画面・取り込み・API が選んだ商品を書いた・消したら、置き場の知らせ（`ItemRepository.Written`。錠の中から鳴る）を画面のスレッドへ回し、手が空いたときに1回だけ読み直す。チェック・開いた組・付ける先は残す。
- **自分で書いたら主の窓へ知らせる**：検索の写しとカード・開いている商品ページ・ナビの数（`MainViewModel.NoteItemsChangedBySubWindow`。API が書いたときと同じ道）。
- 選んだ商品が消えたら一覧から外し、一覧の上に「削除された商品 n 件を一覧から外しました。」と出す。付ける先だった物なら、付ける先も外す。
- 表示の色・大きさは、開いたままでも変えた物に追う（中身の倍率は資源を指す。題の帯は色を変えたときにアプリの窓すべてへ当て直す）。窓の大きさは開いたときの倍率のまま。

## キー

- Esc で閉じる（「閉じる」に `IsCancel`）。Enter で決まるボタンは置かない（付ける・外すは押して選ぶ操作で、打ち終えた Enter で走らせない）。
- 表示の大きさのキー（Ctrl＋プラスなど）・戻る（Alt+←）は主の窓の物で、サブ画面では受けない。
- 押せる行は Tab で止まり、Enter・Space で押したのと同じ（`PressableBorder`）。
