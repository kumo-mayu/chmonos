# 窓（ダイアログ）と知らせの決まり

画面の中の決まりは [ui-rules.md](ui-rules.md)。ここは**別の窓で聞く・言う**ときの決まり
（ユーザ判断 2026-09-20。洗い出しの D1〜D11・`docs/feedback/ui-consistency-2026-09-20.md`）。

## キー

- **Esc でどの窓も閉じられる**（D1）。やめる側のボタンに `IsCancel="True"` を付ける。
  ボタンを置かない窓（初回の窓）は code-behind で Esc を受け、×と同じに閉じる。
- **Enter で決められる**（D2）。主のボタンに `IsDefault="True"` を付ける。
  入れる物が足りない窓は、そのボタンの `IsEnabled` を条件に結ぶ（空欄の Enter は何も起こさない）。
- 例外は**意図を聞く三択**（`ChoiceDialog`）。どちらの意図か分からないから聞いているので、Enter で片方に倒さない。
- 候補付きの入力欄（`SuggestBox`）は、**候補の一覧が開いているときだけ** Enter と Esc を受ける。
  閉じているときまで食べると、打ち終えた後の Enter で窓が決まらず、Esc でも窓が閉じられない。

## ボタン

- やめる側の名前は**「キャンセル」**で揃え、**右端**に置く（D3）。主のボタンはその左。
  `MessageBox` が同じ並び（OK が左・キャンセルが右）なので、窓の種類で並びが変わらない。
- 押すと何が起きるかが分かる名前にする（[ui-writing.md](ui-writing.md)）。
- **中止の範囲を名前に入れる**（D11）。1件ずつ順に聞く窓では「この商品を飛ばす」（1件）と
  「残りすべてを中止」（残り全部）を並べる。「やめる」だけでは、1件なのか全部なのか読めない。
- 本文でボタンごとに説明するときは、ボタンの名前を「」で1行に書き、説明はその下の行に書く。選択肢の間は1行空ける
  （「……」「：」でつないで1行にしない。ユーザ判断 2026-09-24・[ui-terms.md](ui-terms.md)）。

## 取り返しがつくか

- 商品やデータを書き換える窓は、**押す前に取り返しがつくかを必ず1行で書く**（D4）。
  戻せるなら「同じ手順で戻せます」と書く。書かないと、戻せないものと見分けが付かない。
- 窓の本文は、1行目に何が起きるか、2行目に取り返しがつくか。理由や経緯は書かない（[ui-writing.md](ui-writing.md)「何を載せるか」）。
- 統合は戻せない（どちらに付いていたかを残していないので分け直せない）。
  名前の変更は戻せる。同じ窓でも、選んだ内容で答えが変わるなら文もそれに合わせる。

## 何回聞くか

- **戻せない操作だけ、窓の後にもう一度聞く**（D5）。統合（分類・属性）がこれにあたる。
  1つになった後は、どちらに付いていたかで分け直せない。
- 名前の変更・移動のように**同じ手順で戻せる**ものは、影響を示す窓の1回だけで済ませる。
  戻せるものまで2回聞くと、聞かれること自体が読み飛ばされる。

## どこに言うか

- **うまくいったことは、行のある画面ならその画面の1行**に表示する（D6）。
- **できなかったことは必ず窓**で知らせる。行に書いた失敗は、次の操作で押し出されて消え、何が起きたか追えない。
  窓を開くときは、途中の表示（「調べています…」）を消してから開く。
- 行を持たない所（カードの右クリック）は、うまくいったことも窓で知らせる。ただし戻せる操作（非表示にする）は、窓の代わりに下の帯に戻し方と解除を表示する（`MainViewModel.HiddenNotice`）。
- **見れば分かることは言わない**（D7）。Unity の取り込み画面が開く・画像が消える・フォルダが一覧に並ぶ、はそれ自体が結果。
- 呼ばれた側は `NoticeSink` に返し、**表示先は呼んだ画面が決める**（`Notices.LineOrWindow`）。

## 知らせのアイコン

- **人が押した操作の確認は Question**（D9）。消す・統合するでアイコンが割れないようにする。
  取り返しのつかない操作は、アイコンではなく**既定のボタンをキャンセル側に倒して**止める。
- **できなかったことは Warning**（D8）。うまくいかなかったこと・壊れている状態を言う窓はこちら。
  結果を呼んだ側に返すときは `NoticeSink`（`failed` を添える）を通す。既定のまま表示していて、
  「送れませんでした」が ℹ のアイコンで表示されていた。
- Information は「済んだこと」だけに使う。

## 「…」の付け方

押すと**もう一度聞かれることがある**ものにだけ付ける（選ぶ窓・ファイルを選ぶ窓が開く。D10）。

- カードの右クリックの「エクスプローラで開く…」「Unityへ送る…」は、対象のファイルがまだ決まっていないので聞く。
- 商品ページのファイルの欄の同じ項目は、押した行で対象が決まるので聞かない。付けない。
- 確認だけの窓（「消しますか」）は聞き返しではないので付けない。
