# フォルダの置き方を手掛かりにする（今の決め事）

> **要点**：使う人が「このフォルダの下は、ファイルから見て1つ上が商品名、2つ上がショップ名」のように**置き方を指定**すると、
> 未確定の自動検索がフォルダ名も手掛かりに使う。置き方は**フォルダごとにオン・オフ**できる。出すのは候補だけで、自動では結ばない。
>
> **コード**：`Core/Resolution/FolderLayoutHint.cs`・`SaleDecorations.cs`・`FolderLayoutFit.cs`・`ShopItemList.cs`、`FallbackResolver.ProposeAsync`、
> `Core/Models/AppSettings.FolderLayouts`、`App/ViewModels/SettingsViewModel.FolderLayouts.cs`
>
> **経緯**：`docs/research/id-resolution.md` §21（2人目の友人の写しで測った。2026-10-12）。ダウンロード元の記録（Zone.Identifier）が残らない入れ方
> （スマホで落としてクラウドから PC へ移す・同期のアプリ）が多い人でも、自分で並べたフォルダ名には商品名とショップ名が残っていた。

## 指定する物（`settings.json` の `folderLayouts`）

```json
"folderLayouts": [
  { "root": "D:\\Booth", "enabled": true, "itemNameLevel": 1, "shopNameLevel": 2 }
]
```

- `root`：置き方が効くフォルダ。この下のファイルに効く（取り込み元でなくてもよい。ドライブの直下も可）。重なるときは、いちばん深い `root` の指定を使う。
  その指定がオフか段が効かない（両方使わない・同じ段）なら、そのファイルには何も効かない（上の指定に落ちない）
- `itemNameLevel`・`shopNameLevel`：ファイルから見て何段上のフォルダが商品名・ショップ名か（1〜3。使わないなら `null`）。両方 `null` の指定は効かない
- `enabled`：オフにすると、指定を残したまま使わない（置き方が合わないと分かったときに、消さずに止める）
- 手で直した JSON で配列が欠けていても空として読む。設定を既定に戻しても消さない（使う人が入れた調整）

## 自動検索での使い方（`FallbackResolver.ProposeAsync`）

ファイルが指定の下にあり、指定の段にフォルダがあるときだけ働く。対象がフォルダ（zip の無い展開物の根）なら、フォルダそのものを「1つ上」と数える。
ファイル名から検索語が作れなくても（「v1.0.zip」など）、フォルダ名では探す。**ファイル名での検索は今までどおり必ず回す**（置き方に合わないファイルで、フォルダ名だけに頼ると外す）。

**指定は必須ではなく、合わない指定は逆効果になり得る**（画面とマニュアルにそう書く。ユーザ指示 2026-10-13）。合わない指定でも、フォルダ名の検索とショップの一覧の分だけ問い合わせが増え（1本ずつ・1.5秒の門を通るので、そのまま時間が延びる）、
関係の無いフォルダ名で見つけた商品が候補の枠を取り、置き方の点が外れの候補に付いて並びを下げ得る。
段を選び間違えた指定を測った（§21）：ショップ名を商品名として探すと、1位の正解は置き方なしと同じで問い合わせが44%増える。
フォルダ名が別の商品の物だと、1位の正解が 25 → 1 本（60本中）まで下がる。

1. **ショップの商品一覧と照らす**（ショップ名の段があり、手元の商品からショップのサブドメインが引けるとき）：
   ショップの一覧（`<サブドメイン>.booth.pm/items?page=N`。1ページ数十件）を取り、商品名のフォルダと同じ名前の商品を探す。
   一覧は起動している間だけ覚え、同じショップの2件目からは問い合わせない。1ショップ50ページまで（数千件のショップでも取り切れる数。暴走の止め）。
   サブドメインが引けないショップは、この段を飛ばす（BOOTH の検索から引く案は測っていない）
2. **商品名のフォルダで検索する**：フォルダ名から販売の飾り（下）を落として検索語にし、フォルダ名との近さで並べ直す
3. **ファイル名で検索する**（今までどおり）

確かめる（商品 JSON を取る）のは、それぞれの上位3件まで。点の足し方：

| 根拠（候補の理由に出る） | 点 |
|---|---|
| フォルダ名が商品名と一致 | +2 |
| フォルダ名がショップ名と一致 | +1 |
| ショップの商品一覧に同じ名前があった | +2 |

- 名前の一致は、全角半角・大小・空白と記号を揃え、飾りを落として比べる。片方が他方を含む（4字以上）も一致と見る
  （フォルダ名は Windows で使えない字が消え、長い名前は切られている）
- **置き方から足した点は「確度が高い」（7点以上）に数えない**（`ResolutionCandidate.LayoutPoints`）。並びだけを上げる。
  測ると、名前とショップが両方一致した1位の外れは、ファイルが**別の商品のフォルダ**に入っていた物で、名前の一致の型では見分けられなかった
  （置き方に合う60本で外れ1/42、合わない30本で外れ4/4。research §21）
- 進み具合に「ショップの商品一覧を見ています（n ページ目）」を出す。一覧は人が押した自動検索と同じ優先度で、門を通す

### 販売の飾り（`SaleDecorations.Strip`）

ブラウザの拡張機能などは、落とした時点のページの題をフォルダ名にする。題には期限付きの飾りが付いていることがあり、作者は後で外す。

- どこにあっても落とす物：日付の期限（「8/5(水)まで」。「/」が消えた「85(水)まで」も）・「期間限定」「○時間限定」「限定無料」「○%OFF」「○円引き」
- **括弧の中か名前の頭と尻にあるときだけ**落とす1語：「無料」「フリー」「free」「sale」「セール」「値下げ」「割引」「特価」「記念」「配布中」「新作」など
  （どこでも落とすと「フリース帽子」が「ス帽子」、「記念碑セット」が「碑セット」になった。点検33）。「限定」だけの語（「限定カラー」）は落とさない
- 飾りだけになった括弧、末尾の「 - <ショップ名>」（商品ページの題に付く）
- 括弧と飾りを交互に、変わらなくなるまで落とす（中の曜日だけ先に落ちて外の括弧が残るため）
- 落として何も残らなければ元の名前を使う
- 測った効き目：飾りの付いたフォルダ157件中133件が今の商品名に戻り、飾りの無い472件で落としすぎたのは3件。残った24件は自由な宣伝の言葉（「夏休み後半戦」など）。
  1語を頭と尻だけにした後、本体の画面の1位の正解は60本で 55 → 54

## 合っているかを見せる（`FolderLayoutFit.Measure`）

設定の行に、**既に商品に結び付いたファイル**で指定がどれだけ当てはまるかを出す（母数は指定のフォルダの下の紐付け済みのファイル全部。段の足りない浅い所のファイルも数える）（「結び付いたファイル n 件中、商品名 a 件・ショップ名 b 件が合っています」）。
合わない置き方をオンにしたまま気付かない事故を防ぐため。結び付いたファイルが無ければ「まだ確かめられません」。
読むだけの計算なので画面から直に呼ぶ（裏のスレッドで。2万件でも画面を止めない）。

## 画面（設定「取り込みと取得」の「フォルダの置き方」）

- 行ごとに：オン・オフ・フォルダ・「外す」、その下に「商品名のフォルダ」「ショップ名のフォルダ」の選択（1つ上・2つ上・3つ上・使わない）と、合っているかの1行。同じ段を2つに選ぶ・両方使わないなら、合っているかの代わりにそれを言う
- 「フォルダを追加」で選ぶ窓。既定は1つ上＝商品名・2つ上＝ショップ名・オン。同じフォルダは足さない
- 書き込みは `UiCommand.ChangeSettings`（変え方を関数で渡す）
- 未確定の画面は変えない。候補の理由に上の根拠が並ぶ
