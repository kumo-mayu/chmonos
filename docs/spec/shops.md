# ショップの画面（今の決め事）

> **要点**：ショップの中（バナー・1行の見出し・商品の一覧）の並べ方とスクロール、戻る・進むでの位置の戻し方。ショップの一覧の幅などは [ui-rules.md](ui-rules.md) の「画面の幅」。
>
> **コード**：`App/ViewModels/ShopViewModel.cs`（`MemoFirstLine`・`ShowsCompactHeader`）・`ViewportHold`・`InsetScrollViewer`・`NoScrollOnClick`・`ListAnchor`・`StickyShift`
>
> **経緯**：`docs/feedback/done-2026-10.md`（メモ24・28・40）、`docs/feedback/done-2026-09.md`（バナーの畳み・位置の戻し）

## バナー

- **バナーは見出しの三角で畳め、全部のショップで同じ値を閉じても覚える**（`ui-state.json` の `shopBannerHidden`・ユーザ指示 2026-09-29：高さ320を取りすぎる）。既定は出す。バナーの無いショップには三角も出さない。

## 1本のスクロール（2026-10-03・メモ24）

- **上の段（バナー・見出しと集計・メモ）と商品の一覧（カード・リスト）を1つのスクロールにする。**前は一覧だけが流れ、上の段を流した量に合わせて別に詰めていたので、別々に動いて見えた。
- 一番上の「← 検索に戻る」の帯は動かさない。
- メモは上の段にいつも出す。
- 「このショップの商品」の行（件数・所持しているものだけ・カード／リスト）は、1行の見出しのすぐ下で止める（`StickyShift`）。
- リストの見出しの行（列の名前）は止めず一緒に流れる。窓が狭くリストが横にはみ出すとき、横のスクロールバーは一覧の末尾にある（Shift＋ホイールは効く）。

### 1行の見出し

- 名前の段が流れ去ったら、「アイコン・名前・星・集計」の1行の見出しを**重ねて**出す（高さ52。重ねるだけで中身の大きさは変えないので、出入りで動かない。`ShopViewModel.ShowsCompactHeader`）。
- **メモの先頭1行を、名前の右に薄い文字で出す**（メモ28・2026-10-04。`ShopViewModel.MemoFirstLine`）。
  - 出すのは、**字のある最初の行**（空行から書き始めたメモで見出しが空に見えないように）。
  - 入り切らなければ「…」で切り、乗せると全文を出す。
  - **字のある行が2行以上あるときは、1行目が収まっていても末尾に「…」を付ける**（続きがあると見出しだけで分かるように。メモ40。コードは字のある行だけを数える）。
  - メモが無いときは何も出さない。

### 一覧の作り（仮想化）

- 一覧は外のスクロールの中にあって WPF の仮想化が効かない。そこで**行の入れ物は全部作り、中身（カード・リストの列）は見えている辺りの行だけ作って、遠く離れた行の中身は捨てる**（`ViewportHold`。リストの商品は出ている間だけ渡す）。
- 数字（2026-10-03）：作り物300件〔その店は150件〕で、全部作ると開いて落ち着くまで約2.4秒・メモリ約260MB、見えている辺りだけにして約0.65秒・約145MB＝1本にする前と同じ。

### 跳ねさせない（ユーザ 2026-10-03）

- カード⇄リスト・所持／更新ありの絞り・列数の変化では、先頭に見えていた商品を同じ高さに戻す（`ListAboutToChange`）。見方・絞りのときは一覧の高さを残して、流せる範囲を縮めない。

### キー・クリック

- 矢印キーで移ったカードは、重なった帯の下まで流す（`InsetScrollViewer`）。マウスで押したカードは流さない（`NoScrollOnClick`）。
- 矢印の左右は段の中だけ、上下と End・Home は段の番号で移る（検索と同じ。遠い段は流してから作る）。

## 戻る・進むで位置を戻す（ユーザ判断 2026-09-28）

- ショップの一覧・ショップの中は、戻る・進むで来たら離れたときの位置に戻す（商品ページは 2026-09-30。流した量で覚え、同じ商品の開き直しでは今の位置を保つ。[item-page.md](item-page.md)。ほかの画面はまだ）。
- 位置はスクロールの量ではなく、**先頭に見えていた項目とそのずれ**で覚える（列数は幅で変わり、間に商品が消えることもある。`ListAnchor`）。
- ショップの中は絞り（所持・更新あり）も戻す。項目が消えていれば先頭から。ナビから開いたときは先頭から。
