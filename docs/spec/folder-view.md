# フォルダビュー（今の決め事）

> **要点**：エクスプローラの代わりになる画面（ナビのショップの下）。左は記録したパスから組んだフォルダの木（ファイルと未確定まで）、右は選んだ物の詳細。
> 根はボリュームごとの共通の祖先で、境目のフォルダで分ける。ドライブ文字が変わった外付けは通し番号の表で今の文字の下に読み替える。
>
> **コード**：`Core/Services/FolderViewRoots.cs`（根の決め方）・`FolderTree`・`VolumeTable`、`App/ViewModels/FolderViewModel*.cs`・`Views/FolderView.xaml`・`FolderRowTemplateSelector`、`App/Services/VolumeReader`
>
> **経緯**：`docs/history/folder-view.md`（散らかった置き方6通りでの試し・速さの計測・読み替え）、`docs/history/tech-debt-2026-09-14.md` 4-3・4-4（木の計測）

## 根の決め方

1. **ボリュームで分ける**。ラベルで名乗り、同じかどうかはボリュームの通し番号で見る。取り外した物は灰色で残す。
2. ボリュームごとに、全部の置き場所（ファイルの親フォルダ・フォルダとして登録した商品の場所）の**共通の祖先を1つの根**にする。
3. 共通の祖先が**境目のフォルダ**になるときだけ1段下で分け、同じことを繰り返す。見出しの数に上限は持たない（数で止めると、整理した人ほど根が割れる）。
   - 境目：ドライブの直下・共有の直下（`\\nas\share`）・`C:\Users`・ユーザのフォルダ・AppData・OneDrive の同期フォルダの根。
   - デスクトップ・ダウンロード・ドキュメントは境目にしない（そこに直接置く人がいる）。
4. 境目の直下で置き場所が1か所しか無いフォルダは「〇〇（直下など）」の1つの根にまとめる（デスクトップ・ダウンロード・ドキュメントは畳まない）。
5. 根から先は子が1つしかない段を「 › 」でつないで1行に畳む（押せば開ける）。
6. 木の形は毎回計算する。**ディスクを読み回らない**（記録したパスだけで組む）。

## 木に出す物

- 管理しているファイル・フォルダと、**未確定のファイル（「?」の印）**。関係ないファイルは出さない。
- **「商品を表示する」**を切ると、ファイルの行を出さない純粋なフォルダの木になる（ユーザ指示 2026-09-14）。入のときだけ「管理対象」「未確定」の2つで出す種類を選べる。
  「未確定」を切っているときは、未確定の**件数と案内（「未確定として開く」「管理から外す」）を出さず**、木の行・右の頭・子フォルダのカードに小さな「未確定あり」の札だけを出す（ユーザ指示 2026-09-15：完全に隠すと片付けていない物を忘れる。件数まではうるさい）。
  片方だけにしたときは、当てはまるファイルのあるフォルダだけを開いて出す。切り替えはアプリを閉じるまで覚える。フォルダだけの木で名前を絞ると、名前が当たったフォルダを出す。
- ファイルの行はディスク上のファイル名が主で、下に商品名と小さな絵。行の右に「商品 n」「未確定 n」の札。
- **［ファイル名｜商品名］の切り替え**（「フォルダ」の行の右・ユーザ判断 2026-10-01：画面は作り替えず、ファイル名の所を商品名にするだけ）。
  商品名のときは、商品に結び付いた行（管理しているファイル・フォルダごと登録した商品）だけ1行目を商品名にし、元のファイル名を2行目へ回す
  （フォルダごとの登録は「フォルダ名（フォルダごと登録した商品）」）。絵・行の高さは変えない。未確定とフォルダの行は名前のまま。読み上げの名前も見えている名前。
  - 同じファイルを2つ以上の商品が持つときは、前から商品ごとに1行ずつ並ぶので、それぞれの行にその商品名を出す（行を選ぶと開くのも右クリックで扱うのもその商品なので、1行にまとめない）。
  - 並び・鍵・絞り込みはファイル名のまま（入切で行が動かない。絞り込みは前から商品名でも当たる）。切り替えは行を作り直さず、流した位置・選んだ行・止まりを保つ。
  - 管理対象を木に出していない間は押せない。`ui-state.json` の `folderRowsShowItemName` に覚える（設定の画面には出さない）。
- 記録にあるのにディスクに無いファイルは灰色で「見つかりません」。取り外したドライブの木も最後に分かっていた形で灰色のまま開ける。
- 同じ中身が別の場所にもあれば「ほかに n か所」（押すとその場所へ移る）。zip の横に展開したフォルダがあれば「展開したフォルダあり」。
- フォルダごと登録した商品はフォルダの行を1つだけ（中身は記録していない）。
- 並びはフォルダが先、名前順（数字は数として比べる）。

## 右に出す物

| 選んだ物 | 出す物 |
|---|---|
| フォルダ・根・ボリューム | 見出しは**名前だけ**、その下にパス（ユーザ指示 2026-09-14）。この下の商品と未確定の数・「このフォルダで絞り込んで検索」「エクスプローラで開く」「**このフォルダのアイテムを取り込む**」（取り込みの対象に積んで始める。**画面は移さず**、下の帯に進み具合と「取り込み画面を開く」を出す〔2026-09-23・動線の点検 A3〕。監視に入れるかは聞かない）・「**監視：監視中／監視していません**」と足す・外すのボタン・未確定の「未確定として開く」「この下の未確定 n 件を管理から外す」（数を出して確かめる）。その下に**検索画面と同じカード**で、先頭に子フォルダのカード（商品のカードと同じ大きさ。名前だけで、パスはカードの下）、続けて**直下**の商品（ユーザ指示 2026-09-14） |
| 管理しているファイル | 商品ページをそのまま組み込む（戻るは隠す。編集もその場で） |
| 未確定のファイル | 未確定の画面の右側を組み込む（そのファイルだけに絞る） |

- 右のフォルダの一覧（`FolderViewDetail`・`Views/FolderBrowserView.xaml`）：
  - 商品のカードは検索画面と同じ部品（`Views/ItemCardResources.xaml`）。押すと商品ページ、右クリック・中クリック・星・なぞる絵も同じ（操作は `IItemCardHost`）。
  - 子フォルダのカードを押すと、木の中でそのフォルダへ移る（木の文字の絞り込みは外す）。1本道の段は木と同じく畳んで1枚にする。
  - 文字で探す欄だけを置く（絞り込みは付けない）。探すときは**この下の全部**から、商品名・ショップ名・ファイル名・フォルダ名で（大文字小文字・かなの種類・全角半角を区別しない）。
  - 非表示・R-18 を出さない設定は検索画面・ショップと同じ決め事で外し、外した数を書く。
  - カードの大きさは、子フォルダも商品と同じにしてある（ユーザ指示「まずは商品カードサイズで」。変わるかもしれない）。
  - 検索画面と同じくリストでも出せる（探す欄の行の右の切り替え）。フォルダの行も同じ列に並び、絵の代わりにフォルダの印、ショップの列に場所、状態の列に数を出す。
  - **まとめて操作も検索画面と同じ**（ユーザ指示 2026-09-14：フォルダも人によっては検索と同等の発見手段）。カードのチェック・リストの選ぶ列で選ぶと、下に帯
    （すべて選択・選択を解除・お気に入りに入れる・改変に追加・Unityへ順に送る・まとめて編集する）。中身は検索画面と共通（`ItemSelectionActions`・帯は `ItemSelectionBar`）。
- 組み込んだ画面は境目のドラッグを出さない（`docs/spec/ui-rules.md` の画面の幅）。
- 未確定の操作は未確定の画面と同じ `UiCommand`（`ExcludeFiles` など）を呼ぶ。「この下の未確定 n 件を管理対象から除外する」は n 件を1回の命令で外す
  （5,000 件で 0.1 秒未満なので、押せない間の印・進み具合は出さない。2026-10-01）。

## 操作

- 上の入力欄で木全体を名前（ファイル名・商品名・フォルダ名）で絞る。「商品を表示する」と「管理対象」「未確定」の切り替え（上の「木に出す物」）。
- 開いた・畳んだはアプリを閉じるまで覚える。戻る（Alt+←）で選んでいた行に戻る。窓が手前に戻るたびに木を読み直す。
- 検索の「パスも探す」とフォルダの絞り込みは残す。フォルダビューからは「このフォルダで絞り込んで検索」で渡す（`SearchViewModel.ShowOnlyFolder`）。

## ドライブ文字が変わった外付け

- **通し番号の小さな表 `volumes.json`**：1行が「このドライブ文字に最後に見えたのは通し番号 X」。手元のファイルの記録には何も足さない。ラベルは表示だけ（既定の名前の外付けは2台が同じ名前になり得る）。
- **控える時は取り込みとフォルダビューを開いた時だけ**（常に見張らない）。
  - 取り込み：取り込むフォルダの文字と通し番号の組をそのまま控える。
  - フォルダビュー：記録したパスが今その文字の上に**実際に在るときだけ**控え直す（文字ごとに20本まで確かめる。確かめずに上書きすると別の外付けと取り違える）。
- **読み替え**：控えた通し番号が別の文字に見えていれば、その文字の記録を今の文字の下に出す。元の文字にまだ同じ通し番号が見えている・どこにも見えていないときは読み替えない。
  - **番号で見分けられない物は使わない**（点検 2026-09-23）：ネットワークドライブ（同じ NAS の別の共有が同じ番号）・subst の文字（元のドライブと同じ番号。`QueryDosDevice` の先が `\??\`）は控えも読み替えもしない。通し番号0は控えない。同じ番号が2文字に見える（複製したディスク）ときは読み替えない。
- 記録のパスは書き換えない（次の取り込みで今の文字になる）。
- **検索のフォルダの条件にも同じ読み替えを当てる**。検索は読み込むたびに読み替えだけ確かめ直す（表は書かない）。
- **読み替えた結果だと分かるようにする**：フォルダビューのボリュームの行に「X: として記録した物を D: で出しています」、根の行と検索のフォルダの行に「記録では X:」。
- ディスクを見る所（通し番号の読み取り・在るかの確認）は画面のスレッドで行わない（`DiskCheck`・`VolumeReader`）。

## 速さ

- 木は裏のスレッドで組み、子の並べ替えもそこで1度だけ。畳んだフォルダの中の行は作らない（絞り込み中だけ作る）。
- 左の一覧は見えている行だけを平らに並べて仮想化する（`CacheLength="4,4"`・種類ごとの見た目 `FolderRowTemplateSelector`）。差し替えは `RangeObservableCollection` で知らせを1回に。
- 商品の絵の場所は、行が画面に出たときに初めて探す。
- 計測（`-stress-realcat`）：開いて行が出るまで約1.1秒。1000本以上が平らに並ぶ根を開くと 0.2〜0.3 秒止まる（残り。原因は行の配置で、1回の最長は約58ms まで下げた）。
- 5000件の作り物で木の1段降りは 22〜31ms で、直す必要は無かった。
