# 商品ページと編集画面（今の決め事）

> **要点**：商品ページは主に見る場所、入力は編集画面に寄せる（保存経路を少なく保つ）。画像は「BOOTH で観測した物 → 自分で足した物 → BOOTH から消えた物」の順。
> 手元のファイルはファイル単位で扱い（外す・戻す・Unity へ送る・展開して開く）、商品ごとの移し替えは「IDを変更」。編集画面は複数の商品を順に埋める画面。
>
> **コード**：`App/ViewModels/ItemViewModel*.cs`・`ItemRows.cs`・`Views/ItemView.xaml`・`ItemFilesPanel.xaml`、`App/ViewModels/EditViewModel*.cs`、
> `Core/Services/ItemImageOrder`・`ImagePipeline`・`ItemService`、`Core/Models/LocalFields.cs`（持ち主）
>
> **経緯**：`docs/history/user-images.md`（自分で足す画像）、`docs/history/ui-revision.md` §5（購入記録）・§8.5（外す）、`docs/history/private-items.md` §9（IDを変更）、`docs/feedback/`（U番号）

## 商品ページ

- 説明は保存した HTML（`items/{id}.h2.html`・script などは保存時に削る）。h2 を畳める（全体とセクションごと・既定は全開）。
  「商品説明」の欄ごとも畳める（ユーザ指示 2026-09-14）。畳んだかどうかは「BOOTHのタグ」と同じく商品を移っても保つ（アプリを閉じるまで）。
- **説明の見出しは、画面に見えている分までを最初の1コマで作り、画面の外の分は後から1行ずつ足す**（ユーザ判断 2026-09-30。`Controls/ProgressiveItems`）。
  見出しごとに選べる文字の箱が1つあり、見出し21個の商品では開くのに約340ms かかっていた（短い商品は約60ms。`docs/research/item-page-open-2026-09-30.md`）。
  - 最初に出るコマは、全部を1回で作ったときと同じ。見えている物は動かさない（足すのは一覧の末尾だけ。先読みは 300px）。
  - **説明の全部が在ることを当てにする処理は、先に足し切る**（`ProgressiveItems.FeedAllNow` → 並べ直す）。今は画面内検索（Ctrl+F）だけ。
    説明をまとめて読む処理（書き出し・印刷など）を足すときは、同じに足し切ってから読む。
  - 分けずに全部その場で足すとき：説明の欄を畳んでいる・流せる画面の中に無い・使い回された画面で前の商品の流した位置が残る。
  - 読み上げ・自動操作から見ると、開いた直後の約0.3秒は画面の外の見出しがまだ無い（足し終えると全部出る）。
- **動画の欄**（ユーザ指示 2026-09-14）：埋め込み（`booth.embeds`）・短い説明・見出しの本文に載っている YouTube の動画を拾い（`VideoLinks`・試験付き）、
  絵とタイトル付きのリンクで出す。押すとブラウザで YouTube を開く（アプリの中では再生しない）。
  - **既定は畳む**。商品ごとに畳んだ状態で始め、開いたときだけ YouTube へ絵とタイトルを取りに行く（`docs/spec/background-and-network.md`）。
  - 動画が無ければ見出しに「この商品の説明に YouTube の動画はありません」と出し、開けない。
  - タイトルが取れなければ（非公開・削除・通信の失敗）その旨を出し、リンクは残す。
- 本文中の BOOTH 商品リンクは、所持していればアプリ内の商品ページへ。作者名はアプリ内のショップ画面へ（外の BOOTH へ飛ばさない）。
- タグは上部（切り替えられる）。
- 対応アバターを手で足す・消す（`docs/spec/avatars.md`。消した印は再検出をまたいで残る）。「＋ 追加」の候補には「〇〇（共通素体）」も混ぜ、選ぶと対応素体に入る（2026-09-28）。
- 持っているのに出していなかった内部情報（メモなど）も出す。
- 「BOOTHから取り直す」（何が起きるかを名乗る）。BOOTH に無い商品では押せない（理由をツールチップ）。
- 右の列に「この商品を使った改変」と「改変に追加」、何回入っているか（`docs/spec/modifications.md`）。
- フォルダビューに組み込むときは戻るを隠す（`IsEmbedded`）。境目のドラッグも出さない。
- **組み込んだ商品ページ（フォルダビュー・改変の画面）で別の商品を選び直したら、流した位置を先頭へ戻す**（ユーザ判断 2026-09-30）。
  画面は使い回されるので、戻さないと前の商品の位置のまま次が出る。同じ商品を開き直したとき（取り直した後・ファイルを外した後）は戻さない。
  主の窓の商品ページは戻さない（商品から商品へ移ると位置が残る。今の動きのまま）。

## 画像

- 保存先 `images/{id}/{URLのハッシュ}.webp`（長辺・画質は設定。既定 384px・WebP 80）。**再取得は画像ファイルを消さない**（消すのは取れなかった印だけ）。
- **並び**：`Booth.Images` の順 → 自分で足した物（`Local.UserImages` の順・足すと末尾）→ BOOTH から消えた物（「削除済」のかぶせ）。BOOTH の画像は並べ替えない。
- **自分で足す**：ファイル選択・ドロップ・貼り付け。ライブラリへコピーして同じ圧縮をかけ、`user-{中身のハッシュ8桁}.webp`（同じ絵は1枚にまとまる）。印は左下の小さな札。
- **サムネイルの指名**：`Local.ThumbnailImage` にファイル名を1つ（BOOTH の画像も指名できる）。指名先が消えたら黙って1枚目に戻す（BOOTH の画像なら指名は残す。自分で消した画像なら指名も外す）。★は右上。
- BOOTH 由来の画像（URL に商品ID）を商品ページに落としたら「この画像をどうしますか？」［キャンセル］［商品を開く］［画像として足す］。既定のボタンは置かない。商品ページ以外では今まで通り。
- 見る：矢印はマウスが絵の端に来たときだけ出し、最初と最後をつなぐ（1枚なら出さない）。帯そのものがボタン。左右キーでも送る（入力欄では効かせない）。操作は右クリックに集める。
- 「この商品の画像取得を優先」は未取得があるときだけ。取れなかった物（`.missing`）は「n 枚は取得できませんでした」。裏で取った画像はその場で出る（見ていた絵は選んだまま）。
- 画像の削除の確認：公開中の商品は1回、非公開・削除済みの商品は「二度と取得できません」と理由を添える。

## 手元のファイル

- 欄は見出しの三角で畳める（ユーザ指示 2026-09-19）。既定は開く。商品を移っても同じ開き方のまま（アプリを閉じるまで）。件数と容量は畳んでも見出しに出す。
- ファイル単位で並べる。容量は論理値（重複を1回）。
- **名前を押すとエクスプローラで開き、場所は名前に乗せたときに出す**（ユーザ指示 2026-09-19：名前の下に場所の行が続き、同じ名前が2回並んで読みにくかった）。
  フォルダの行も同じ。見つからないファイルは開く先が無いので名前を押せない。
  同じ中身が別の場所にもあるときは、名前の横に「同じ中身が n 箇所に」の札（「実体」は内部の言葉に読めたので改めた・2026-09-19）、下に**2つめ以降の場所**を「同じ中身がある、ほかの場所」として行に出し、場所のすぐ横の［エクスプローラで開く］から開ける（ツールチップは押せないので入口が要る）。
- **ボタンは名前のすぐ横**（ユーザ判断 2026-09-19：右端に並ぶと、名前を読んでから押すまでに視線が画面の幅ぶん往復した）。
  - ［開く ▾］：「エクスプローラで開く」「一時的に展開して開く」（zip のときだけ）を下に出す（`Controls/MenuButton`・改変の「Unity ▾」と同じ開き方）。外したファイルでも薄くしない。
  - unitypackage の行：名前の横に［Unity ▾］で「Unityへ送る」「改変に追加して送る」「Unityで選択」。送り方を2つに分けたまま選ばせる（送る前に記録するか聞くと、記録を使わない人の邪魔になる）。
    「選択」は改変の画面と同じ道（`UnityMemberSelect.ShowIfPresentAsync`）で、相手は送り先と同じいま開いている Unity。**入っていなければ言うだけで、取り込みには進まない**（「示す」つもりが「取り込む」にすり替わらないように）。結果は欄の下の1行。
  - 商品の中身を変える「この商品から外す」「この商品に戻す」「登録を解除」だけは右端に離す（開く・送るの隣で押し間違えないように）。
- ファイルごとに：「この商品から外す」（灰色の行で残る・`docs/spec/id-resolution.md`）／「一時的に展開して開く」／zip の中の unitypackage ごとに「Unityへ送る」「改変に追加して送る」と入り先（`docs/spec/unity.md`）。
- 最後のファイルを外すときは、商品を「非表示にして残す（おすすめ）」「残す」「完全に削除」の3択で聞く（ユーザ判断 2026-09-12）。
  残す2つは外した印も残るので、次の取り込みでこのファイルがこの商品に戻らない。非表示は検索とショップの件数から除き、統計の支出には入れる。
  完全に削除は印も消えるので、次の取り込みで読み取った情報がこの商品を指せば作り直される。窓には選ぶのに要ることだけを書く（2026-09-24）。
- 在るか・中の unitypackage は画面のスレッドの外で調べ、行を先に出して後から印を付ける（`DiskCheck`）。
- 見つからないファイルは「見つかりません」（記録のどの場所にも無い。移した・消した）。［開く ▾］は出さず、名前も押せない。在るかは商品ページを開くたびに画面のスレッドの外で確かめる（`LocalFilePresence`。前は記録のパスが空のときだけ出していて、移したファイルも普通の行で出ていた・点検 2026-09-30 の B）。
  つながっていないドライブの上にしか場所が無いファイルは「取り外しているドライブ」（取り込みがそこのパスを残すのと同じ考えで、無くなったとは言わない。フォルダの表示と同じ語）。フォルダとして登録した商品はフォルダの行。
- **壊れていて開けない zip は、名前のすぐ横に札「壊れたzip」**（ユーザ判断 2026-09-30。記録の `archiveBroken`・`docs/spec/import.md`）。未確定の行と同じ色（赤：`BadSoft`・`BadBorder`・`Bad`）、同じ吹き出し「zipを開けませんでした。ダウンロードし直してください。」。
  前は中身の一覧が空なだけで、「一時的に展開して開く」を押して初めて分かった。商品ページを開くたびに zip を開き直さず、取り込みが書いた事実を見せる。編集画面も同じ部品なので同じ札が出る。
  - **在る物にだけ出す。**「見つかりません」「取り外しているドライブ」の行には出さない（無い物は壊れているかを見られない。次の手が「取り込み直す」「つなぐ」と「ダウンロードし直す」で並ぶと、どちらを先にするのか分からない）。
  - 外したファイルの行にも出る（事実は変わらない）。［開く ▾］の「一時的に展開して開く」と Unity へ送るは、壊れていない物と同じに出す（押すと失敗の文が出る）。

## 購入記録

- 商品ページのバリエーションの欄は畳める。見出しに三角と件数を置き（ローカルファイルの欄と同じ形）、畳んだ状態はアプリを閉じるまで覚える（ユーザ判断 2026-09-27）。
- 畳む印は全画面で三角に揃える（商品ページ・編集画面のあと、アバターの管理・改変の画面・未確定・設定にも広げた。ユーザ判断 2026-09-29。`ManageResources.xaml` の `TriangleExpander`・`TagToggle`。見出しの文字を押しても開閉する。ユーザ判断 2026-09-27）。
- 「記録していること」の「検索から除く」のチェックで、非表示にする・解除する（状態の横で戻せるので「元に戻す」の帯は出さない。ユーザ判断 2026-09-27）。
  隣の「更新通知」と同じチェック1つにする（状態の文字と［非表示にする］［非表示を解除］は分かりにくかった。ユーザ判断 2026-09-28）。

- **買った1回＝1レコード**（`purchases[]`：`variationId`（`long?`）・`price`・`kind`＝自分用／贈った／貰った・`note`）。同じ種類が複数行あってよい（3人に贈れば3行）。
- 2件目以降は種類の行の下に独立した行で足す（既定は「贈った」）。行ごと消す。種類を指さない購入もいつでも足せる。
- 所持の定義は変えない（贈った物はファイルが来ないので所持ではないが、支出には入る）。貰った物は支出に数えない。
- 価格の空欄は **0円として記録する**（ユーザ判断 2026-09-29：未入力を無くす。前は空欄を未入力、0 を無料配布と分けていたが、未入力は検索の「払った額」「有料・無料」で値の無い物として抜け落ちた）。欄は空欄のとき薄い 0 を出す。BOOTH の値段が無い行（種類を指さない購入・消えた版）では横の「現在 -」を出さない。読めない文字だけは保存せず知らせる。
- ファイルに「どの種類か」を付ける：購入した種類の行の横のプルダウン（名前に種類名が入っているファイルを先に並べる。自動では付けない）。書くのは編集画面の保存とは別の命令（`LocalFiles` は取り込みも書く）。

## 編集画面

- 複数の商品を順に埋める。「保存して次へ」を上にも下にも置く。無くなったら3秒後に検索へ戻る（切れる・止められる）。
- 商品名・ショップ・カテゴリは左の商品表示の「編集」で開く（BOOTH から取れている商品では普段変えない）。右の入力はユーザータグから始まる。
- 既定の属性を並べておき、触るまで保存しない（触っていないのに書くと「決めた」と区別できない）。
- 入力欄には候補（`SuggestBox`）。全部並べず候補から積む。Enter で確定・↑↓で候補・Tab は次の欄。候補に無い語は「新しく足す」と明示。
- ユーザータグ・属性は名前で参照、トップレベルは複数選べ、サブはトップレベルごと（外すと配下のサブも外れる）。
- 非表示にする（統計には含める）。
- ショートカット：保存して次へ＝Ctrl+Enter・スキップ＝Ctrl+Shift+→・前へ＝Ctrl+Shift+←（入力欄の外だけ。`ui-input.md` のキー）・画面の中を探す＝Ctrl+F・戻る＝Alt+←。設定画面でキーを押して変えられる（同じキーは先の方を外して知らせる）。文字の欄では文字を打つ・カーソルを動かすキーは働かせない。
- 編集キューの位置は `edit-session.json`（`UiCommand` の編集キュー5種）。
- 一括操作は ユーザータグの追加・削除／属性の一括設定／非表示・管理から外す だけ（メモや価格のような1件ずつ違って当然の物は対象にしない）。
- 保存は `SaveLocalAsync` で編集画面が持つ項目だけ（`LocalOwners`）。

## 取り消し

1. 取り消せる操作（非表示・管理から外す）は確認なしで、直後に「元に戻す」。
2. ファイル削除・公開中の商品の画像削除は確認1回。
3. 取り返しがつかない物は理由を添えて確認（非公開商品の画像・共通素体の削除・改変の削除）。
