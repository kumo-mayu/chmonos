# 画面の用語表（今の決め事）

> **要点**：画面の語は、普通の Windows のソフトで見る語にする（ユーザ判断 2026-09-24）。作り手にしか通じない言い回し（積む・落とす・痩せる）と、コードや JSON の名前は画面に出さない。
> 同じことは同じ語で呼ぶ。この表に無い語を画面に入れるときは、先にこの表に書き足す。
>
> **道具**：`tools/wording.mjs` が「使わない語」「揃える表記」「まだ決めていない揺れ」の3つの表を読んで印を付ける。表の列の並びを変えるときは道具も直す（探す形は JavaScript の正規表現。表の中の `|` は `\|` と書く）。
>
> **書き方の決まり**は [ui-writing.md](ui-writing.md)。**経緯**：`docs/research/ui-wording.md`（2026-09-09 の総点検）、`docs/history/ui-wording-2026-09-24.md`（AI らしさの点検と、この表の作り直し）

## 内部の言葉と画面の言葉

コードと JSON の名前は画面に出さない。

| コード・JSON | 画面 |
|---|---|
| `item` | 商品（失敗の文では「商品データ」） |
| `appTag`・`userTag` | ユーザータグ（階層は大分類／小分類） |
| `BoothID` | 商品ID |
| `variation` | バリエーション（2026-09-18。「種類」はカテゴリの種類とも読めた） |
| マスタ | 一覧 |
| ハッシュ（取り込みの結果の数） | 「中身を確かめた」「確かめを省いた」（ユーザ判断 2026-09-24） |
| 実体 | 同じ中身 |
| トップレベル／サブレベル | 大分類／小分類 |
| .NET の例外の文（`exception.Message`） | 出さない。`FailureText.Cause` の原因の文に置き換える |

## 同じ操作は同じ動詞で呼ぶ（ユーザ判断 2026-09-20。W1〜W10・`docs/feedback/ui-consistency-2026-09-20.md`）

| 何を | 画面での言い方 | 使わない言い方 |
|---|---|---|
| Unity へ渡す | **送る**（「Unityへ送る」） | インポート・取り込み。「取り込み」はこのアプリの画面の名前なので、Unity の画面は「Unityの取り込み画面」と書く |
| unitypackage が入るフォルダ | **場所**（「場所：Assets/FUKA」。移っていれば「場所：Assets/_FUKA → Assets/FUKA」と矢印でつなぐ） | 入り先。「移動されています」の文（長い。ユーザ指示 2026-09-29） |
| 関係を切る（本体は残る） | **外す**（「商品から外す」「登録を外す」「紐付けを外す」） | 解除・（その意味の）消す |
| 未確定から片付ける | **管理対象から除外** | 管理から外す |
| さっきの操作を取り消す | **○○を解除**（「非表示を解除」「除外を解除」「紐付けを戻す」）。何を解除するかを書く | 裸の「解除」「元に戻す」「記録を消す」 |
| 永久に無くす | **削除** | 消す（入力欄を空にする × は「消す」のままでよい） |
| 2つを1つにする | **統合** | まとめる・寄せる |
| 関連づける | **紐付け** | 結び付け |
| 手元のフォルダを開く | **エクスプローラで開く** | フォルダを見る・フォルダを開く |
| 検索画面へ行く | **検索で開く**（「この商品を検索で開く」） | 検索で見る・絞り込んで検索 |
| 商品に付ける自分の語 | **ユーザータグ**（階層は大分類／小分類） | 分類（BOOTH のカテゴリは「カテゴリ」と呼ぶ） |
| 見えている分を全部選ぶ | **すべて選択** | 表示中をすべて選択 |
| 選んだ物を編集の画面へ | **○○を編集する**（未確定は「確定したものを編集する」） | 編集へ送る |
| BOOTH に問い合わせて情報を更新する | **商品情報を取り直す**（吹き出しに「商品のファイルはダウンロードしません」） | BOOTHから取り直す（ダウンロードに読めた） |

ナビの項目名は「タグの管理」、画面の見出しは「ユーザータグの管理」（ユーザ判断 2026-09-20）。
要確認の見出し「タグの参照切れ」も変えない（ユーザが決めた語）。

## 決めた呼び方

- **アプリの中で開くのか、ブラウザで BOOTH を開くのか**をボタンの名前で分ける。アプリ内は「商品ページを開く」「アバターの管理へ」、外は「BOOTHで開く」。
  外へ出るボタンの吹き出しには「アプリの外へ出ます」と書く（2026-09-18）。行き先が無いときは押せなくし、理由を吹き出しに書く。
- 画面の名前は左上に太字で書く。検索画面だけは書かない（左の「絞り込み」で伝わる。2026-09-20）。
- VRChat の利用者が普段使う語は、そのまま使う：素体・改変・着せる・対応アバター。
- **日付の2つを呼び分ける**（ユーザ判断 2026-09-28。並べ替えに「入手日」と「手元に入った日」が並び、違いが分からなかった）。

  | 画面の語 | 何の日付か |
  |---|---|
  | 取り込んだ日 | このアプリに取り込んだ日時（`recent.json` の AddedAt）。「最近取り込んだ順」「取り込んだのが古い順」 |
  | 入手日 | 手で入れた日。空欄ならファイルの日付（`AcquiredDateResolver`） |

  「手元に入った」は使わない。
- **バリエーションの行の呼び分け**（ユーザ判断 2026-09-29。「（名前のないバリエーション）」が分かりにくかった）。

  | 画面の語 | 何の行か |
  |---|---|
  | バリエーション選択なし | BOOTH が名前を持たせていないバリエーション（種類が1つだけの商品に多い）。`DisplayText.VariationName` |
  | バリエーションを選ばない購入 | 種類を指さない購入の記録（`DisplayText.VariationLabel(null)`） |
  | 名前の分からないバリエーション | BOOTH から消え、名前を控えていなかった種類 |

  「名前のないバリエーション」は使わない。前の2つは別物なので混ぜない。
- **表示の大きさ**（2026-09-29）：アプリの中だけを大きく・小さくする設定（90〜150%）。Windows の「拡大率」とは別物なので、画面では「拡大率」「ズーム」と呼ばない。
  操作は「表示を大きくする」「表示を小さくする」「表示の大きさを100%に戻す」。
  ショートカットの記号のキーは言葉で書く：「プラス」「マイナス」「テンキーのプラス」（「Ctrl + +」は区切りと見分けにくい。矢印を「右矢印」と書くのと同じ）。
- **ALCOM**（2026-09-29）：VCC の代わりに使われるコミュニティのアプリ。名前はそのまま「ALCOM」と書き、説明や読みを付けない（VCC と同じ扱い）。
  ボタンは「ALCOMを開く」。「vrc-get」「VCC互換」とは書かない。どちらも無いときの案内は「VCCかALCOMを入れると、ここから開けます。」。
- **vcc://**（2026-09-29）：VCC と ALCOM が引き受けるリンク。設定の選択肢「vcc:// に合わせる」でだけ使い、そのまま書く（ALCOM の設定画面と同じ見え方にする）。
- **表示の色**（2026-09-29）：選択肢は「明るい」「暗い」「Windows に合わせる」。「テーマ」「ダークモード」「ライト」「ダーク」とは書かない。
- **知らせと確認の窓のボタン**（2026-09-29。自前の窓にしても Windows の確認の窓と同じ語）：「OK」「キャンセル」「はい」「いいえ」。
  「はい(Y)」のような括弧の文字は付けない。本文でボタンを指すときも「はい」「いいえ」と書く（[ui-dialogs.md](ui-dialogs.md)「知らせの窓」）。
- **無いファイルの札**（2026-09-30。フォルダの表示と商品ページで同じ語）：記録の場所に無いものは「見つかりません」、つながっていないドライブの上にしか場所が無いものは「取り外しているドライブ」。
  後者は無くなったとは限らないので「見つかりません」と混ぜない（次の一手が「取り込む」ではなく「つなぐ」）。
- **一時展開の帯**（2026-10-01）：進み具合は「展開しています… 120.5 MB / 2.3 GB」と、展開した後の大きさで書く（件数では書かない。大きい1ファイルの間、止まって見える）。
  2つ以上を並べて展開している間は「{n} 件のzipを展開しています…」。止めるボタンはほかの帯と同じ「中止」で、押した後は片付けが済むまで「展開を中止しています…」。
  大きさの書き方はファイルの行と同じ（`DisplayText.Size`）。
- **壊れたzip**（2026-10-01）：取り込みで zip として開けなかった物の札（未確定の行）。文では「壊れていて開けないzip」。次の手は「ダウンロードし直す」と書く。
  「読めなかったファイル」（取り込めていない物。閉じて取り込み直す）とは別の物なので混ぜない。

## 使わない語

ユーザ判断 2026-09-24 の方針（普通の Windows のソフトで見る語）で決めた。`tools/wording.mjs` は「探す形」に当たった文に「使わない語」の印を付ける。
意味が違う使い方にも当たることがある（「こちらを選びます」の「こちら」は選択肢を指す）。印は見直しのきっかけで、直すかは文を読んで決める。

| 使わない語 | 使う語 | 探す形 |
|---|---|---|
| 積む | 追加する（「取り込みの対象に追加」） | `積[まみむめもん]` |
| 足す | 追加する | `足[さしすせそ]` |
| 落とす（ドラッグの意味） | ドロップする | `落と[さしすせそ]` |
| 落とす（ダウンロードの意味） | ダウンロードする（「ダウンロードし直す」） | `落とし直` |
| 写す | コピーする | `写[さしすせそ]` |
| 出す（表示の意味） | 表示する | `(?<![取書引抜呼送持見差提突飛吐張思検算輸放排選演露支進届移りき]\|前に\|思い)出[さしすせそ]` |
| 出る（表示の意味） | 表示される | `(?<![外取])(?:に\|が)出(?:ます\|ません\|る\|ない\|た\|て)` |
| 名乗る | 表示する・「〜という名前にする」 | `名乗` |
| 相手（アプリが働きかける先） | 対象。BOOTH を指すなら「BOOTH」 | `相手` |
| こちら（アプリ自身） | 主語を省く・「このアプリ」 | `こちら` |
| 見に行く・取りに行く | 確認する・取得する | `(?:見\|取り\|探し\|読み)に行` |
| 束ねる | まとめる・「同じショップとして扱う」 | `束ね` |
| 退ける | 移動する・「別の名前で残す」 | `退け` |
| 結び直す・結び付ける | 紐付け直す・紐付ける | `結び[直付]` |
| 手掛かり | 読み取った情報（「取り込み時に読み取った情報」。ユーザ判断 2026-09-24） | `手掛か\|手がか` |
| 痩せる | 減る・少なくなる | `痩せ` |
| 暴れる | ばらつく・安定しない | `暴れ` |
| 思いがけない失敗 | 予期しないエラー | `思いがけ` |
| 黙って | 知らせずに・何も表示せずに | `黙` |
| 拾う | 読み取る・検出する | `拾[わいうえお]` |
| 畳む | 折りたたむ | `畳` |
| 割れる | 分かれる | `割れ` |
| 寄せる | 統合する・揃える | `寄せ` |
| 当てる（照らし合わせる意味） | 照合する・合わせる | `(?<!割り)当て[るてたま]` |
| 湧く | 表示される・増える | `湧` |
| 紛れる | 混ざる | `紛れ` |
| 辿る | 開く・たどる | `辿` |
| 見当（原因の見当） | 考えられる原因 | `見当` |
| 言い分ける | 分けて表示する | `言い分` |
| 取り違える | 間違える | `取り違` |
| 行う | する | `を行[いうっわ]\|行います` |
| 可能 | できる | `可能(?!性)` |
| 〜となります | 〜です・〜になります | `となります` |
| 物（形式名詞） | もの（「送るもの」） | `(?<=[るたいなだ])(?<!買い)物` |
| 所（形式名詞） | ところ・箇所 | `(?<=[るたいなの])所(?![有属持在])` |

## 揃える表記

同じものを2通りに書かない。左に揃える。

| 使う表記 | 揃える前 | 探す形 |
|---|---|---|
| ユーザータグ | ユーザタグ | `ユーザタグ` |
| （押さずに保存する欄の案内）打ち終えると保存されます | 打ち終えると残ります・押さなくても残ります | `(打ち終えると\|押さなくても)残ります` |
| すべて | 全部・全て | `全部\|全て` |
| ユーザータグ（自分で付ける語） | 分類 | `(?<![大小H]\|BOOTHの)分類` |
| {n} 件（数と単位の間に空白） | {n}件 | `\}件` |
| …（三点リーダー） | ... | `\.\.\.` |
| 英字と日本語の間に空白を入れない（「BOOTHで開く」「Unityへ送る」「Unity側」） | 「BOOTH で」「の Unity」 | `[A-Za-z] [ぁ-んァ-ヶ一-龠]` `[ぁ-んァ-ヶ一-龠] [A-Za-z]` |
| カタカナ語の最後の長音を付けない（フォルダ・エクスプローラ・カテゴリ） | フォルダー・エクスプローラー・カテゴリー | `フォルダー\|エクスプローラー\|カテゴリー` |
| 選ぶ窓の選択肢は、名前と説明を別の行に分ける | 「……」「：」で区切って1行に書く | `……` ` ：` |

BOOTH のカテゴリは、編集画面の欄も検索の絞り込み・並べ替えと同じ「カテゴリ」と呼ぶ（前は編集画面だけ「BOOTH分類名」で、同じ物に2つの名前が付いていた。ユーザ判断 2026-09-24）。
「分類」は統計の「分類なし」のように別の意味でも残っているので、印が付いても読んで決める。

空白を入れるのは、数と単位の間（「{n} 件」「1500 ミリ秒」）だけ。英字と日本語の間には入れない（ユーザ判断 2026-09-24）。
カタカナ語の最後の長音は付けない。今の画面はこの形で揃っている（ユーザの好み。Windows 11 は付けるが合わせない。ユーザ判断 2026-09-24）。
選択肢の名前と説明を「……」や「：」でつながず、説明は名前の下の行に書く（ユーザ判断 2026-09-24）。
「失敗」と「エラー」は今の使い分けのまま（「〜に失敗しました」「予期しないエラー」）。「商品情報を取り直す」も今のまま（ユーザ判断 2026-09-24）。

## まだ決めていない揺れ

標準を決めていない揺れを置く。道具は両方の数を数えるだけで、印は付けない。決めたら「揃える表記」へ移す。
今は無い（2026-09-24 に、英字と日本語の間の空白・Unity側・選択肢の区切り・カタカナ語の長音を決めて移した）。

| 揺れ | 探す形 | 備考 |
|---|---|---|
