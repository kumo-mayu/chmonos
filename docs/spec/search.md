# 検索（今の決め事）

> **要点**：絞り込み（離散値）と文字列検索（自由記述）を分け、並べ替えは単一値の欄だけ。常設の条件と「条件を追加」で積む条件があり、積んだ条件は**種類だけ**覚えて値は覚えない。
> 文字列は同梱の辞書で表記（ローマ字・かな・漢字・英語）をまたげる。**意味検索（埋め込み）はしない**——辞書は引いた結果を説明できる。
>
> **コード**：`App/ViewModels/SearchViewModel*.cs`（`.History` など partial）・`ItemCardViewModel`・`DeferredCardHost`、`Core/Search/`（`SearchQuery`・`SearchBridge`・`ReadingMatch`）・`Core/Services/ItemOrder`・`FolderTree`・`ModificationUsage`
>
> **経緯**：`docs/history/ui-revision.md` §1〜3（絞り込み・文字列・カード・辞書の実測）、`docs/history/grill-2-ui-and-data-model.md`、`docs/research/fuzzy-search.md`（類義語は入れない推し）

## 絞り込み

- **常設**：カテゴリ／所持（とギフト：贈った・貰った）／ユーザタグ／BOOTHタグ／属性／対応アバター。
- **条件を追加**：公開日・スキ数・価格・R-18・販売終了・対応素体・着せているアバター（改変経由）・更新の有無・フォルダ・お気に入り・最近・アバターの商品ID など。
  入力の形は 範囲（日付・数値。片側だけも可）／チェック／候補入力から積む／フォルダの降り方。
- **積んだ条件は種類だけ覚える**（`ui-state.json`）。値まで戻すと「なぜか少ない」で始まり、原因が畳んだ中にあると気付けない。
- **選択肢には件数**：今の他の条件を当てた後の件数。自分の軸は自分を除いて数える。0件は消さずに薄く。
- 候補が多い条件（BOOTHタグ・属性）は入力欄から積む（80%が1商品にしか付かず、順位に意味がない）。対応アバターは所持しているアバターを常時出し、ほかは `名前（商品ID）` の候補から引く。
- 意味：価格＝**自分が払った額**。更新の有無＝要確認に未読の更新通知が残っているか。
- 対応アバター：直接対応＋素体経由が既定（`docs/spec/avatars.md` の相性）。「素体経由の対応も含める」はそのアバターが素体に属しているときだけ出す（効かない選択肢を並べない）。
- 属性は上下限の範囲。0〜100 のままなら未評価も通り、片側でも動かせば未評価は外れる。属性で並べると未評価は昇順・降順どちらでも末尾。
- フォルダ：1階層ずつ降りる＋パンくず、チェックで選ぶ（子孫を含む・複数は OR）。並びは自然順（番号接頭辞を壊さない）。見つからないファイルも記録上のフォルダに出す。
  ドライブ文字が変わった外付けは読み替えて「記録では X:」と出す（`docs/spec/folder-view.md`）。エクスプローラの代わりはフォルダビューの役。
- 絞り込みパネルは畳める（286px ⇄ 34px）。畳んだ姿に効いている条件の数とその中身のツールチップ。
- 検索の履歴：絞り込みと文字列を1セット。名前を付けた物は件数で落とさない。書くのは `UiCommand.ChangeSearchHistory`。

## 文字列

- 構文：スペース＝AND・`-語`＝除外・`"…"`＝フレーズ・`OR`・`( )`・`name:語`＝探す所を絞る（ユーザ案 2026-09-15）。入力欄の下に見本1行、説明はホバーで。
  **構文の記号は1字ずつ NFKC で畳んでから読む**（全角の括弧・引用符・ハイフン・空白・コロンも効く・ユーザ判断「記号も畳みましょう」）。
  - 前置きは決めた名前だけ（`name` `shop` `subdomain` `memo` `main` `path` `id` `variation` `file` `content` `tag`）。知らない語（`Re:Zero`・`https:`）はふつうの文字。
    `"…"` の中の `name:` は前置きにしない。`name:"夏 セット"`・`tag:(夏 OR 冬)`・`-tag:無料` と書ける。前置きがあれば「対象」で切っている所でも探す（ユーザ判断 2026-09-16）。
- **対象**（検索欄の右の「対象」・1つずつ切り替え）：商品名・ショップ名・メモ（ここまで既定オン）／サブドメイン・本文（説明と h2）・BOOTHタグ・バリエーション名・商品ID・ファイル名・ファイルの場所（パス）・zip の中のファイル名（既定オフ）。
  **本文・パス・BOOTHタグは既定に入れない**（当たりすぎて「なぜ出たか」が分からない。BOOTHタグは絞り込みの条件で探す物・ユーザ判断 2026-09-16）。自分で入れたカテゴリは文字列の対象にしない。
  畳んだ文字列はその対象を初めて探すときに作って持つ（本文や zip の中身は使うまで作らない・`SearchHaystack`）。
- **オプション**（検索欄の右の「オプション」）：大文字と小文字を区別する（既定オフ）・全角と半角を区別する（既定オフ）・ひらがなとカタカナを区別する（既定オン）。
  既定の組み合わせ（とカタカナをひらがなに寄せるだけ）は前もって畳んだ文字列で速く比べ、それ以外は元の文字列を日本語の比べ方（`CompareInfo`）で照らす。
- **別表記でも検索**（既定オフ）：中の5つをそれぞれ切り替える——ローマ字変換（tori → とり・トリ）・漢字変換（とり → 鳥。ローマ字から直した読みにも効く）・英日変換（shark → サメ）・
  日英変換（リボン → ribbon）・造語変換（商品名を漢字1字ごとの音訓で読む・撫で音 → なでおと）。同梱の JMdict（読み→表記・英語→表記・読み→英語）と KANJIDIC2。
  - **0件でも自動では広げない**（ユーザ判断 2026-09-16：切っているのに広げると切っている意味が無い）。0件の所に「別表記でも検索する」ボタン。
  - 日英変換の英語は**英単語の区切りで当てる**（top が stop に当たらない。関係のある当たりの目安 32% → 64%・`docs/history/search-redesign.md` §4）。
  - 式の木を `Or(Term, 別表記…)` に組み替える（`-無料` などの意味を壊さない・前置きは別表記にも当てる）。打ち直したら広げた式を捨てる。
  - **何で当たったかを必ず出す**（「『tori』を とり・トリ・鳥 としても探しました」）。1文字のかなは候補にしない。漢字を含む語には架けない。
  - 辞書は無改変で同梱し、索引は初回に手元で組む（CC BY-SA 4.0 の継承条項に触れる配布物を作らない）。出典は設定画面に。
- 類義語（Sudachi 同義語辞書・日本語 WordNet）は**入れない推し**（足した分の4件に3件が関係の無い物だった）。

## 結果

- 並べ替えは単一値の欄だけ（名前・入手日・払った額・容量・公開日・スキ数・最近など）。値が無い商品は後ろにまとめる（`ItemOrder`）。
- カード：1枚目の絵（マウスの横位置で切り替え・止まったときだけ150ms）、下段に容量と所持・状態のチップ（所持／未編集／ファイルが見つからない）。未所持は左下に「未所持」の襷。お気に入りの星は下の真ん中。
- **カードとリストを切り替えられる**（ユーザ指示 2026-09-14）。切り替えは一覧の右下に重ねて置く。どちらで出すかは画面ごとに `ui-state.json` の `itemListScreens` に覚える。
  - リストの1行：選ぶチェック・小さな絵（乗せると大きな絵）・星・名前・ショップ・札（見つからない・取り込み中・未編集・所持／未所持）。押す・右クリック・中クリック・星はカードと同じ。
  - 列の幅は見出しの境目をドラッグで変え、全部の行で共通（`docs/spec/ui-rules.md`「商品のリストの列」）。
  - カードとリストの見た目と操作は1か所（`Views/ItemCardResources.xaml`・`IItemCardHost`）にあり、フォルダビューの右側も同じ物を使う。
- カードの大きさは設定の「サムネイルの大きさ（小・中・大）」で変わり、その場で列を割り直す（ユーザ判断 2026-09-15。前は保存されるだけだった・R2）。
  大きさは `CardMetrics` の1か所：中が前からの大きさ（幅228・絵の高さ200・絵を読む長辺240）、小（180・150・190）と大（300・270・320）は**仮の値**で、ユーザが触って決め直す。
  文字の欄の高さ（136）は変えない。ショップ画面・改変の使ったものも同じカード（`ItemCardResources.xaml`）を使う。
- カードは白い枠だけ先に並べ、中身を4枚ずつ作る（`DeferredCardHost`）。サムネイルの保持は画素で132MBまで（`docs/research/memory-budget.md`）。
- 右クリック：BOOTHで開く／ショップを開く／編集に入る／エクスプローラで開く／非表示にする。中クリックは BOOTH を開く近道。
- 複数選択：まとめて編集・お気に入り・改変に足す・Unityへ順に送る。
- 検索の状態（条件・並び・スクロール・選択）はセッション中保持し、戻ったら復元する。終了後は復元しない。
- 取り込み中に増えた物は「n 件増えました（押すと反映）」。押すまで一覧を動かさない。
- 非表示・R-18（設定で出さない）は検索から外す。非表示中の件数は既定で出さない。
