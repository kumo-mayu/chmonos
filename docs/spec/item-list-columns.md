# 商品のリストの列（今の決め事）

> **要点**：検索・ショップの中・フォルダビューの右の欄で、商品をリストで出すときの列。出す列と並びは画面ごとに選んで覚え、幅は見出しの境目で変える。
>
> **コード**：`App/ViewModels/ItemListColumnCatalog.cs`（列の一覧・既定・覚えた並びの読み直し）・`ItemListColumns.cs`（画面ごとの並び・幅）・`ItemListRow.cs`（文字の列の値）・
> `Controls/ItemListColumnsView.cs`（GridView を組む・右クリックのメニュー・ドラッグの並べ替え）・`Services/PaneWidths.cs`（覚える所）・`Views/ItemCardResources.xaml`（絵・星・名前などの型の列）
>
> **経緯**：`docs/feedback/open.md`「検索：リスト表示で出す列を自分で選ぶ」（ユーザ判断 2026-11-20）。前は列を XAML の GridView 2つで決め打ちしていた（`SearchItemListGridView`・`ItemListGridView`）

## 出す列を選ぶ（ユーザ判断 2026-11-20）

- 置くのは**検索・ショップの中・フォルダビューの右の欄**のリスト。**画面ごとに別々**に選び、覚える。改変の「使ったもの」のリストは今の列のまま（選べない）。
- **見出しの右クリック**で「表示する列」のメニュー（ID `ItemListColumnsMenu`）。中は検索の「条件を追加」と同じ見出しで分けた4つのサブメニュー：
  BOOTHの情報・商品の情報・ファイルの情報・改変登録（見出しは `SearchModuleCatalog` の定数をそのまま使う。項目の ID は `ItemListColumn.<列>`）。
  - 項目はチェックの付く行。押すと出し入れし、メニューは閉じない（続けて何列も選べる）。
  - **出した列は右クリックした見出しの列の右**に入る。続けて出すと、出した列の右へ順に並ぶ。見出しの無い右の余白で開いたときは右端。
  - **最後の1列は外せない**（押せず、吹き出し「ほかの列を表示すると外せます。」）。名前も外せる。
  - 選ぶチェックの列（`select`）はメニューに出さない。まとめて操作できる画面の左端にいつも置く。
- **見出しをドラッグして並べ替える**（GridView の `AllowsColumnReorder`）。並べ替えた順を覚える。選ぶチェックの列を動かしても左端に戻る。
- 最初に出す列は前のまま：
  - 検索：選ぶ・絵・星・名前・ユーザータグ・属性・払った額・対応・ショップ・状態
  - フォルダビューの右：選ぶ・絵・星・名前・ショップ（見出しは「ショップ・場所」）・状態
  - ショップの中：選ぶ・絵・星・名前・入手日・状態（前はショップの列の場所に入手日を出していた。今は別の列 `acquired` で、ショップの列も選べる）
- 覚える所は **`ui-state.json` の `itemListColumns`**（画面 → 左からの列の名前）。
  画面の見た目の状態なので ui-state（`architecture.md`・`data-model.md`。同じ画面のカード／リスト `itemListScreens` と列の幅 `paneWidths` もここ）。
  書き込みは `UiCommand.ChangeUiState` で、書くときのファイルの値に足す（ほかの画面の並びを手元の控えで潰さない）。足した欄なので形式の版は上げない（`data-format.md`）。
  読むときは知らない名前・重なり・欠けを飛ばし、何も残らなければ既定（`ItemListColumnCatalog.Normalize`）。設定画面の「すべて元の幅に戻す」は幅だけ戻し、選んだ列は残す。

## 値の作り方と重さ

- 文字の列は1つの型（`ItemListColumnsView.TextTemplate`。区切りの線・`Caption` の字・切れたら「…」・数は右寄せ）を列ごとに1つ作って使い回す。
- 値は**カード1枚ごとに1回だけ**作る（`ItemCardViewModel.ListRow`。列が初めて読んだときに作り、控える）。行が出入りするたびに記録を読み直さない。
  改変の数は改変の見張り（`UsedItemsWatch`）の答えから引き、答えが替わったら作り直す（検索の画面は描いている行に知らせる）。
- 出さない列は列ごと外す（幅0で残すと中身を作り続ける。前に選ぶ列のチェックがはみ出した）。

## 列の幅

- 見出しの境目をドラッグで変え、全部の行で共通（ユーザ指示 2026-09-14）。画面ごと（`search`・`folder`・`shop`）に `paneWidths` へ `"{画面}.col.{列}"` で覚える（「すべて元の幅に戻す」で戻る）。範囲は `PaneWidths.All`（列の一覧の既定・最小・最大から作る。前からある列は前の値のまま）。

| 列 | 検索の既定 | フォルダビュー・ショップの既定 | 最小 | 最大 |
|---|---|---|---|---|
| 選ぶ（`select`） | 36 | 36 | 28 | 60 |
| 絵（`icon`）。**画面ごとに覚えない**：一覧の右下のスライダー（行の高さ・全画面で共有）で決まり、列の幅は絵＋16。境目をドラッグすると行の高さが変わる（2026-09-29・`search.md`「結果」） | 56 | 56 | 44 | 120 |
| 星（`fav`） | 36 | 36 | 28 | 60 |
| 名前（`name`）。検索は 2026-10-04 に 460 から詰めた | 280 | 420 | 160 | 1000 |
| ユーザータグ（`tags`）・属性（`attrs`）・払った額（`paid`）・対応（`avatars`） | 160・160・76・56 | 同じ | 80・80・56・44 | 500・500・160・120 |
| ショップ（`shop`。フォルダビューは「ショップ・場所」） | 200 | 260（フォルダ）・200（ショップ） | 80 | 500／600 |
| 入手日（`acquired`） | 120 | 200（ショップ。前の入手日の列の幅） | 70・80 | 600 |
| 状態（`chips`） | 220 | 220 | 100 | 420 |
| ほかの文字の列 | 列の一覧の値（`ItemListColumnCatalog.All`） | 同じ | | |

- 改変の詳細の「使ったもの」（`modification`・ユーザ指示 2026-09-14）も同じ部品の列：順・絵（56）・星（36）・名前（**残りの幅を全部**。最小 160・覚えない。2行目に使ったファイル。切れた分はツールチップ）・操作（右端 216：▲▼・Unity ▾・外す）。
  左の列の中（既定で 500px ほど）に横に送らずに収まるよう、使ったファイルは列にせず名前の下に置く（列にすると右端の操作が画面の外に押し出された）。
