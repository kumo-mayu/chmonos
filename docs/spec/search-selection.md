# 選択の帯（今の決め事）

> 検索・フォルダの右側・ショップの中で商品を選んだときに、画面の下に出る帯。3つの画面で同じ部品（`ItemCardResources.xaml` の `ItemSelectionBar`）と同じ中身（`ViewModels/SelectionBulkActions`。画面ごとに `Bulk`）。
> 選び方（クリック・キー）は [search.md](search.md)「複数選択」。

## 並び（ユーザ判断 2026-11-20）

左から：すべて選択・選択を解除｜お気に入り ▾｜タグ・属性 ▾｜改変に追加…｜全てUnityへ送る…｜その他 ▾｜まとめて編集する。

- 前は「既読にする」「プラグイン ▾」「ファイルを割り振る」をボタンで並べ、出し入れで帯の長さが変わった。たまにしか使わない物は「その他 ▾」へ移した
- **使えない物は消さずに押せなくする**（出し入れでほかのボタンが動かない。右クリックのメニューと同じ作法）
- 「▾」のボタンは押すとメニューを開く（↓キーでも開く。`Controls/MenuButton`）
- **入り切らないときは右から「その他」へ畳む**（`Views/SelectionBarFold`）：「全てUnityへ送る…」→「改変に追加…」の順。畳んだ物は「その他」の先頭に出す。
  幅は描いた大きさで決める（文字の大きさ・表示の倍率で変わる）。窓 1280・絞り込みの欄を開いた形では「全てUnityへ送る…」だけを畳む。2つ畳んでも入らない幅（窓 900）は、今までどおり段を送って折り返す（`SplitRowPanel`）
- 「お気に入り ▾」「タグ・属性 ▾」はそれ自体がメニューなので畳まない（「その他」の中で3段になる）。「まとめて編集する」は帯の主の操作なので畳まない

## お気に入り ▾・タグ・属性 ▾

- お気に入り：「お気に入りに追加」「お気に入りから外す」。反転は無い
- タグ：「タグを追加…」で窓を開き、大分類と小分類を候補付きの欄（`SuggestBox`）で選ぶ。候補に無い語は「（新規）」で、選んだらタグの一覧にも足す（`UiCommand.AddUserTag`）。足すのは確かめない
- 「タグ・属性を削除…」の窓はタグか属性かを選び、**候補は選んだ商品に付いている物だけ**（付いている件数の多い順）。外す前に件数を出して1回だけ確かめる。属性は「外した属性の値は元に戻せません」も言う
- 「属性を追加…」は**値を付けずに**足す（付いているが値はまだ。ユーザ判断 2026-11-20 の (a)・[data-model.md](data-model.md)「属性」）。窓はタグの追加と同じ作りで、スライダーは出さない（同じ値で埋めると、付けただけか評価したかが分からなくなる）。候補は属性の一覧で、無い語は属性の一覧にも足す（`UiCommand.AddAttribute`）。値がある（0% も）・値はまだの商品は何もせず数える。外す候補には値はまだの物も出る
- **既に付いている物に足す・付いていない物から外すのは何もせず、後で件数を出す**：「5 件に追加しました（2 件は既に付いていました）。」を帯の左に出す。記録から消えていた物も数える

## その他 ▾

上から：（畳んだボタン）／見つからないファイルを探す…（n 件）／ファイルを割り振る／既読にする／プラグイン ▸／非表示にする・表示に戻す／更新の通知を入れる・切る／IDをコピー・リンクをコピー／BOOTHの情報を取得し直す…・対応アバターを確認済みにする。

- 見つからないファイルを探す：選んだ物のうち見つからないファイルを持つ商品の数を出し、**その商品の分だけ**を探す（商品ページの「探す…」と同じ `MissingSearchFlow`。[missing-search.md](missing-search.md)）。結果は窓で言う（探し終えると一覧を読み直し、帯ごと選択が外れるため）
- ファイルを割り振る：2件以上のとき（[file-pool.md](file-pool.md)）。既読にする：未読の更新がある商品があるとき（`MarkNotificationsRead` を1回）
- プラグイン ▸：許したソフトが帯に項目を宣言したときだけ出す（[plugins-menu.md](plugins-menu.md)）
- コピー：改行でつなぐ。リンクは BOOTH に無い商品を飛ばす
- BOOTHの情報を取得し直す：件数と目安の時間（1件約3秒：JSON と HTML の2回で、それぞれ 1.5 秒の門を待つ）を出して確かめ、**1件ずつ** `UiCommand.RefreshItem` で取る（門は `BoothClient` のまま。並べない）。帯に進み具合と「中止」。BOOTH に無い商品は取らない
- 対応アバターを確認済みにする：確認待ちの対応アバターを確認済みにする。外した物は触らない
- 「BOOTHで開く」「記録から削除」は置かない（ユーザ判断 2026-11-20）

## 書き方

- 書き込みは `UiCommand.ChangeItems`（`Core/Services/BulkItemChange`）1本。商品ごとに `ChangeLocalAsync` で**今の値に当てる**（カードの写しが古くても、ほかの欄・ほかのタグを消さない）。名指しの欄だけを書く
- 変わらない商品は書かない（`WriteIfChangedAsync`）。書いた後に記録を読み直してカードに映し、選択は残す（非表示にした物は一覧と選択から外す）
- 試験：`SelectionBarBulkTests`（App）・`BulkItemChangeTests`（Core）
