# 画面の用語表：使わない語・揃える表記（今の決め事）

> **要点**：画面に出さない語と、2通りに書かないための揃える表記の表。使う語・同じ操作の動詞・決めた呼び方は [ui-terms.md](ui-terms.md)（用語表の入口）。
> この表に無い語を画面に入れるときは、先に [ui-terms.md](ui-terms.md) かこの表に書き足す。
>
> **道具**：`tools/wording.mjs` がこのファイルの「使わない語」「揃える表記」「まだ決めていない揺れ」の3つの表を読んで印を付ける。表の列の並びを変えるときは道具も直す（探す形は JavaScript の正規表現。表の中の `|` は `\|` と書く）。

## 使わない語

ユーザ判断 2026-09-24 の方針（普通の Windows のソフトで見る語）で決めた。`tools/wording.mjs` は「探す形」に当たった文に「使わない語」の印を付ける。
意味が違う使い方にも当たることがある（「こちらを選びます」の「こちら」は選択肢を指す）。印は見直しのきっかけで、直すかは文を読んで決める。

| 使わない語 | 使う語 | 探す形 |

## 揃える表記

同じものを2通りに書かない。左に揃える。

| 使う表記 | 揃える前 | 探す形 |
|---|---|---|
| ユーザータグ | ユーザタグ | `ユーザタグ` |
| 監視フォルダ | 監視対象（ユーザ判断 2026-11-13「監視フォルダに合わせましょう」。開いている間の監視の帯・設定と、取り込み画面の見出しで揺れていた） | `監視対象` |
| （押さずに保存する欄の案内）打ち終えると保存されます | 打ち終えると残ります・押さなくても残ります | `(打ち終えると\|押さなくても)残ります` |
| すべて | 全部・全て | `全部\|全て` |
| ユーザータグ（自分で付ける語） | 分類 | `(?<![大小H]\|BOOTHの)分類` |
| {n} 件（数と単位の間に空白） | {n}件 | `\}件` |
| …（三点リーダー） | ... | `\.\.\.` |
| 英字と日本語の間に空白を入れない（「BOOTHで開く」「Unityへ送る」「Unity側」） | 「BOOTH で」「の Unity」 | `[A-Za-z] [ぁ-んァ-ヶ一-龠]` `[ぁ-んァ-ヶ一-龠] [A-Za-z]` |
| カタカナ語の最後の長音を付けない（フォルダ・エクスプローラ・カテゴリ） | フォルダー・エクスプローラー・カテゴリー | `フォルダー\|エクスプローラー\|カテゴリー` |
| 選ぶ窓の選択肢は、名前と説明を別の行に分ける | 「……」「：」で区切って1行に書く | `……` ` ：` |

BOOTH のカテゴリは、編集画面の欄も検索の絞り込み・並べ替えと同じ「カテゴリ」と呼ぶ（前は編集画面だけ「BOOTH分類名」で、同じ物に2つの名前が付いていた。ユーザ判断 2026-09-24）。
「分類」は統計の「分類なし」のように別の意味でも残っているので、印が付いても読んで決める。

空白を入れるのは、数と単位の間（「{n} 件」「1500 ミリ秒」）だけ。英字と日本語の間には入れない（ユーザ判断 2026-09-24）。
カタカナ語の最後の長音は付けない。今の画面はこの形で揃っている（ユーザの好み。Windows 11 は付けるが合わせない。ユーザ判断 2026-09-24）。
選択肢の名前と説明を「……」や「：」でつながず、説明は名前の下の行に書く（ユーザ判断 2026-09-24）。
「失敗」と「エラー」は今の使い分けのまま（「〜に失敗しました」「予期しないエラー」）。「商品情報を取り直す」も今のまま（ユーザ判断 2026-09-24）。

## まだ決めていない揺れ

標準を決めていない揺れを置く。道具は両方の数を数えるだけで、印は付けない。決めたら「揃える表記」へ移す。
今は無い（2026-09-24 に、英字と日本語の間の空白・Unity側・選択肢の区切り・カタカナ語の長音を決めて移した）。
