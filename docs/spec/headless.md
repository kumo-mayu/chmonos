# 画面を出さずに動かす（今の決め事）

> **要点**：`Chmonos.exe --headless` で、窓を出さずに核（Core のサービス一式）だけを動かす。動いていることは通知領域のアイコンで見せ、
> 右クリックで「Chmonosを開く」「終了」。起動したときの作業・取り込み・登録の列は、画面ありと同じ係を通す。
>
> **経緯と段取り**：`docs/history/headless-core-2026-10-13.md`（最小の起動単位を「核＋API」にする。API を同じプロセスで動かすのは段2で、まだ）。
>
> **コード**：`App.xaml.cs`（`StartHeadless`・`OpenFromTray`・`ExitFromTray`）、`Services/TrayIcon.cs`・`StartupWork.cs`・`ImportRunner.cs`、`AppServiceContainer.Registrations`

## 起動

- 既定は画面あり。`--headless` を付けたときだけ窓を出さない（ダブルクリックの操作は変えない）
- 起動の順と守りは画面ありと同じ：保存先の確かめ → 初回の窓 → 形式の版 → 多重起動の錠 → 組み立て。`StoreLocation.AllowsUserStore`（2026-09-30 の事故の守り）も同じ
- 起動できないときは知らせの窓を1つ出して終える。使う人の答えで状態が変わる問いは出さない：
  - 保存先が決まっていない（初回の窓を通っていない）→「一度ふつうに起動して、データの保存先を決めてください」（勝手に作らない）
  - 設定した保存先が見つからない → 「既定の場所で開きますか」を聞かずに終える（保存先を勝手に替えない）
- 同じ保存先で既に動いていれば、窓を出さずに黙って終える（ログオン時などに二重に起動されても邪魔をしない）。
  画面ありの起動は今までどおり「既に起動しています」（動いている方に窓を開かせる頼み方は段4）

## 動いている間

- 起動したときの作業（`StartupWork`）：画面ありと同じ設定に従う（裏の取得・通信しない確かめ・見回り・控えの片付け）。**プロセスで1回だけ**始める
- 前の起動で終わらなかった「このIDで登録」の続きを流す（人が押した物なので）。登録の列はプロセスに1つ（`AppServiceContainer.Registrations`）
- 新しい版の確認はしない（知らせを出す場所が無い）。窓を開いたときに回す
- 自動の取り込み：API の設定 `importOnHeadlessLaunch`（設定の「API」の節。既定はオフ）。対象の決め方（監視フォルダの新着と前回の続き）と取り込みの道（`ImportRunner`）は、
  画面ありの「起動したとき…取り込む」と同じ。押してもいないので、展開先のファイルについて尋ねない（G2）

## 窓を開く・閉じる・終える

- 「Chmonosを開く」（アイコンのダブルクリックも同じ）：主画面は1回だけ作り、閉じたら**隠して取っておく**（主画面はアプリの間1つの前提で作られていて、作り直すと知らせを二重に受ける）。
  閉じるときは待っている保存を書き、窓の位置を覚える。書きかけも登録の列も残る
- 窓を後から開いても、起動したときの作業と自動の取り込みは走らせ直さない（監視フォルダの新着は見て知らせる）
- 「終了」：窓を開いていれば、窓を閉じるときと同じこと（終わっていない登録・書きかけ）を確かめてから終える。書きかけを尋ねる前に窓を出す
  （「移動する」が編集画面を開くため）。窓を開いていなければ、終わっていない登録だけ聞く
- 通知領域のアイコンは Windows の機能を直に呼ぶ（WinForms の部品は WPF と型の名前がぶつかる）。エクスプローラが作り直されたら出し直す

## 係（画面に依存しない）

| 係 | 受け持ち | 画面へ返す物 |
|---|---|---|
| `StartupWork` | 起動したときの作業（③検出し直し・通信しない確かめ・⑤・アバターの画像・⑦・見回り・控えの片付け・読めない記録・止まった操作の続き） | 進み具合・段の終わり・読み直し・件数・見回りで書いた商品 |
| `ImportRunner` | 取り込みを1本だけ走らせる・積む・立ち上げ中の頼みを後で積む・履歴・中断・起動したときの対象の決め方 | 始まった・進んだ・終わった（終わりは画面が済ませるのを待つ）・履歴を書いた |
| `RegistrationQueue`（一式が持つ） | 「このIDで登録」の列 | 登録できた商品（主画面が差し込む）・受け止められなかった終わり |

知らせは裏のスレッドから来ることがある。受ける側が画面のスレッドへ渡す。画面が無ければ誰も受けない。
