# 入力の決め事

画面全体の決め事は [ui-rules.md](ui-rules.md)、別の窓は [ui-dialogs.md](ui-dialogs.md)、
空のとき・失敗したとき・押せないときは [ui-empty-and-errors.md](ui-empty-and-errors.md)。

## 候補と札

- 入力欄には候補を付ける（`SuggestBox`）。候補に無い語は「新しく足す」と明示して選ばせる（表記揺れで名前でつないだ絞り込みが割れる）。
- **候補を全部並べて選ばせる画面は作らない**。候補付きの入力欄から1件ずつ積むか、畳めるようにする。
- 多い札（対応アバター・BOOTHのタグ）は50件までは全部、超えたら40件と「残り n を表示」。作った札は捨てずに隠す（`ChipStrip`：差し替えると全部作り直すため）。20体を超えたら「アバター名で絞る」欄。
- 探す語はひらがな・カタカナ／全角・半角／大文字小文字を区別しない。

## 決め方と保存

- **Enter は入力の確定**（ユーザ判断 2026-09-20・I12）。1行の入力欄は、横のボタンと同じことが Enter で起きる
  （呼び方を足す・素体の商品を設定・改変を作る・未確定は「このIDで確認」まで）。
  **取り返しのつかない確定は Enter で走らせない**（未確定の「このIDで確定する」は押して決める）。
- 名前を変えるのは**欄の中**（Enter か「名前を保存」。変えたときだけボタンを出す）。OS の入力窓は使わない（B10：共通素体だけ残っていた）。
- **メモはどこでも押さずに残る**（I9）。商品のメモは商品ページでも書ける
  （編集画面の中に入れているときは、右の欄と二重にしないので出さない）。
- **保存のしかたが画面の中で分かれるときは、画面に書く。**編集画面の左（画像・星など）は押した時点で保存し、右は「保存して次へ」で保存する。
  この形のままにすると決めたので（ユーザ判断 2026-09-20・B7）、左の列の頭に「この列は押した時点で保存されます。右の欄は「保存して次へ」で保存します。」と出す。
