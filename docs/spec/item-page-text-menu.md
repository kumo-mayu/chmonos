# 商品ページの説明文の右クリック（今の決め事）

> **要点**：説明文・メモの右クリックに、リンクを開く・コピーする・リンクの商品を登録する（手元にあれば開く）と、選んだ範囲の文をコピーする・その中の商品をまとめて登録する、を並べる。
> 登録は貼り付けのまとめての登録（計画 26・[ui-rules.md](ui-rules.md)「ドロップと貼り付け」注3）と同じ一覧の窓と同じ道を通す。
>
> **コード**：`App/Controls/TextMenu.cs`（`TextMenuPlan` が並びを決め、`TextMenu` が組む）・`SelectableText`（付ける所）・`ItemViewModel`（`ITextMenuHost`）・
> `MainViewModel.PastedItems.cs`（`ChooseFoundItemsToRegisterAsync`）。試験は `App.Tests/TextMenuTests.cs`
>
> **経緯**：計画 29（ユーザ案 2026-11-11「セット商品から登録に進みやすいように、商品画面でテキストとして選択した範囲のリンクの商品をファイルの無い商品として登録する機能を右クリックに」）

## 付ける所

- URL をリンクにする本文だけ（`SelectableText` の `PlainText` でない物）：商品ページの見出しの無い説明文・見出しごとの本文・メモ。
  組み込んだ商品ページ（フォルダビュー・改変の画面）も同じ部品なので出る。
- 編集画面の「商品説明」にも付ける。相手は編集画面の中の商品ページ（`SelectableText.MenuHost`）。左クリックの行き先（`Navigator`）は結ばず、今までどおりすべてブラウザで開く。
- 名前・パスなど `PlainText` の短い字は、RichTextBox の既定のメニュー（コピー）のまま。

## 並び

区切りで3つの群に分ける。商品のカードの右クリックと同じく、外へ出る物を先に、アプリの中の物を後に置く。

| 群 | 項目 | 押せないとき・吹き出し |
|---|---|---|
| リンク（リンクの上で開いたときだけ） | 「BOOTHで開く」（`booth.pm`・`*.booth.pm`）／「ブラウザで開く」（それ以外） | 吹き出し「このリンクをブラウザで開きます。アプリの外へ出ます。」 |
| | 「リンクをコピー」 | |
| リンクの商品 | ライブラリにある商品：「商品ページを開く」 | |
| | ない商品：「商品として登録…」 | BOOTH の商品ページの URL でなければ灰色。「BOOTHの商品のリンクだけ登録できます。」 |
| 選んだ文（いつも出す） | 「コピー」 | 選んでいなければ灰色。「文字を選ぶとコピーできます。」 |
| | 「選んだ範囲の商品をまとめて登録…」 | 押せるとき「n 件の商品が見つかりました。」。商品が無ければ灰色で「BOOTHの商品のリンクを含めて選ぶと登録できます。」 |

- リンクの上でないときはリンクの2群を出さない（どのリンクの話か分からない）。項目を出し入れするので、区切りが先頭・末尾・続けて出ないことを試験で押さえる。
- 「商品として登録」の可否は、26 と同じ線（`BoothUrlExtractor.TryExtractItemPageId`：商品ページの URL だけ。ショップ・画像・配布の置き場は外す）。
  左クリックでアプリ内へ送るかは今までどおり `TryExtractItemId` で見ている。
- ライブラリにある商品のリンクは、灰色にせず「商品ページを開く」にする（登録しても何も変わらない。左クリックでも開くが、右クリックで登録を探した人に、もうあることを名前で言う）。
- 「…」は一覧の窓が開いて選び直せるので付ける（[ui-dialogs.md](ui-dialogs.md)「…」の付け方）。
- キーボード（Shift+F10）で開いたときは、選んだ範囲の頭がリンクの中ならリンクの群を出す。

## 選んだ範囲から拾う物

- 範囲を欠片に分け、**範囲が掛かったリンクは URL の全体**、リンクでない字は選んだ所だけにして、26 の `PastedItemIds.Collect` で拾う（出てきた順・重ねない）。
  範囲の端が URL の途中で切れたとき、見えている字のまま拾うと、別の番号の商品を登録してしまう（登録は取り消せない）。
- 「コピー」は選んだ字そのまま。クリップボードは `ClipboardText`（OLE を通さない）。

## 登録

- 選んだ範囲も、リンク1つの「商品として登録…」も、件数に依らず 26 の一覧の窓を通す（`RegisterPastedItemsDialogViewModel`）。
  手元にある商品はチェックを外して並べる。押す前に、通信が起きることと取り消せないことを窓が言う。
- 1件のときは、窓の名前を「商品を登録」、見出しを「この商品を登録します。」、手元にある1件は「この商品は、ライブラリにあります。」（「すべて」「選んでください」は1件では浮く）。
  貼り付け・ドロップの1件は今までどおり窓を通さず「登録しますか」と聞く（右クリックは押す前に「登録」を選んでいるので、聞き返しは何が起きるかを言う窓1つでよい）。
- 登録は `UiCommand.RegisterItem` を1件ずつ待って流す（門は1本ずつ・人が押した優先度は命令の入口）。帯・中止・済んだ知らせ・失敗の窓は 26 と同じ。
  失敗の窓の「取得できなかった商品」の次の手は、出どころに依らない「もう一度お試しください」にした（前は「もう一度貼り付けてください」）。

## 確かめていない事

- 実際の右クリック（読み取り専用の RichTextBox で、範囲の外を右クリックしたときに選択が残るか・リンクの上の判定）。メニューは別の窓に出るので撮れない。
