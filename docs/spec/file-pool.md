# ファイルの割り振り（今の決め事）

> **要点**：検索・フォルダ・ショップで2件以上の商品を選び、帯の「ファイルを割り振る」でサブ画面を開く。左は選んだ商品、右は選んだ商品に付いているファイルの溜まり。
> 左で付ける先を選び、右でチェックを入れて「付ける」。付けても元の商品からは外さない（共有）。外すのは左の商品の下のファイルの行から。
>
> **コード**：`Core/Services/FilePool.cs`・`FilePoolGroups.cs`・`UiCommand.AttachRecordedFile`、`App/ViewModels/FilePoolViewModel.cs`・`FilePoolRows.cs`、`App/Views/FilePoolWindow.xaml`
>
> **経緯**：plan 30（ユーザ案・判断 2026-11-11）。セット商品のファイルを中身の各商品にも付ける（[shared-files.md](shared-files.md)）のを、商品ページを1件ずつ開かずにまとめて行う。窓の決め事は [ui-subwindows.md](ui-subwindows.md)。

## 入口

- 選んだ帯（`ItemSelectionBar`。検索・フォルダの右・ショップの中で同じ型）の「ファイルを割り振る」。3つの画面とも置く（型が1つなので、どこから押しても同じ物が開く。片方だけにすると押しても何も起きないボタンが出る）。
- 1件だけ選んでいるときは押せず、吹き出しで「2件以上の商品を選ぶと使えます。」。開いても選択は外さない。

## 溜まりと重複回数

- 溜まりは `FilePool.Of(選んだ商品)`：持っている（外していない・古い版でない）ファイルを中身ごとに1行。**重複回数は選んだ商品の中で数える**（ユーザ判断 2026-11-11）。行の下に「n 件に付いています」、吹き出しに付いている商品の名前。
- **選んだ商品の最後の1件から外した物は 0 件で残す**：窓を開いてから溜まりに出た物だけ（開く前に外してあった物は出さない。割り振る物が埋もれる）。行は「どの商品にも付いていません」で、別の商品へ付け直せる（写す元は最後に持っていた商品の外した行）。写す元の商品が一覧から消えたら落とす。
- 絞り：「付いている商品の数が [n] [以下・以上・のみ] のファイルを表示」。既定は「1 以下」（ユーザ判断「基本は n 以下を表示」。割り振っていない物＝1件だけが持つ物が残る）。n は 0 から選んだ商品の数まで。
  右上に「n 個」（全部出ているとき）か「n 個のうち m 個を表示」。何も無いときは「選んだ商品に付いているファイルはありません。」、絞りで全部隠れたら「条件に合うファイルはありません。付いている商品の数を変えてください。」

## 組（名前の頭で畳む）

- ファイル名の頭から区切りの最初の1つまでを組の名前にする（`FilePoolGroups.GroupName`。大文字小文字は区別せずにまとめる）。
  区切り：`_`・`-`・半角と全角の空白・`.`・括弧（`(`・`（`・`[`・`【`・`「` と閉じ）・版の印（v1.0・Ver1.2・ver.）の前。前が英字の「ver」は切らない。頭の区切り・括弧は飛ばす。英字だけが続く名前は大文字小文字の切れ目で切らない。
- **測った結果**（2026-11-11）：手元の確かめ用のダウンロードの zip 31 本と中の unitypackage 43 本で、区切りの候補を全部入れても `_` だけでも組は同じだった（31本→18組・うち1本だけの組13、43本→19組・うち12）。名前のほとんどが「作者や素体の名前_種類_版」の形で、`_` が先に来る。
  大文字小文字の切れ目でも切ると組が減り（18→16・19→17）、別の作者の物どうしが1つにまとまった。ほかの区切りは作り物の名前（`FilePoolGroupsTests`）で決めた。外れても組が細かくなるだけで、付け外しには響かない。
- 2つ以上の組は三角で畳む（既定は畳む）。見出しは「名前（数）」と組のチェック（全部・一部は中間・無し）、下に「unitypackage：A、B、C ほか n 個」（中の一覧と、それ自体が unitypackage の物。3つまで）。1つだけの組は見出しを出さずにファイルの行だけ。
- 場所の記録が無いファイルは「場所の記録が無いファイル」の組として最後。
- 「すべて広げる」「すべて畳む」「選択を解除」（チェックを外す）。チェックと開いた組は、読み直し・絞りの変更でも残す。

## 付ける・外す

- 左の商品を押すと付ける先に選び（薄い青）、その商品の下に付いているファイルと赤い「外す」を並べる。同時に**メインの画面がその商品ページを開く**（人が開くのと同じ道・画面の履歴に積む。ユーザ指示「ページ遷移の履歴に登録する形」）。
- 付ける先が持っているファイルは「この商品に付いています」で、チェックできない。
- 「n 個を付ける」（青）：窓は出さずに `UiCommand.AttachRecordedFile(付ける先, ハッシュ, 写す元, Share)`。ファイルは読まない（見つからないファイルも付き、大きい zip を読み直さない）。
  左に押せない理由（「左の一覧で、付ける先の商品を選んでください。」「付けるファイルにチェックを入れてください。」）か「付ける先：（名前）」。結果はその下の1行（「n 個のファイルを「（名前）」に付けました。」）。
  除外している物は解かずに付けず、「「（名前）」は管理対象から除外しているので、付けませんでした。」（解くかは商品ページで人が決める）。
- 「外す」：`UiCommand.DetachFile`（商品は消さない。商品ページの「非表示にして残す」などは聞かない）。ほかの商品（選んでいない商品も含めて）にも付いていれば聞かずに外す（この画面で付け直せる）。
  どの商品にも付かなくなるときだけ確認の窓：「「（ファイル）」を「（商品）」から外しますか？」「どの商品にも付いていない状態になります。ファイルが手元にあれば未確定に表示されます。この画面でほかの商品に付け直せます。」（既定はキャンセル）。
