## データが消える・取り返せない（高）

- **商品IDを付け替えると、自分で足した画像・お気に入り・画像の役割・サムネイルの指定が黙って消え、画像ファイルも消えていた**（合わせる処理が引き継がず、元の画像フォルダを消していた）
- **引越しなどが済んだ後も古い保存先へ書き続け、次の起動で消えていた**（上の判断）
- 引越しの門が、既に走っている書き込みを待たなかった
- 読んでいる最中の JSON に保存すると、置き換えが共有違反で失敗していた（取り込み中は約10秒おきに全件を読むので偶然ではない）
- 編集画面で「商品情報を取り直す」を待つ間に次へ進むと、書きかけと順番が前の商品へ付け替わっていた
- 取り込み元の一覧を、取り込み画面・設定画面が古い写しで丸ごと書いていた（技術的負債 1-1 の再発）
- 同じ zip に同じ名前の unitypackage が2つあると、2つ目を送っても1つ目が入っていた
