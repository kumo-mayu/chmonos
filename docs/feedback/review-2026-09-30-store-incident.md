# 道具が友人の写しを開いて動かした件（2026-09-30）

ユーザは当日アプリを触っていない（「今日は私はアプリを触ってないですね」）。窓を出さずに描く台の担当の報告にあった
「friendtest の settings.json が 17:40:16 に変わっていた」を調べて分かった。

## 起きたこと

本番の `location.json` は友人のデータの写し（`-friendtest`）を指している。確かめの道具の作りかけの版が、保存先を切り離さずに
アプリの一式（`AppServiceContainer`・`MainViewModel`）を組み、その写しを相手に動いた。

- 17:40：起動時の取り込み（設定・取り込みの記録・未確定・走査の控え・unitypackage の控え 301 個を書いた。商品 8 件で対応アバターの検出をやり直した）
- 17:53〜18:06：期限の来た商品 19 件を BOOTH から取り直した。18:06 は1分の間に6件（道具を6本並べて走らせていたので、同時に問い合わせた恐れがある。決め事1）

## 原因の見立て

窓を出さずに描く台（`tools/ViewShot`）の作りかけの版がいちばん疑わしい（断定はできない。担当は作業用フォルダを片付けた後で、聞けなかった）。
台は「アプリの型に触れる前に環境変数 `CHMONOS_HOME` を入れる」順番に頼っていた（`AppPaths.Default` は最初に触れたときに1回だけ決まる）。
18:06 の6件同時は、場面を6本並べて描く動きと合う。完成した版は切り離せている（その後 72 回動かして、写しは変わらなかった）。
商品ページの速さ・部品の名前・画面の確かめの担当は、台本とプログラムを読んで原因でないことを確かめた。

## 被害

- 作り物の商品は混ざっていない。商品は 207 件のまま、新しく作られた商品も無い
- ファイルの記録・購入の記録は、この書き換えで減っていない
- 変わったのは取得の日時・説明文・対応アバターの検出結果（普段使いのアプリを次に起動すれば同じように変わる物）
- 友人のデータは外へ送られていない（BOOTH へ出たのは、商品の情報を取り直すいつもの問い合わせ）
- ユーザ判断：写しは戻さない

## 守り

- `StoreLocation.Resolve` は、環境変数の指定が無く、アプリ本体が立てる印（`AllowsUserStore`）も無ければ、例外で止まる（`14d9f19`）
- 試験の助け（`TestApp`）は、保存先を決めるたびに環境変数にも入れる
- 気付くのが遅れたわけ：`Test-ProductionUntouched` は `%LOCALAPPDATA%Chmonos` の `settings.json` と `items` しか見ず、`location.json` が指す先を見ていなかった。
  担当の「本番は触っていません」は、指す先を見ていない報告だった。**道具の側の直しは未**（指す先の更新日時も見るようにする）
- BOOTH への問い合わせの門を PC で1つにする直し（別の担当が作業中）が入れば、道具が何本並んでも合わせて1本ずつになる
