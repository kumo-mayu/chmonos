  - Release は最後に `dotnet build BoothAssetManager.App -c Release` をしてから使う（Debug より速い）

  写しでも、起動すると期限の来た商品の確認（⑦）が裏で問い合わせる（左下の常設の1行に「商品の更新を確認中 n/N」）

## 1. 起動とナビ

- [ ] 起動 → 検索の画面で開く。ナビの頭に「Chmonos クモノス」と商品の件数
- [ ] 「ナビを畳む」→ アイコンだけになり、左上は「←」（戻る）だけ残る。もう一度押すと開き、「←」「→」が並ぶ
- [ ] 画面を2つ3つ移ってから Alt+← かマウスの戻るボタン → 1つ前の画面へ。Alt+→ で進む
- [ ] ナビの札（未確定・要確認・編集の「未:n」）が数と合っている

## 2. 取り込み

- [ ] ナビ「取り込み」→「フォルダを選択」で1つ選ぶ（またはフォルダを窓へドロップ。ドロップはそのまま始まる設定が既定）
- [ ] 進み具合の段（1. ファイルをスキャン … 6. サムネイルを取得。取得できたものから一覧に表示されます …）と、
      「この段の残り」「編集できるまで」「画像を取り終わるまで」の見込みが出る
- [ ] 途中で「中断」→ 帯に「続きから進む」「続きを捨てる」。「続きから進む」で画面を移らずに再開する
- [ ] 終わったら「未確定を開く」「取り込んだ商品を検索で開く」
- [ ] 監視フォルダの「外す」→ 下の帯に「「…」の監視をやめました。」と［監視を再開］。押すと戻る。画面を移ると帯は消える

## 3. 未確定

- [ ] ナビ「未確定」→ 左でファイルを選ぶ
- [ ] 商品IDかURLを入れて「このIDで確認」→ 名前と絵が出る →「このIDで確定する」
- [ ] 「自動検索」→ 候補が並ぶ（BOOTH へ問い合わせるので数秒〜）
- [ ] 「この名前で登録する」（BOOTH に無い物。確認が出る）
- [ ] 「管理対象から除外する」→ 上に「外した {n} 件を戻す」で戻せる
- [ ] 右クリック・ボタンの「エクスプローラで開く」、フォルダの「元zipで登録」
- [ ] 上の「最後に確定した商品を開く」「確定したものを編集する」

## 4. 検索

- [ ] 検索欄に語を入れて絞る（`衣装 -無料`・`"夏セット"`・`衣装 (夏 OR 冬)` のような書き方も効く）
- [ ] 左の絞り込み：所持・ユーザータグ・対応アバター など。「＋ 条件を追加 ▾」で公開日・価格などを足す。「条件をクリア」
- [ ] 並べ替え（名前・払った額・公開日・BOOTHの価格・ショップ・カテゴリ など）と、カード⇔リストの切り替え
- [ ] カードを押す → 商品ページ。星でお気に入り
- [ ] カードの右クリック：BOOTHで開く／ショップを開く／リンクをコピー／編集／開く ▸／Unity ▸／非表示にする
      （非表示にすると下の帯に「…を非表示にしました。」と［非表示を解除］）
- [ ] 複数選んで下の帯：すべて選択・お気に入りに入れる・改変に追加…・Unityへ順に送る…・まとめて編集する
- [ ] 2000件の写しなら、端まで速く流してもカクつかない

## 5. 商品ページ

- [ ] 上の帯：「← 検索に戻る」（行き先の名前が入る）・「商品情報を取り直す」・「この商品を編集」・「BOOTHで開く」
- [ ] 絵：矢印で送る・下の小さな絵・「＋」で画像を追加
- [ ] 畳む印がすべて三角：BOOTHのタグ・バリエーション（右に件数）・対応アバター・商品説明・ローカルファイル。押すと畳み、もう一度で開く
- [ ] 「記録していること」の「検索から除く」：［非表示にする］→「している［非表示を解除］」に替わる。もう一度押すと戻る
- [ ] 対応アバターの札を押す → そのアバター（持っていれば商品ページ）
- [ ] ローカルファイル：「開く ▾」（エクスプローラ・一時的に展開）・「この商品から外す」（確認が出る）

## 6. 編集

- [ ] ナビ「編集」→ 上に続く商品の小さな絵の帯
- [ ] ユーザータグ・属性を入れる（候補が出る。無い語は「（新規）」）
- [ ] 購入したバリエーション：印を付ける・値段・自分用／贈った／貰った・「＋ 追加購入」。見出しで畳める（畳んでも「未選択」の札は見える）
- [ ] 入手日：空欄なら欄の中に薄い字で「空欄ならファイルの日付 …」。日付を入れると消える
- [ ] 「保存して次へ」（Ctrl+Enter）・「スキップ」（Ctrl+Shift+→）・「← 前へ」
- [ ] 「終える」→ 全部終えていれば数秒後に検索へ戻る（「ここに留まる」で止まる）
- [ ] 書きかけのまま別の画面へ → 戻ると続きから。書きかけのまま閉じると聞かれる

## 7. ショップ

- [ ] ナビ「ショップ」→ 一覧。「更新のあった商品が {n} 件」が出ているショップがある（作り物の写しなら多い）
- [ ] ショップを開く → 上に「画像を取り直す」「このショップの商品を検索で開く」「BOOTHのショップページを開く」
- [ ] 更新のあった商品のカードに「更新あり」の札 → 押すと要確認が開き、その商品の知らせまで送られる
      （送った行は一覧の下の方に出る）

## 8. フォルダ

- [ ] ナビ「フォルダ」→ 木を開いて行を押すと右に中身。ファイルの行の右クリックはカードと同じメニュー
- [ ] 右側：「このフォルダで絞り込んで検索」「このフォルダのアイテムを取り込む」（画面は移らず下の帯で進む）

## 9. 統計

- [ ] ナビ「統計」→ 支出・ショップ・分類などの節。リンクを押すとその画面・その条件の検索へ

## 10. アバター・改変

- [ ] ナビ「アバター」→ アバターの行・共通素体。「商品ページを開く」「この商品を検索で開く」
- [ ] ナビ「改変」→ 見方の3択（Unityプロジェクト／アバター／改変）。2000件の写しでも切り替えが速い
- [ ] 改変を開く：写真の追加・メモ・使ったものの「外す」（印だけ付いて「戻す」で戻る。完全に消すのは「削除」で確認が出る）
- [ ] 使ったものの「Unity ▾」→「Unityで選択」（Unity を開いていなければ「まだ開かれていません」）

## 11. タグの管理・属性の管理

- [ ] ナビ「タグの管理」→ 大分類を選ぶ → 小分類の「すべて開く」「すべて折りたたむ」、カード／リスト
- [ ] 小分類の「名前を変更」（既にある名前なら統合。大文字と小文字だけの変更も効く）・「別の大分類へ移す」・「削除」（確認が出る）
- [ ] 並べ方：名前順・件数順・手で並べた順。見出しの行をドラッグで並べ替え
- [ ] ナビ「属性の管理」→ 属性を選ぶ → 値の高い順／低い順、横に／縦に並べる、カード／リスト

## 12. 要確認

- [ ] ナビ「要確認」→ 束（商品ページの変更 など）の見出しに「重要」「未読」の札と件数
- [ ] 「未読のみ」・「この束を既読にする」・行の丸で既読／未読の切り替え・「すべて既読にする」
- [ ] 1000件の写しでもすぐ開く

## 13. 設定

- [ ] 取り込み元の「外す」→ 下の帯に「「…」を取り込み元から外しました。」と［取り込み元に戻す］
- [ ] 「非表示にした商品」の一覧から「非表示を解除」・「商品ページを開く」
- [ ] 間隔（ミリ秒）に 1000 を入れる → 「…入れられるのは 1500〜10000 ミリ秒です。1500 ミリ秒にしました。」
- [ ] 「すべて元の幅に戻す」
