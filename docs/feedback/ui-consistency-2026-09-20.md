## どこから手を付けるか（案）

1. **W1・W2・W3・W4**（語の統一）。直す量は多いが、判断は「どちらの語にするか」を決めるだけで済み、取り違えがいちばん減る。
2. **M1・D1・D2・D3**（改変のリストの右クリック、窓の Esc・Enter・ボタンの言葉）。それぞれ数行で、作法が揃う。
3. **I1・I2・I3**（黙って捨てる・起きていないことを言う）。データが静かに失われる種類なので、量の割に効く。
4. **B1・B2**（名前と行き先の食い違い、Ctrl+F の例外）。
5. **E1・E2・E7**（真っ白な画面、絞り込み0件の言い分け、Unity 送信を止められない）。
