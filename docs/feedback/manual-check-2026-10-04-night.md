## 1. 全体

- [ ] 画面の名前が「要確認」から「通知」になった（ナビ・見出し・空の文・吹き出し）。**言い方が自然か**
- [ ] 右クリックのメニュー（商品のカード・リスト・アバター・ショップ順の札・画像の欄・検索の条件の枠）で、できない操作が薄く出て、乗せると理由が出る
- [ ] 押せないチェック・ラジオの文字も薄い（検索の価格で「払った額」のときの「外れ値を無視」）

## 2. 知らせの置き場（各画面）

- [ ] 操作の結果が、押した欄・ボタン・行のすぐ下に出る（アバター・フォルダ・改変・設定・商品ページ・通知・タグと属性）。**場所が分かりやすいか**

- [ ] メモなどを打ち終えても「保存しました」が出ない

## 3. 検索（friendcheck）

- [ ] 絞り込みの欄の一番上の「保存した検索」：保存・呼び出し（条件・文字・並べ替え・カードかリストかが置き換わる）・上書き・名前の変更・削除・並べ替え・畳む
- [ ] カードの札と1行（ユーザータグ・属性2つ・払った額と対応の数）。**情報の量と読みやすさ**。幅を小さくしたとき
- [ ] カードの名前の欄に乗せたとき・キーボードで止まったときの重ね表示（属性の棒など）
- [ ] リストの列（ユーザータグ・属性・払った額・対応）
- [ ] 設定の「カードに表示する属性」で選ぶ。カードには商品に付いている順で出る
- [ ] 条件「見つからないファイル」「BOOTHに無い商品」

## 4. 商品ページ（noticeline3・friendcheck）

- [ ] 値段の変わったバリエーションの行の帯と「¥前 → ¥今」。**色（橙）と読みやすさ**
