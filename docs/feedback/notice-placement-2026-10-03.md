# 知らせの置き場の洗い出し（2026-10-03・メモ20-②③）

ユーザの方針（2026-10-03）：画面の右上にぽつんと出る状態の文は、知らせとして適さない。入力欄やボタンの操作で出る知らせは、その近くへ移す（全部ではない）。
担当NTC（Sonnet・読むだけ）がコードから洗い出し、まとめ役が置き場と件数をコードで確かめた。直すのはこの後。

## 方針（仕様に書く一文）

操作の結果の知らせは、その操作の欄やボタンのすぐ下に出す。画面の上の1行（や下の帯）は、画面全体の状態と、裏の作業の結果と、押した所が消える操作の結果だけに使う。

## 決まった事（ユーザ判断 2026-10-03）

1. 自動で保存する欄（メモ・改変の名前・blueprint ID など）は、保存できたときは何も出さない（設定と同じ）。保存できなかった・範囲を丸めたなど、人が知る必要のあることだけ欄のすぐ下に出す
2. 押した所ごと消える操作（削除・外す・非表示や除外の解除）の結果は、その一覧の見出しの近くに出す。「戻す」がある物はそこに置く
3. アバターの検出の結果の文（最大5つを「 / 」でつなぐ）は上の段に残し、「…」で切らずに折り返して全部見せる
4. フォルダの「監視しています。次に起動したとき…」は出さない（同じ行の「監視：」の状態の表示で足りる。説明が要るなら状態の表示の吹き出しへ）

## 移す先の主な物

- **アバター**：共通素体を足す欄・素体の名前・商品ID・改名の欄・呼び方の欄の入力の誤り（欄のすぐ下）。IDのコピー（IDの隣）。「確認し直す」（ボタンの近く）。改変を作る（「新しい改変」の欄の下）。書き込みの共通口（`WriteAsync`）は一律 `Status` に出しているので、呼び手が出し先を渡す作りに変える。残す物：検出の途中経過と結果・素体の削除（管理の欄ごと切り替わる）
- **フォルダ**：残す物：一覧を読めなかった（裏の作業）・未確定をまとめて除外（枠ごと消える）
- **改変の画面**：改変を作る・VCC／ALCOM を開く・プロジェクトを開く・Unityで選択（どれも押したボタンや行の近く）。残す物：読めなかった記録・開いていた改変がもう無い・改変を消した
- **改変の詳細**：候補の追加・名前で足す・Unityで選択・VRChatで着替える・紐付け・開く・行の外す／戻す・行のリンク・写真の追加と貼り付け（ギャラリーの近く）。残す物：行の削除・写真の削除（一覧の見出しの近くへ）
- **設定**：バックアップの書き出し・戻す・引越しの途中経過と結果（データの欄のボタンの下。「エクスプローラで開く」も一緒に）、ショートカットの割り当てを外した（その行）、数の欄の範囲を丸めた（9欄。その欄の下）、幅を戻した、別の作業中で押せない。残す物：保存できなかった（欄が特定できない）

## 画面を跳ねさせない（ユーザ 2026-10-03）

「上部の変更があるので画面が一瞬で大きくズレるような動作は避けるようにしてくださいね。」
知らせを欄やボタンのすぐ下に出すと、出る・消えるたびに下の物が押し下げられる。移すときは、知らせの1行分の場所を前もって取っておく（出ていない間も空けておく）か、
下の物に重ねて出し、どちらの形でも今見ている位置が動かないようにする。上の段の文を移して上の段が低くなる所も、画面ごとに一度だけの変化で済むようにする。
