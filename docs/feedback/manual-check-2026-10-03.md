# 手で見る確認項目（2026-10-03・2026-10-02 の UI 監修で直した物）

2026-10-02 にユーザのメモを受けて直した物のうち、**人が見ないと決められない物**だけを並べた。
出し分け・書き込み・件数・キーの順番などの計算で決まる物は、試験（直しを戻すと落ちることも確かめた）で保証してあるので載せていない。
ここで見るのは、見た目（配置・色・折り返し）・手触り（ドラッグ・ホイール・キーで動かしたときの感じ）・言い方の分かりやすさ。

`[ ]` は見る物。気付いた事は「メモ:」で送る（記録だけして、直すのは頼まれた物だけ）。

## 始める前に

- どれも最新版（master）で開く。「〇〇で開いて」と言えば、まとめ役が写しを用意して開き直す
- 写しの使い分け：検索・ショップ・フォルダ・アバター・設定は `friendcheck`（友人の写し・205件）、要確認と商品ページの変わったところは `noticeline`（作り物・知らせ7件）、
  未確定は `importcheck`（作り物・未確定13件）、改変は `d1check`（自分の本番の写し）、タグの管理は `tagcheck`、属性の管理は `attrcheck`
- `friendcheck` などの古い写しの設定には、編集画面の古いキーの割り当て（Ctrl+Shift+矢印）が残っている。Ctrl+N／P を試すときは、設定の「操作」の節のショートカットの各行で「既定に戻す」を押す
