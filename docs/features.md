# 機能一覧 — 何があって、なぜあるか

機能が増えてきたので、**後から「これは何のためにあるのか」を辿れるように**並べておく。
`何` が「何ができるか」、`なぜ` が「どの困りごと・実測・判断から来たか」、`状態` が今どこまで出来ているか。
今の決め事は `docs/spec/`、経緯と根拠は `docs/history/`・`docs/research/` にある（右端の出典）。コミット履歴（`git log`）とも対応している。

書き足すときの約束：
- 理由の分からない機能は「理由未記録」と書いて残す。推測で理由を作らない
- `状態` は次のどれか。**作っていない物を「ある」と読ませない**ための列

| 状態 | 意味 |
|---|---|
| 実装済み | 本体に入っていて、画面から使える |
| 一部 | 入っているが、本来の困りごとの一部しか片付いていない（残りを書く） |
| 調査済み・未実装 | 作り方は調べて文書にある。作るかは決めていない |
| 案・要判断 | 直す方向は出したが、ユーザの判断待ち |
| 道具 | 本体ではなく、測るための実行ファイル（`experiments/`） |
