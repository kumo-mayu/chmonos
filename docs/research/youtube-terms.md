# YouTube の動画の絵とタイトルを手元に置いてよいか（2026-09-14）

> **要約**
> - **目的**：商品ページの動画の欄に出す絵（サムネイル）とタイトルを、保存先に控えてよいかを確かめる（ユーザ指示：規約に反さないかを確かめてから作る）。
> - **方法**：YouTube の利用規約・YouTube API サービスの開発者ポリシー・API サービスの利用規約を読んだ。
> - **結果**：**絵は保存しない**（利用規約はダウンロードを禁じ、許している箇所が無い）。**タイトルは30日まで控え、過ぎたら取り直すか消す**（開発者ポリシーの読み方どちらでも外れない側）。
> - **決めたこと**：ユーザ判断「30日で取り直す」。実装は `VideoTitleBook`・`YouTubeInfo`（`docs/spec/background-and-network.md`）。

## 1. 何を確かめたか

動画の欄は、説明に載っている YouTube の動画を絵とタイトル付きで出す。調べる前は、

- 絵：動画 ID から決まる `i.ytimg.com/vi/{ID}/mqdefault.jpg` を画面が直に読む（保存しない）
- タイトル：oEmbed（`youtube.com/oembed`）で取り、アプリを閉じるまで覚えるだけ

だった。ユーザは「何の動画か分からないのでタイトル位は保存」「画像は一旦の大きさでも良い」とし、保存してよいかの確認を求めた。

参考に、容量は問題にならない。友人のライブラリ（205件）で動画のある商品は55件・85本。絵は1本 平均9.7KB（320×180。確認用の保存先の11本で測った）で、全部で約0.8MB（1件あたり約+4KB。今の1件の平均130.5KB の約3%）。

## 2. 規約に書いてあること

| 文書 | 該当する所 | 読み |
|---|---|---|
| [YouTube 利用規約](https://www.youtube.com/t/terms)「許可と制限事項」 | 本サービスやコンテンツのどの部分も、アクセス・複製・ダウンロードなどをしてはならない。例外は (a) 本サービスが明示的に認める場合と (b) YouTube と権利者が書面で許可した場合だけ | 絵のファイルを落として置くのは、明示的に認められていない |
| [開発者ポリシー](https://developers.google.com/youtube/terms/developer-policies) III.E.4.d | 利用者の認可なしで取れるデータ（Non-Authorized Data）は、必要な間だけ一時的に、**30日を超えずに**置いてよい | タイトルを置けるのは30日まで |
| 同 III.E.4.e | 置いているデータを、今の YouTube のデータと合うよう努めること | 取り直しが要る（非公開・削除なら消す） |
| 同 III.E.1 | 動画そのものをダウンロード・保存・オフライン再生してはならない | 動画は元から扱わない |
| 同 定義 | API Data は API サービスを通して渡されるデータ・コンテンツ・情報 | タイトルも入る |
| [API サービス利用規約](https://developers.google.com/youtube/terms/api-services-terms-of-service) 定義 | 「YouTube API サービス（例：Data API・Reporting API）」 | **oEmbed が対象かははっきりしない** |

## 3. 決めたこと

- **絵は保存しない。**画面が YouTube から直に出す今の形のまま（YouTube が表示のために配っている形）。
- **タイトルは控えるが、30日を超えて置かない。**oEmbed が API サービスの対象と読んでも外れないように合わせた。
  - 取った日時と一緒に `video-titles.json` へ（動画ごとに1つ）。
  - 30日以内なら聞き直さない。過ぎたら動画の欄を開いたときに聞き直す。
  - 非公開・削除で取れなくなったら（400・401・403・404）控えを消す。
  - 開かれないまま残る控えもあるので、控えを書くときと起動したときにも30日を過ぎた物を消す。
- 引き換えに、**消えた動画が何だったかは、30日を過ぎると分からなくなる**。ユーザはこれを承知で選んだ（ほかの案：ずっと残す＝開発者ポリシーの読み方によっては反する／保存しない）。
