# 画面の文言の AI らしさの点検（2026-09-24）

画面の文言が「AI が書いたように読める」という指摘から、App と Core の画面に表示される文を全部集めて型を調べ、
書き方の決まり・用語表・点検の道具を作り直した記録。画面の文そのものは、この日にはまだ変えていない（第2段で一括置換、第3段で画面ごとに直す）。

今の決め事は `docs/spec/ui-writing.md`（書き方）と `docs/spec/ui-terms.md`（語）。

## 見つかった型

画面の文は約2,400件。AI らしさは硬い言い回しではなく、次の型に出ていた。

1. **作り手の理由・経緯・根拠の数字を画面に書く**（約100件）。「〜を避けるため」「前は〜だった」「件数が少ないと数字が暴れるため」
2. **文の終わりの括弧の補足**（約290件）。先回りの言い訳になっている
3. **1つの吹き出しに詰めすぎる**（60字以上が173件）
4. **普通の人が使わない言い回し**（約90件）。積む・落とす・写す・名乗る・出す（表示の意味）・見に行く・取りに行く・相手・こちら（アプリ自身）・束ねる・退ける・結び直す・手掛かり・痩せる・暴れる・「思いがけない失敗」
5. **呼び方の揺れ**。ユーザタグ／ユーザータグ、分類、結び付け／紐付け、すべて／全部／全て、「{n} 件」／「{n}件」、「Unity 側」／「Unity側」、選択肢の区切りの「……」「：」

## 元になっていた所

- **決め事が「書け」と足す向きばかりだった。**押すと何が起きるか・取り返し・次の手・行き先を、全部1つの文に入れるように読めた。削る向きの決まりと長さの上限が無かった。
- **コードのコメント向けの「なぜを書く」（CLAUDE.md）が画面にまで広がっていた。**
- **決め事の文そのものが AI の言い回し（名乗る・積む・黙って・出す）で書かれていて、画面へ移っていた。**
- **点検の道具（`tools/wording.mjs`）の印③「理由なし」が、短い文に理由を足す方へ誘っていた。**印⑥の「60字で長い」も吹き出しには甘かった。道具は App しか見ておらず、コメントも拾っていた。

## 手本

- SmartHR のライティングの手引き（https://smarthr.design/products/contents/ ）：用字用語を先に決める。エラーは事象・原因・対処で、場所が足りなければ原因＞対処＞事象の順で削る（https://smarthr.design/products/contents/error-messages/overview/ ）
- Ubie の UX ライティングの手引き（https://vitals.ubie.life/ux-writing/ ）：日常語を優先。一文80字以内・50字推奨。否定より肯定
- 文化庁「公用文作成の考え方」（2022）：一文を短く。正確・分かりやすく・相手に配慮
- 「AI っぽい日本語」の型：過剰な括弧の補足、日常語で足りる所の難しい語、保険の言い回し、Markdown の記号の残り

## ユーザの判断（2026-09-24）

1. **一般的なソフトの語に寄せる**：積む・足す → 追加、落とす → ドロップ（ダウンロードの意味は「ダウンロードし直す」など）、写す → コピー、出す（表示の意味）→ 表示。名乗る・相手・こちら（アプリ自身）は使わない。「すべて」に揃える。数と単位は「{n} 件」（空白あり）に揃える。ほかの語も、普通の Windows のソフトで見る語を標準にする
2. **長さの目安**：吹き出しは1〜2文・40字まで。窓や空表示の本文は一文50字目安・80字上限
3. **進め方**：決め事とスキル → 一括置換 → 画面ごと

「同じ操作は同じ動詞で呼ぶ」表（2026-09-20）の「全て選択」は、1の「すべて」に揃えて「すべて選択」にした。

## この日にしたこと（第1段）

- 決め事：`ui-rules.md` の「文言」「言葉」を `ui-writing.md`（書き方）と `ui-terms.md`（語）へ移し、削る向きの決まり・長さ・要素ごとの型・正確さを落とさない確かめを足した。
  `ui-dialogs.md`・`ui-empty-and-errors.md`・`ui-input.md`・`.claude/rules/screen-and-wording.md`・CLAUDE.md の言い回しも、画面に移ると困る物（名乗る・積む・黙って・出す）を直した（決め事の中身は変えていない）
- スキル `ui-wording` を作った（手順・印の読み方・良い例と悪い例）
- `tools/wording.mjs` を App と Core の両方の、画面に表示される文だけを拾う形にし（コメント・ログ・例外の文・辞書の表を除く）、印を入れ替えた。語の表は `ui-terms.md` から読む
