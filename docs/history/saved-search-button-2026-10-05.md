# 保存した検索の置き場を、畳める節からボタンの一覧へ（2026-10-05）

> 現在の決め事は `docs/spec/search-saved.md`。ここは決めた経緯。書き直さない。

## 経緯

- 2026-10-04：絞り込み欄のいちばん上に畳める節を置いた（案A3）。
- 2026-10-05 の確認「3. 検索」でユーザが4点を言った（メモ36）。
  - 星マーク（★）は商品のお気に入りの印で別の意味があるので、保存した検索では使わない。
  - 行の操作「今の検索で上書き」は「条件を上書き」の方が分かりやすい。
  - 保存の小窓の説明は長いので「条件、検索文字列、表示順などが保存されます。」にする。
  - 上の節は条件の並びの上で情報量が浮いているので、「条件を追加」ボタンの横に「保存した条件」のボタンを置き、押すと開く形にする。
- メモ38：検索の履歴の件数の設定の説明は「同じ条件は連続して保存されません。」にする。

## したこと

- 節をやめ、ボタン＋ポップアップの一覧にした。畳んだ状態の記憶（`ui-state.json` の `savedSearchesCollapsed`）は要らなくなったので外した。
- 今の検索と同じ物の印は、行は ✓ と地の色、閉じたボタンは末尾の小さな点にした。
- 呼び出したら一覧を閉じる（メニューから選んだのと同じ）。小窓・確認の窓で一覧が閉じたときは、書いた後に開き直して行へ止まり直す。

## 確かめていないこと

- ポップアップの開閉・Esc・小窓を挟んだ後の止まり直しは、実際の窓で動かしていない（試験は ViewModel まで。描く台はポップアップの中身だけを外して撮る）。
