## 変わったこと

### Unity プロジェクトに入っている商品で絞れます

- 検索の条件「Unityプロジェクト」は、そのプロジェクトに実際に入っている商品を表示するようになりました。改変に紐付けていなくても使えます
- 条件を足すと「今開いているプロジェクト」が入っています。開いているプロジェクトは名前のボタンで並び、押すと条件に追加できます
- 検索欄の右のスイッチ「開いているUnity」で、開いている Unity のプロジェクトに入っている商品だけをすぐ表示できます。Unity が開いていないときは押せません
- 今までの条件（紐付けた改変に使った商品）は「改変プロジェクト」という名前になり、「条件を追加」の「改変登録」の下に移りました。「改変」の条件も「アバター・改変」という名前で同じ場所にあります。保存した条件の結果は変わりません

### 手で Unity に入れた画像も探せます

- png・jpg・tga・psd の画像を、大きさと中身で探します。名前を変えていても見つかります
- 中身が同じ画像は「同じ画像」、名前だけ同じ画像は「名前が同じ」と表示します。検索の条件では、名前だけ同じ物は「名前が同じファイルも含める」を入れたときだけ表示します
- 商品ページの「Unityで画像を選択…」か、カードの右クリックの「Unityで選択…」で、Unity の Project ウィンドウで選択できます

### 字を選んでコピーできる所が増えました

- 商品名・ショップ名・アバターの名前・バリエーションの名前・通知の見出しと本文・取り込みのファイル名とエラーの文などを、なぞって選べます
- ファイルやフォルダの場所は「開く ▾」の「パスをコピー」で写せます。省いて表示している場所は、右クリックで全文を写せます

### 未確定の自動検索がフォルダ名も使えます

設定の「フォルダの置き方」でショップ名や商品名の分け方を指定すると、未確定の自動検索がフォルダ名でも探します。そのぶん、BOOTH への問い合わせが増えることがあります。

### 開発者向けの API を足しました

ほかのアプリや自作のツールから、Chmonos のデータを読めるようにする機能です。

- 設定の「API」でオンにしたときだけ動きます（既定はオフ）。同じ PC の中からだけ使えます
- 設定で許すと、お気に入り・ユーザータグ・メモなどを変えたり、Unity へ送ったりできます
- `Chmonos.exe --headless` で、ウィンドウを開かずに動かせます
- 使い方はマニュアルの「[API（開発者向け）](https://github.com/kumo-mayu/chmonos/blob/manual-v1.2.0/manual/40-api.md)」にあります

### そのほか

- アプリのアイコンができました
- 保存先の中に取り込み元のフォルダや商品のファイルを置いているときは、引っ越しの前にそう知らせるようにしました。先に保存先の外へ移してください
- タグの管理で、保存を待っているメモの入力が消えることがあったのを直しました
- アプリに同梱している .NET を、セキュリティの修正が入った版（10.0.14）に更新しました
- そのほか、細かな不具合を直しました

このバージョンで使ったデータは、v1.1.0 でも開けます。そのときは、新しい「Unityプロジェクト」の条件は無視されるので、絞り込みの結果が増えます。
