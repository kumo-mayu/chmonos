根拠のコミットは `git log v1.0.0..v1.1.0`（作者向けの節は末尾）。

## 変わったこと

### 検索欄の書き方が増えました

- `usertag:` ユーザータグ、`avatar:` 対応アバター、`category:` カテゴリで探せます。ユーザータグは名前がぴったり同じ物を探し、`usertag:衣装/ワンピース` のように大分類と小分類を分けたり、`usertag:*ピース` のように一部だけで探したりできます
- 商品の状態で探せます：`is:favorite`（お気に入り）・`is:hidden`（非表示）・`is:owned`（所持）・`is:local`（BOOTHに無い商品）・`is:r18`・`is:delisted`（販売終了・非公開）、`has:update`（更新通知あり）・`has:brokenzip`（壊れたzip）・`has:missing`（見つからないファイル）
- 値段とスキ数を範囲で探せます：`price:`（BOOTH価格）・`paid:`（払った額）・`wish:`（スキ数）。`price:-400`（400以下）・`price:100-500`・`price:500-`（500以上）のように書きます
- `"tori"` のように二重引用符で囲んだ語は、「別表記でも検索」を入れていても広げず、打ったとおりに探します
- タグの管理・属性の管理の検索欄でも、同じ書き方が使えます

書き方の一覧は、マニュアルの「[検索の画面](https://github.com/kumo-mayu/chmonos/blob/master/manual/10-search.md#検索欄)」にあります。

### 新しいバージョンを知らせます

1日1回まで、GitHub に新しいバージョンがあるかを問い合わせ、あれば画面の下に知らせます。設定の「新しいバージョンを確かめる」で止められます。

### データを守る仕組みを足しました

- 保存するデータに形式の番号を付けました。この先のバージョンでデータの形が変わったとき、古いバージョンで開いて壊すことのないよう、開く前に止めます
- データの形を変える前には、変える前のデータを控えます。控えの量は設定の「データ」で見られ、いらなければ削除できます

このバージョンで使ったデータは、v1.0.0 でもそのまま開けます。

### 直したこと

- 対応アバターを足す・消す操作が、裏で商品の情報を取り直すのと重なったとき、その操作が消えることがあったのを直しました
- バックアップの書き出しが途中で止まったとき、書きかけのファイルが残ることがあったのを直しました
- 画像を読む部品（ImageSharp）に脆弱性の知らせが出たため、読む画像の形式を jpg・png・gif・webp・bmp に絞り、画像の付属情報（カラープロファイルなど）を読まないようにしました。TIFF の画像は追加できなくなりました

非公式のアプリケーションです。ピクシブ株式会社（BOOTH・pixiv の運営）が作成・配布しているものではありません。

## 作者向け：配った後に zip を作り直した（2026-10-08）

公開の後、同梱する .NET ランタイム・Windows Desktop（WPF・Windows Forms）の許諾文と第三者の表示が `THIRD-PARTY-NOTICES.txt` に無いと分かった（ユーザの指摘。`f85e7ea0`）。

ほかの8ファイルは元の zip と同じことを確かめた。Releases の zip と `.sha256` を差し替え（新しい zip の SHA256 `BD0C115B74AD61085755302561E611BCE4DE2D17E494E335655116D9E7663BB5`）、BOOTH の2つのバリエーションも同じ zip に差し替える。
