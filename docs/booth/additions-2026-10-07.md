# 公開の文書に書き足す候補（2026-10-07 の洗い出し）

README・BOOTH の原稿・zip の README に、まだ書いていない「使う人が知らないと戸惑う動き」の一覧。
3人の担当（取り込みとファイル／探す・商品ページ／アバター・改変・設定）が spec とコードを読んで挙げ、重い物は自分でコードを見て確かめた。
どれを書くかはユーザが決める（`CLAUDE.md`「洗い出して」と言われたら報告までで止める）。書いたら行頭に「済」を付ける。

置き場の略：R＝README、B本＝BOOTH の本文、B注＝購入前の注意、B使＝使い方、BQ＝よくある質問、Z＝zip の README。

## 先に直した（事実と違っていた）

- 探す対象の既定は商品名・ショップ名・メモ。説明文・ファイルの場所は検索欄の「対象」で入れる。別表記（ゆびわ→指輪）は「オプション」の「別表記でも検索」で入れる（既定は切）。`docs/spec/search.md`
- 監視フォルダの新しいファイルを起動時に取り込むのは、設定の「起動したとき、…取り込む」を入れたときだけ（既定は切）。切なら知らせるだけ
- 「商品IDを手で打ち込む必要はありません」は、候補が見つからなかったときの手入力と食い違うので「打ち込むのは候補が見つからなかったときだけ」にした
- バックアップに入る物（記録・設定・改変。手元の zip やフォルダは入らない）を README に書いた

## アプリの問題として見つかった物（文書ではなくアプリを直すか、要判断）

- **バックアップで「画像は入れない」を選ぶと、改変の写真と自分で足した画像も入らない。**窓の説明は「戻した後、BOOTHから少しずつ取り直します」だが、この2つは取り直せない。
  `BackupArchive.IsImage` が `images\` の下を丸ごと落とす（改変の写真は `images\_mods`、自分で足した画像は `images\<商品ID>`。`AppPaths`・`ImagePipeline.SaveUserImageToAsync`）。確かめた
- 版がアプリの画面のどこにも出ていない。問い合わせのときに版を聞けるよう、設定の「このアプリについて」に出す案
