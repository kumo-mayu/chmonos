Chmonos（クモノス） v1.0.0
============================

BOOTH で買ったアセットを、今のフォルダの並びのまま管理する Windows のアプリです。

  pixiv プラットフォーム（BOOTH）を利用して個人が開発した、非公式のアプリケーションです。
  pixiv が作成、配布しているアプリケーションではありません。

  GitHub : https://github.com/kumo-mayu/chmonos
  マニュアル : https://github.com/kumo-mayu/chmonos/tree/master/manual
  BOOTH  : 【未定】
  お問い合わせ : BOOTH ショップのメッセージ、または X（@kumo_mayu79）の DM


■ 入っているもの

  Chmonos.exe                … アプリ本体（インストール不要）
  assets                     … 辞書とカテゴリの表（Chmonos.exe と同じ場所に置いたままにする）
  README.txt                 … このファイル
  LICENSE                    … Chmonos のライセンス（Apache License 2.0）
  NOTICE                     … 同梱しているデータの出典
  THIRD-PARTY-NOTICES.txt    … アプリが使っているライブラリのライセンス


■ はじめかた

  1. この zip を右クリックして「すべて展開」を選ぶ
     （zip の中から直接開くと assets が使われず、辞書を使った検索が効かないことがあります）
  2. 展開したフォルダの Chmonos.exe を開く
  3. はじめの窓で、データの保存先と、画像を保存するかを選ぶ（どちらも後から変えられます）
  4. 管理したい zip やフォルダなどを、アプリの窓へ落とす
  5. 特定できなかった物は「未確定」に並びます。「自動検索」で BOOTH から候補を探し、
     合っている物を選んで「このIDで登録」（商品IDや URL を自分で入れても登録できます）
  6. どの商品も、必要なら「編集」でユーザータグなどを入れられる（入れなくても使えます）

  Windows の警告が出たとき
    Chmonos.exe には電子署名をしていないため、初めて起動するときに警告が出ることがあります。
    ・「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」で起動できます
    ・「スマート アプリ コントロール」にブロックされたときは、警告の画面から起動する方法が
      ありません。「Windows セキュリティ」→「アプリとブラウザー コントロール」→
      「スマート アプリ コントロールの設定」でオフにすると起動できます。オフにすると、
      ほかのアプリにもこの保護が働かなくなります。オフにするかはご自身で判断してください。
      2026年4月の更新より前の Windows 11 では、一度オフにすると、Windows を入れ直さないと
      オンに戻せません。


■ 取り込みにかかる時間

  BOOTH への問い合わせは1回ずつ、1.5秒以上空けて行います。BOOTH のサーバーに
  負担をかけないためです。100商品で、商品名と説明がそろうまで少なくとも約5分、
  画像まで全部そろうまで約30分かかります。名前と説明は先に全部取るので、すぐ探し始められます。
  取り込みの途中でもアプリは使えます。途中で閉じても、取れた分は保存されています。
  次に起動すると画像の残りは自動で取りに行き、商品の情報の残りは「続きから進む」で続けられます。


■ データの置き場と消し方

  データは、既定で %LOCALAPPDATA%\Chmonos に置きます。
  移すときは、設定の「データ」の「場所を変える」で「引っ越す」を選んでください。
  （参照先だけを変えると、今のデータは元の場所に残ります）
  アプリを消すときは、このフォルダと、データの置き場の両方を消してください
  （Chmonos.exe を消してもデータは残ります）。


■ 通信とアカウント

  BOOTH にはログインしません。アカウント情報を入力する所はありません。
  取ってきた説明や画像は、このパソコンに置くだけで、ほかの所へは送りません。
  「自動検索」を押したときは、ファイル名から作った語を BOOTH の検索に送ります。
  取ってきた説明や画像の権利は、それぞれの作者にあります。
