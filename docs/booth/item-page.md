## 本文（見出しなし）

```
BOOTH で買ったアセット（VRChat 向けの衣装・アバターなど）を、今のフォルダの並びのまま管理する Windows のアプリです。

ダウンロードした zip やフォルダなどをアプリの窓へ落とすと、どの商品かを調べて記録します。多くは自動で決まり、決まらない物も候補から選ぶだけです。商品IDを手で打ち込むのは、候補が見つからなかったときだけです。

BOOTH のアカウント情報は入力しません。ログインせずに、誰でも見られる商品の情報を取りに行きます。

・探す：商品名・ショップ名・メモから探せます。説明文やファイルの場所も、検索欄の「対象」で入れると探せます。「別表記でも検索」を入れると、「スカート」で「skirt」が見つかるように、かな・漢字・英語をまたいで引けます
・絞り込み：所持・対応アバター・ユーザータグ・属性・カテゴリ・ショップ・価格・入手日・改変など、たくさんの条件を組み合わせて絞れます。組んだ条件は名前を付けて残せます
・対応アバター：商品の説明やタグから、どのアバターに対応しているかを読み取って入れます。確かでない物だけ「確認待ち」として出ます
・改変の記録：どのアバターにどの衣装をどの順で入れたかを、写真やメモと一緒に残せます
・Unity へインポート：開いている Unity へ、zip の中の unitypackage をそのままインポートできます（「Unityへ送る」）。インポートした商品のフォルダを、Unity のプロジェクトの画面で開くこともできます
・更新の通知：持っている商品が更新されたり販売終了になったりすると知らせます

pixiv プラットフォーム（BOOTH）を利用して個人が開発した、非公式のアプリケーションです。pixiv が作成、配布しているアプリケーションではありません。

無料版と支援版の中身は同じです。気に入っていただけたら、支援版で応援してもらえると嬉しいです。

AI を使って作っています（詳しくは GitHub の README に書いています）。ソースコードは GitHub で公開しています（Apache License 2.0）。
https://github.com/kumo-mayu/chmonos
```

## 購入前の注意

```
導入の前に確認してください。できないこと・向かないことがあります。

- Windows の 64bit 版専用です。Mac・スマートフォンでは使えません。確かめているのは Windows 11 です（Windows 10 では確かめていません）。

- BOOTH への問い合わせは1回ずつ、1.5秒以上空けて行います。BOOTH を運営するピクシブ株式会社のサーバーに負担をかけないためです。そのため、たくさんの商品を一度に取り込むと時間がかかります（目安は下の「取り込みにかかる時間」）。

- 商品が自動で決まらないファイルもあります。Brave でダウンロードした物・シークレットウィンドウなどで落とした物・7-Zip などで展開した中身・USB メモリへ写した物は、ファイル名から候補を探して、自分で選ぶ形になります。確かめているのは Chrome と Edge です（Firefox・Vivaldi・Opera なども記録は残しますが、まだ確かめていません）。

- 購入履歴は読み込みません。BOOTH にログインしないので、手元にあるファイルから商品を調べます。払った額や買った日は、必要なら自分で入力することができます。入力しておくと検索の条件や統計に使えますが、入力しなくても使えます。

- Unity へ送る機能は、Unity 2022.3 で確かめています。

- 対応アバターは、商品の説明やタグから自動で読み取ります。商品によっては間違えることがあります。自分で足したり外したりできます。

- 電子署名をしていないので、初回の起動で Windows の警告が出ることがあります。詳細は下の「Windows の警告について」を見てください。

- 商品画像に写っている商品名・ショップ名は、説明のために作った架空の物です。
```

## 使い方

```
【はじめに】
① ダウンロードした Chmonos-v1.0.0.zip を右クリックして「すべて展開」を選ぶ（zip の中から直接開くと、辞書が使われないことがあります）
② 展開したフォルダの Chmonos.exe を開く
③ はじめの窓で、データの保存先と、画像を保存するかを選ぶ（どちらも後から設定で変えられます）

【取り込む】
① 管理したい zip やフォルダなどを、アプリの窓へ落とす
② 商品が特定できた物は、そのまま記録されます
③ 特定できなかった物は「未確定」に並びます。「自動検索」を押すと BOOTH から候補を探して出すので、合っている物を選んで「このIDで登録」を押します。商品IDや商品ページの URL を自分で入れても登録できます
④ どの商品も、必要なら「編集」でユーザータグなどを入れられます。入れなくても、検索や Unity へのインポートはそのまま使えます

設定の「起動したとき、監視フォルダの新しいファイルと前回の続きを取り込む」を入れておくと、起動したときに監視フォルダの新しいファイルを自動で取り込みます。入れていなければ、新しいファイルがあることを知らせるだけです。

詳しい使い方は、GitHub のマニュアル（https://github.com/kumo-mayu/chmonos/tree/master/manual）にあります。
https://github.com/kumo-mayu/chmonos
```

## 取り込みにかかる時間

```
BOOTH への問い合わせは1回ずつ、1.5秒以上空けて行うので、商品の数に比例して時間がかかります。
100商品あたり、少なくとも次の時間がかかります（画像の枚数は15商品で測った値です）。

・商品名・ショップ・説明（ここで探したり編集したりできるようになります）：約5分以上
・画像（全部）：約30分以上

名前と説明を先に全部取り、画像はあとから取ります。取り込みの途中でも、届いた商品から探せます。

途中でアプリを閉じても、取れた分は残ります。次に起動すると、画像の残りは自動で取りに行き、商品の情報の残りは画面の下の「続きから進む」で続けられます。
```

## Windows の警告について

```
Chmonos.exe には電子署名をしていないため、初回の起動で「Windows によって PC が保護されました」（SmartScreen）と出ることがあります。「詳細情報」を押すと「実行」のボタンが出るので、それを押すと起動できます。

「スマート アプリ コントロール」にブロックされたときは、警告の画面から起動する方法がありません。起動するには、「Windows セキュリティ」→「アプリとブラウザー コントロール」→「スマート アプリ コントロールの設定」で、スマート アプリ コントロールをオフにします。オフにすると、ほかのアプリにもこの保護が働かなくなるので、オフにするかはご自身で判断してください。2026年4月の更新より前の Windows 11 では、一度オフにすると、Windows を入れ直さないとオンに戻せません。

気になる方は、GitHub のソースコードからご自身でビルドすることもできます（手順は GitHub にあります）。exe は .NET を同梱しているので、別に .NET を入れる必要はありません。
```

## データの置き場と消し方

```
- データは、既定で %LOCALAPPDATA%\Chmonos に置きます（エクスプローラのアドレス欄に貼ると開けます）
- 置き場は、初回起動時の画面で好きな場所を選べます。後からは、設定の「データ」の「場所を変える」で変更できます。データを新しい場所へ移す（「引っ越す」）か、参照先だけを変えるかを選べます。参照先だけを変えると、今のデータは元の場所に残り、空のフォルダを選んだ場合は空の状態から始まります
- インストーラが無いので、Chmonos.exe を消してもデータは残ります。すべて消すときは、データの置き場のフォルダも消してください
- 取ってきた説明や画像は、このパソコンに置くだけで、ほかの所へは送りません
```

## よくある質問

```
Q. 起動しません
A. Windows の警告で止められている可能性があります。上の「Windows の警告について」を見てください。

Q. 「スカート」で「skirt」が見つかりません
A. 検索欄の右の「オプション」で「別表記でも検索」が入っているかを確かめてください。入っているのに見つからず、画面の下に「辞書などのファイルが見つかりません。」と出ていたら、zip を「すべて展開」してから、展開したフォルダの Chmonos.exe を開いてください。Chmonos.exe と assets フォルダは同じ場所に置いたままにしてください。

Q. 商品が「未確定」に残ります
A. ダウンロードしたときの手掛かりが残っていないファイルです。「自動検索」で候補を出して選ぶか、BOOTH の商品ページの URL から商品IDを入れてください。BOOTH に無い商品（配布が終わった物など）は、名前を付けて登録できます。

Q. 取り込みが遅いです
A. BOOTH に負担をかけないよう、問い合わせを1回ずつ間を空けて行っているためです。商品名と説明を先に全部取り、画像はそのあとで取るので、画像が届く前から探したり編集したりできます。途中で閉じても、次の起動で続きから進められます。

Q. BOOTH のアカウントは要りますか
A. 要りません。アカウント情報を入力する所もありません。BOOTH へは、ログインしなくても誰でも見られる商品の情報・ショップのページ・画像を見に行くだけです。「自動検索」を押したときは、ファイル名から作った語を BOOTH の検索に送ります。

Q. 手元のファイルを動かしたり消したりしますか
A. 勝手に動かしたり、名前を変えたりはしません。消すのは、取り込みの画面で zip の展開先のフォルダを選んで「ごみ箱へ移動」を押したときだけです。

Q. アプリを消すにはどうすればいいですか
A. Chmonos.exe のあるフォルダと、データの置き場（既定は %LOCALAPPDATA%\Chmonos）を消してください。

Q. どんなファイルを取り込めますか
A. フォルダごと落としたときは、BOOTH で配られる形式（zip・rar・画像・PSD・PDF・音声・動画・VRM・VRoid など）と、unitypackage・7z・blend・fbx を取り込みます。それ以外のファイルも、商品ページの「追加…」から、その商品に足せます。単体の unitypackage も Unity へインポートできます。

Q. ファイルを別のフォルダへ移しました
A. zip などのファイルは中身で見分けるので、取り込み直せばそのまま使えます。フォルダとして登録した物は「見つかりません」になるので、取り込みの画面の「見つからないファイルを探す…」で結び直してください。

Q. 展開したフォルダの中身が取り込まれません
A. zip の隣にある、展開しただけのフォルダは、別の商品として数えないようにしています。zip のまま取り込んでください。

Q. OneDrive のフォルダで、取り込まれないファイルがあります
A. 「オンラインのみ」のファイルは、読むとダウンロードが始まるので読み込みません。フォルダを「常にこのデバイスに保持する」にしてから、取り込み直してください。

Q. Unity に送れません
A. 送り先の Unity のエディタを先に開いておいてください。最後の「Import」は、Unity の取り込みの画面で押します。確かめている Unity は 2022.3 です。

Q. 「未確認」の対応アバターとは何ですか
A. 商品の説明から対応しているかを読み取れなかった物です。「非対応」という意味ではありません。確かでない物は「確認待ち」として出るので、合っているかを選んでください。

Q. 「VRChatで着替える」を押しても着替えません
A. VRChat の OSC を有効にしてください（Action Menu の Options から）。着替えられたかどうかは、アプリからは分かりません。

Q. バックアップには何が入りますか
A. 商品の記録・設定・改変・自分で足した画像が入ります。zip やフォルダなど、あなたのファイルそのものは入りません。「画像は入れない」を選ぶと、BOOTH の画像は戻した後に取り直します。

Q. 不具合を見つけました
A. 設定の「このアプリについて」のバージョンと、データの置き場の logs\app.log を添えて、下のお問い合わせ先へ送っていただけると助かります。

Q. 無料版と支援版の違いは何ですか
A. 中身はまったく同じです。
```

## 根拠（ページには貼らない）

- ログインしない・cookie を使わない：`docs/spec/id-resolution.md` の要点
- 手掛かりが消える場合：`docs/research/id-resolution.md` §6（Brave はオリジンだけ・7-Zip の既定で消える・FAT32 / exFAT は ADS を持てない。最後はこの PC では未検証）
- 取り込みの時間：`docs/history/import-order.md`（15商品で画像は1商品あたり約9.5枚。約19秒は本数×1.5秒の計算で実測ではない。門は前の問い合わせが終わってから1.5秒を数えるので、実際はこれより長い）。画像を切ると①②の2本で約3秒・100商品で約5分。どちらも「以上」と書く
- 通信する先：`BoothClient` と `YouTubeInfo` だけが `HttpClient` を作る。ほかに WPF が動画の絵を i.ytimg.com から直に読む（`ItemVideosPanel.xaml`）。BOOTH の検索（`FallbackResolver`）は `UiCommand` から、人が押したときだけ（2026-10-07 に Grep）
- 取り直しの間隔：`AppSettings.RefreshIntervalDays` = 7・`RefreshJitterDays` = 3
- 手元のファイルを消すのは「展開先フォルダの削除」（`UiCommand.RemoveUnpackedFolders`）だけで、ごみ箱へ送る。送れないドライブでは消さない（`AppServiceContainer.DeleteToRecycleBin`）
- `assets` が無いと、アプリは起動するが辞書を使う検索が黙って切れる（`SearchBridge.IsAvailable`。知らせは出ない）
- 購入記録は手で入れる（`docs/spec/item-page.md`「購入記録」）
- 非公式の表記：`docs/research/booth-terms.md` §3。アプリの初めの窓と設定の「このアプリについて」と同じ言い方にした
