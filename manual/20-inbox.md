# 通知の画面

<!-- nav:top -->
[← 目次へ](README.md)　｜　[← 前の記事：統計の画面](19-stats.md)
<!-- /nav:top -->

Chmonos が見つけた「確かめてほしいこと」を集める画面です。BOOTH での商品の変化のほか、手元の記録の食い違いや、壊れて読めない記録なども、ここに出ます。左のナビの「通知」で開きます。ナビの「通知」の横の数が、未読の件数です。

![通知の画面。商品ページの変更の束に、価格・説明文・バリエーション・販売状態の変更が並ぶ](images/inbox.png)

通知は種類ごとの「束」にまとまって並びます。束の見出しを押すと畳めます。特に見てほしい通知には「重要」の札が付き、重要な未読がある束が上に来ます。

## 通知の種類

**BOOTH での変化**

起動している間、Chmonos はしばらく確かめていない商品の情報を BOOTH から取り直します（既定ではおよそ1週間ごと）。そのときに見つけた変化です。

| 束 | 中身 | 行のボタン |
|---|---|---|
| 商品ページの変更 | 取り直したときに内容が変わっていた商品。変わった所を1つずつ「前 → 後」で出します（価格 ¥2,000 → ¥1,600・バリエーション 5色 → 6色・販売状態 販売中 → 販売終了など）。説明文は、足された行と消された行を出します | 商品ページを開く |
| 消えたバリエーション | 手元のファイルや購入の記録が指すバリエーションが、BOOTH から消えた | 商品情報を取り直す |
| 復活したバリエーション | 消えていたバリエーションが、BOOTH にまた出てきた | 商品情報を取り直す |
| 非公開商品の復活 | 非公開と見なしていた商品が、BOOTH でまた見えるようになった | 商品情報を取り直す |

**手元のファイル**

| 束 | 中身 | 行のボタン |
|---|---|---|
| zipを入手した | 展開したフォルダとして登録していた商品の zip が手元に入り、両方を登録している（同じ中身を二重に数えています） | zipで登録しなおす（zip を商品に付け、展開したフォルダの登録を外します。ディスクのファイルには触りません） |
| 展開先のファイルを取り込んだ | 自動で始めた取り込みで、zip を展開したフォルダの中のファイルを取り込んだ。元の zip の方で持ち直せます | ― |

**手元の記録**

| 束 | 中身 | 行のボタン |
|---|---|---|
| タグの参照切れ | タグの管理・属性の管理から消したか名前を変えたタグ・属性を、商品がまだ使っている | タグの管理を開く（作り直すか、商品から外します） |
| 手で直したJSONの食い違い | 保存先の JSON を手で直したところに、同じ名前の重複や、ファイル名と商品IDの食い違いがある | ―（JSON を開いて直してください） |
| 読めない商品の記録 | `items` フォルダの商品の記録が壊れていて読めない。読めない間、その商品は検索などに出ません | 1つ前の版に戻す（アプリが最後に書いた版に戻します）か、BOOTHから作り直す（タグ・メモ・購入記録などは戻りません） |
| 途中で止まった操作 | IDや名前の変更で、途中で止まったり、記録を残せなかったりした操作。次の起動でまた続けます | ― |

壊れて読めなかった記録は消さずに、保存先の `items\_broken` フォルダによけてあります。

BOOTH の商品ページの作りが変わって情報が取りにくくなったときは、束ではなく、ナビの「設定」の上に「BOOTHの情報の形式が変わったかもしれません」の帯が出ます。手元のデータはそのままです。

## 操作

| 部品 | すること |
|---|---|
| 未読のみ | 入れると、未読の通知だけを出す |
| 読み直す | 一覧を作り直す |
| すべて既読にする | 全部の通知を既読にする |
| この束を既読にする | その見出しの通知を既読にする |
| 行の左の丸 | その通知の既読・未読を切り替える |
| 行の下のボタン | マウスを乗せた行に出ます。上の表の「行のボタン」 |
| 商品ページを開く | その商品のページを開く。商品ページの変更なら、変わった欄に色の線と札が付いています（[商品ページ](11-item.md#booth-で変わった所)） |

既読にしても通知は消えません。「未読のみ」を外すと、既読の物も出ます。もう直った通知（読めるようになった記録など）には「解消済み」の札が付きます。

検索のカードやショップの画面の「更新の通知を開く」から来たときは、その商品の行が色付きで強調され、束の先頭に並びます。

商品の更新の通知が要らない商品は、編集の画面の「更新を通知する」を外します。
