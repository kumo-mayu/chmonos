# データの保存先・バックアップ・引っ越し・削除

<!-- nav:top -->
[← 目次へ](README.md)
<!-- /nav:top -->

Chmonos が保存するデータの場所と、移し方・残し方・消し方です。

## 何がどこにあるか

| 物 | 場所 |
|---|---|
| アセットのファイル（zip など） | 今ある場所のまま。Chmonos はコピーも移動もしません |
| Chmonos のデータ（商品の記録・画像・設定・改変など） | データの保存先。既定は `%LOCALAPPDATA%\Chmonos` |
| アプリ本体 | 展開した `Chmonos-v1.0.0` フォルダ |

`%LOCALAPPDATA%\Chmonos` は、エクスプローラーのアドレスバーに貼り付けると開けます。設定の「データ」の「エクスプローラで開く」でも開けます。

保存しているデータは、すべて普通の JSON です。アプリを介さずに開いて読めます。不具合を知らせるときに頼むことのある `logs\app.log` も、この中にあります。

新しい版の Chmonos がデータの形を変えるときは、変える前の JSON を保存先の `format-backups` フォルダに控えます。前の版の Chmonos に戻したいときは、この控えを使います。いらなくなったら、設定の「データ」の「控えを削除…」で消せます。

新しい版の Chmonos で使ったデータは、古い版では開けません。開こうとすると知らせが出るので、新しい版を入れてから開いてください。

## 保存先を変える

C ドライブの空きが少ないときなどは、設定の「データ」の「場所を変える」で、保存先を変えます。変えるときは、次のどちらかを選びます。

| 選ぶもの | 起きること |
|---|---|
| 引っ越す | 今のデータを新しい場所へ移します。今までの記録をそのまま使い続けます |
| 参照先だけを変える | 新しい場所を使い始めます。今のデータは元の場所に残ります。空のフォルダを選んだときは、空のライブラリから始まります |

引っ越しの途中で止めたり失敗したりしたときは、移す先に書いた物を消して、元のまま使い続けます。取り込みが走っている間は変えられません。

## バックアップする

設定の「データ」の「バックアップを書き出す…」で、データを1つの zip に保存します。

- 入る物：商品の記録・設定・改変・自分で足した画像・改変の写真など
- BOOTH の商品の画像を入れるかは、書き出すときに選べます。入れないと zip が小さくなり、戻したあとに BOOTH から取り直します
- 入らない物：アセットのファイル（zip など）そのもの。アセットは BOOTH のライブラリから、ダウンロードし直せます

戻すときは「バックアップから戻す…」で zip を選びます。別の空の場所に展開して、次の起動からそこを使います。

BOOTH で販売終了になった商品は、手元にしか情報がありません。統計の画面の「手元の状態」の「もう買えないもの」に出る物があるときは、バックアップをおすすめします。

## 外付けドライブ・クラウドのフォルダ

- アセットを外付けドライブに置いていて、取り外している間も、記録は消えません。つなぎ直せば元に戻ります
- データの保存先を外付けドライブや OneDrive・Google ドライブなどの同期フォルダに置いたときは、つながっていないと起動時に「データの保存先が見つかりません」と出ます。ドライブをつなぐか、同期のアプリを動かしてから起動し直します

## 削除する（アンインストール）

インストーラーが無いので、次の2つを消すと、すべて消えます。

1. 展開した `Chmonos-v1.0.0` フォルダ（アプリ本体）
2. データの保存先のフォルダ（既定は `%LOCALAPPDATA%\Chmonos`）

アプリ本体だけを消しても、データは残ります。もう一度使うときに、同じ保存先を選ぶと続きから始まります。
アセットのファイル（zip など）は、どちらにも入っていないので消えません。

起動中は、一時的なファイルを `%TEMP%` の中に作ります（`%TEMP%\.net\Chmonos` と `%TEMP%\Chmonos`）。消しても、次に起動したときに作り直します。
