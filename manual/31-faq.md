各章の「うまくいかないとき」の表にも、その場面のよくある困りごとがあります。ここには、場面をまたぐ物を集めています。

## 使う前に

### BOOTH のアカウントは要りますか

要りません。ログインする画面もありません。アクセスするのは、ログインせずに見られる商品の情報（商品ページと、その内容の JSON）・ショップのページ・画像だけです。
商品の JSON は、BOOTH が公式に文書化している API ではありません。BOOTH の仕様が変わると、情報を取得できなくなる場合があります。

### 購入履歴を読み込めますか

読み込みません。BOOTH にログインしないので、手元にあるファイルから商品を調べます。払った額や買った日は、必要なら編集の画面で入れます。

### 外へ何を送りますか

- 未確定の画面で「自動検索」を押したときに、ファイル名から作った検索語を BOOTH の検索に送ります
- 商品ページの動画の欄を開いたときに、YouTube から動画のタイトルと画像を取得します
- 1日1回まで、GitHub に新しい版があるかを問い合わせます。設定の「新しい版を確かめる」をオフにすると、問い合わせません
- それ以外は BOOTH から取得するだけです。取得した説明や画像は、お使いの PC の保存先に置くだけで、外へは送りません

### Mac・スマートフォンで使えますか

使えません。Windows の 64bit 版専用です。

## 取り込み

### 取り込みを速くできますか

BOOTH へのリクエストは、1件ずつ、1.5秒以上の間隔を空けて送ります。BOOTH を運営するピクシブ株式会社のサーバーに負担をかけないためで、短くする設定はありません。
時間の多くは画像の取得です。画像が要らなければ、設定の「画像を取って保存する」を切ると、取り込みはかなり速くなります。

画像を保存する設定のままでも、商品名と説明は先に全部取得するので、画像を待たずに探し始められます。

### 取り込みの途中でアプリを閉じても大丈夫ですか

大丈夫です。取得した分は残ります。次に起動すると、画像の残りは自動で取得し、商品の情報の残りは、画面の下の「続きから進む」で続けられます。

### zip を展開したフォルダしか持っていません

展開したフォルダも取り込めます。中のファイルが未確定に並んだら、元の zip ごとにまとめて登録するか、「zipの代わりにフォルダを登録する」でフォルダごと登録します（[未確定の画面](13-resolve.md)）。
ダウンロードし直せるなら、zip のまま取り込む方が確実です。

### ファイルを移動・名前を変えたら、記録はどうなりますか

zip などのファイルは中身で見分けるので、移動や名前の変更をしても、記録はそのまま使えます。移した先を取り込むと、新しい場所に付け直します。移した先を取り込むまでは、カードに「見つからない」の札が付きます。

消してしまったファイルなど、もう戻らないファイルの記録が残っているときは、設定の「データ」の「見つからないファイル」で「記録をすべて削除…」を押すと、全部の商品からまとめて消せます。あとでファイルが戻ってきても、取り込めばまた紐付きます。
フォルダとして登録した物は場所で見分けるので、移すと「見つかりません」になります。取り込みの画面の「見つからないファイルを探す…」で紐付け直します。

## 使っていて

### 同じアプリを2つ開けますか

同じ保存先を使う Chmonos は、同時に2つ起動できません。

### 間違った商品に登録してしまいました

商品ページの「IDを変える」で、正しい商品IDへ移します。記録はそのまま移ります。
ファイルだけが違うときは、ローカルファイルの欄の「外す」でその商品から外し、正しい商品に「追加…」で紐付けます。

### 商品の説明が古いままです

商品ページの「商品情報を取り直す」で、BOOTH から取り直します。起動している間は、しばらく確かめていない商品を自動で取り直します（既定は7日ごと）。

### 消してしまった物を戻したい

| 消した物 | 戻し方 |
|---|---|
| 非表示にした商品 | 設定の「隠したもの」の「解除」 |
| 除外したファイル | 設定の「隠したもの」の「解除」 |
| 商品から外したファイル | 商品ページで「この商品に戻す」か、設定の「隠したもの」の「戻す」 |
| 外した対応アバター | 商品ページの対応アバターの欄の「消したもの」の「戻す」 |
| 改変から外した使ったもの | 改変の画面で、薄く残った行を戻す |
