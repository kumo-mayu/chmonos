# 未確定の画面

<!-- nav:top -->
[← 目次へ](README.md)　｜　[← 前の記事：編集の画面](12-edit.md)
<!-- /nav:top -->

取り込みで、どの商品か決まらなかったファイルが並ぶ画面です。左のナビの「未確定」の横の数が、残りの件数です。使い方の流れは [アセットを取り込む](02-import.md#4-商品が決まらなかったファイルを登録する) にあります。

![未確定の画面](images/resolve.png)

## 上の帯

| ボタン | すること |
|---|---|
| 最後に確定した商品を開く | 最後に登録した商品のページを開く |
| 確定したものを編集する | ここで登録した商品を、編集の画面で順に開く |
| 外した n 件を戻す | 直前に除外したファイルを、未確定に戻す（除外した直後だけ出ます） |

## 左：未確定のファイル

- 上の欄で、ファイル名・フォルダ・zip の名前で探せます
- チェックを入れると、まとめて扱えます（まとめて除外する・まとめて1つの「BOOTHに無い商品」にする）。「すべて選択」「選択を解除」もあります
- zip を展開した中身は、元の zip ごとにまとめて畳んで並びます

**行の札**

| 札 | 意味 |
|---|---|
| 壊れたzip | zip を開けません。ダウンロードし直して、もう一度取り込みます |
| BOOTHで非公開 | 読み取れた商品IDが、BOOTH で見つかりませんでした |
| 登録待ち n番目 | 「このIDで登録」の順番を待っています |

**右クリック**

「エクスプローラで開く」「ファイル名をコピー」「管理対象から除外する」「登録をやめる」（順番待ちから外す）を選べます。

## 右：対象と、決め方

**対象の帯**

右の上に、今登録しようとしている物（対象）が出ます。

- 同じ zip の中身や同じフォルダのファイルは、まとめて1つの対象になります。「zipの中身 n 件」「フォルダの n 件」と「このファイルだけ」で切り替えます
- 元の zip が一覧にあるときは、「元zipとして扱う」で zip を登録します
- 元の zip が見つからないときは、そう出ます

**このファイルについて分かっていること**

保存場所・ダウンロード元・展開したときの元の zip・zip の中身が出ます。「ファイル名をコピー」「エクスプローラで開く」もここにあります。

**商品IDを決める**

| 部品 | すること |
|---|---|
| 商品IDかURLの欄 | 商品ID か、商品ページの URL を入れる。ブラウザから商品ページのリンクをドラッグ＆ドロップしても入ります |
| 情報を確認 | 入れた ID の商品を BOOTH から取得して、下に出す |
| このIDで登録 | 出た商品として登録する |
| 自動検索 | ファイル名で BOOTH を検索して、候補に並べる |

キーボードでは、欄で Enter が「情報を確認」、Ctrl+Enter が「このIDで登録」です。登録すると次のファイルへ進みます。

**候補**

自動検索の結果と、手元の記録から見つけた候補が並びます。

| ボタン | すること |
|---|---|
| これで確認 | その候補を「商品IDを決める」に出す |
| BOOTHで開く | 候補の商品ページをブラウザで開く |
| ブラウザで検索 | ファイル名で BOOTH の検索をブラウザで開く |

**その他**

| 部品 | すること |
|---|---|
| BOOTHに無い商品として登録する | 非公開・削除済みで商品IDが分からない物を、名前を付けて手元の商品として登録します。画像も足せます。名前も画像も自動では増えません |
| zipの代わりにフォルダを登録する | 展開したフォルダを、そのまま商品のファイルとして登録します。zip をダウンロードし直せないときに使います |
| 除外する | 管理しないファイルとして、一覧から外します。ファイル自体は消しません。設定の「隠したもの」から戻せます |

「BOOTHで非公開」の札の行は、読み取れた ID のまま登録する形で出ます。そのまま登録すると、BOOTH で再び公開されたときに情報を取得します。

## 登録にかかる時間

手元に情報が無い商品を「このIDで登録」すると、BOOTH から情報を取得します。登録は順番待ちに入り、1件ずつ進みます。待っている間も、ほかの行を登録できます。
登録で取得するのは、商品の情報と1枚目の画像までです。残りの画像は、そのあとで取得します。
