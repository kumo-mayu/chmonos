既定の割り当てです。Ctrl・Alt を使う割り当ては、設定の「操作」の「ショートカット」で変えられます（[設定](22-settings.md#操作)）。

## どの画面でも

| キー | 操作 |
|---|---|
| Ctrl+F | 画面の中を検索する（Enter・Shift+Enter で次・前へ、Esc で閉じる） |
| Alt+← ／ マウスの戻るボタン | 前の画面へ戻る |
| Alt+→ | 戻った画面から進む |
| Ctrl+プラス ／ Ctrl+マイナス ／ Ctrl+0 | 表示を拡大 ／ 縮小 ／ 100% に戻す |
| Shift+F10 | 右クリックのメニューを開く |
| Shift+ホイール | 横にスクロールする |

## 画面ごと

| 画面 | キー | 操作 |
|---|---|---|
| 商品ページ | ← → | 画像を切り替える |
| 編集 | Ctrl+Enter | 保存して次へ |
| 編集 | Ctrl+N | 次の商品へスキップ |
| 編集 | Ctrl+P | 前の商品へ戻る |
| 未確定 | Enter（商品IDの欄で） | 情報を確認 |
| 未確定 | Ctrl+Enter | このIDで登録して、次のファイルへ |
| 入力欄の候補 | ↑ ↓ ／ Enter ／ Tab | 候補を選ぶ ／ 決める ／ 次の欄へ |

## キーボードだけで動かす

- **Tab** で、ボタンや欄を順に移ります。左のナビは Tab で1回だけ止まり、中は ↑ ↓ で移ります
- **カードの一覧**（検索・ショップ・フォルダの右など）や、札の並びは、Tab で1回だけ入り、中は矢印キーで移ります（← → は順に、↑ ↓ は上下、Home・End は端へ）
- 検索の絞り込みの条件の並びも、Tab で1回だけ止まります。↑ ↓ で条件の間を移り、Enter か Tab で条件の中へ、Esc で外へ戻ります
- ボタンは Enter か Space で押せます
