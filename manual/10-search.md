# 検索の画面

<!-- nav:top -->
[← 目次へ](README.md)
<!-- /nav:top -->

左のナビの「検索」で開く、商品を探して一覧にする画面です。使い方の流れは [探す](03-find.md) にあります。この章は、画面の部品ごとの説明です。

![検索の画面](images/search.png)

| 場所 | あるもの |
|---|---|
| 上 | 検索欄・「対象」・「オプション」 |
| 左 | 絞り込み（条件の一覧） |
| 一覧の上 | 件数・表示順・「カード」「リスト」 |
| 中央 | 商品のカードかリスト |
| 右下 | カードの大きさ・行の高さのスライダー |

## 検索欄

入れたそばから一覧が絞られます。書き方（スペース・`-`・`""`・`OR`・`name:` などの前置き）は [探す](03-find.md#文字で探す) にあります。

**「対象」**：文字で探す所を選びます。既定は商品名・ショップ名・メモです。

| 項目 | 前置き |
|---|---|
| 商品名 | `name:` |
| ショップ名 | `shop:` |
| メモ | `memo:` |
| サブドメイン（ショップの URL の `〇〇.booth.pm` の部分） | `subdomain:` |
| 本文（説明とセクション） | `main:` |
| BOOTHタグ | `tag:` |
| バリエーション名 | `variation:` |
| 商品ID | `id:` |
| ファイル名 | `file:` |
| ファイルの場所 | `path:` |
| zipの中のファイル名 | `content:` |

次の前置きは「対象」にはありませんが、検索欄に書くと使えます。

| 前置き | 探す物 |
|---|---|
| `usertag:` | ユーザータグ（大分類と小分類の名前） |
| `avatar:` | 対応アバター（名前・呼び方・共通素体の名前） |
| `category:` | カテゴリ |
| `is:favorite` | お気に入り |
| `is:hidden` | 非表示の商品。書くと、非表示の商品も一覧に出ます |
| `is:owned` | 所持している商品 |
| `is:local` | BOOTHに無い商品 |
| `is:r18` | R-18 の商品。設定で R-18 を表示しないようにしているときは出ません |
| `is:delisted` | 販売終了・非公開の商品 |
| `has:update` | 更新通知がある商品 |
| `has:brokenzip` | 壊れたzipがある商品 |
| `has:missing` | 見つからないファイルがある商品 |
| `price:` | BOOTH価格。種類のどれか1つが範囲に入れば見つかります |
| `paid:` | 払った額。入れていない商品は、どの範囲にも入りません |
| `wish:` | スキ数 |

`price:`・`paid:`・`wish:` の範囲は、次のように書きます。

| 入れ方 | 範囲 |
|---|---|
| `price:-400` または `price:<=400` | 400以下 |
| `price:100-500` | 100から500 |
| `price:500-` または `price:>=500` | 500以上 |
| `price:500` | ちょうど500 |

`price: -400` のように前置きの後に空白を入れると、`-400` を除く語として読みます。続けて書いてください。

**「オプション」**

| 項目 | すること |
|---|---|
| 大文字と小文字を区別する | 入れると、「Skirt」と「skirt」を別の語として探します |
| 全角と半角を区別する | 入れると、「ＡＢＣ」と「ABC」を別の語として探します |
| ひらがなとカタカナを区別する | 入れると、「りぼん」と「リボン」を別の語として探します |
| 別表記でも検索 | かな・漢字・ローマ字・英語をまたいで探します。下の5つで、どの変換を使うかを選べます |
| ローマ字変換 | tori → とり・トリ |
| 漢字変換 | とり → 鳥 |
| 英日変換 | shark → サメ |
| 日英変換 | リボン → ribbon |
| 造語変換 | nadeoto → 撫で音 |

## 絞り込み

「＋ 条件を追加」で条件を足します。条件は見出しごとに並んでいて、同じ条件が2つの見出しに出ていることもあります。

| 条件 | 絞るもの |
|---|---|
| カテゴリ | BOOTH のカテゴリ（自分で入れたカテゴリを含む） |
| BOOTHタグ | BOOTH のタグ |
| R-18 | R-18 の商品かどうか |
| 価格 | 既定は自分が払った額。切り替えると BOOTH の価格 |
| スキ数 | BOOTH のスキ数 |
| 有料・無料 | BOOTH の価格が有料か無料か |
| ショップ | ショップ。ショップの画面で星を付けたお気に入りのショップもまとめて選べます |
| 対応アバター | 対応しているアバター・共通素体 |
| 公開日 | BOOTH での公開日 |
| 公開状況 | BOOTH で公開中か、販売終了・非公開か |
| 更新通知あり | 未読の更新の通知がある商品（変わった内容の種類で選べます） |
| ユーザータグ | 自分で付けたタグ |
| 属性 | 自分で付けた属性の値。評価していない商品は外れます |
| お気に入り | カードの星 |
| 非表示 | 非表示にした商品を表示します。この条件が無いときは、非表示の商品は出ません |
| 所持 | 手元にファイルがあるか |
| ギフト | もらった物か、自分で買った物か |
| BOOTHに無い商品 | 「BOOTHに無い商品として登録」した商品か |
| 改変 | 改変に使った商品。アバターだけを選ぶと、そのアバターのどれかの改変に使った商品 |
| 最近 | Unity へ送った・商品ページを開いた・取り込んだ日からの日数 |
| Unityプロジェクト | そのプロジェクトに紐付けた改変に使った商品 |
| 入手日 | 入手日か買った日 |
| 編集状況 | 編集画面の項目を入力したか、対応アバターを確認したか |
| 見つからないファイル | 記録はあるのに、置いた場所に見つからないファイル・フォルダがある商品 |
| 壊れたzip | 壊れていて開けない zip がある商品 |
| ファイルの場所 | 手元のファイルのフォルダ（その下のフォルダも含む） |

**条件の組み合わせ方**

- 種類の違う条件は、全部を満たす商品が残ります（AND）
- 1つの条件の中で複数の値を選んだときは、どれかに当てはまる商品が残ります（OR）。「すべてを満たす商品のみ（AND）」のある条件では、入れると全部に当てはまる商品だけが残ります
- 価格・スキ数・公開日・入手日は、同じ種類を2つ以上置くと、どれかの範囲に入る商品が残ります

**条件の操作**

| 操作 | すること |
|---|---|
| 左のチェック | 外すと、値を残したまま効かなくなります |
| × | 条件を外します |
| ▲ | 条件を畳みます。畳んでも効いたままで、中身は1行で出ます |
| 左のつまみをドラッグ | 条件の順番を変えます |
| 「…」か右クリック →「当てはまる商品を除く」 | 当てはまる商品を除きます。見出しに「除く」の札が付きます |
| 絞り込みの上の「…」→「条件をクリア」 | 全部の条件を外します |
| 絞り込みの上の「…」→「絞り込みを折りたたむ」 | 絞り込みの欄を畳みます。畳んだ姿に、効いている条件の数が出ます |

**保存した条件**

「保存した条件 ▾」→「＋ 今の検索を保存」で、検索欄の文字・条件・表示順・カードかリストかを、名前を付けて残します。呼び出すと、今の検索と置き換わります。
保存した物は、同じメニューで「条件を上書き」「名前を変更…」「上へ移動」「下へ移動」「削除」できます。

## 表示順

「表示順」で並べる項目を選び、隣のボタンで向きを切り替えます。

| 項目 | 向き |
|---|---|
| 入手日・公開日 | 新しい順・古い順 |
| 払った額・BOOTH価格 | 高い順・安い順 |
| スキ数・改変に使った回数 | 多い順・少ない順 |
| 名前・ショップ | 昇順・降順 |
| カテゴリ | BOOTHの並び（BOOTH のカテゴリの一覧と同じ順）・逆順 |
| 容量 | 大きい順・小さい順 |

このほか、属性の値と、最近の記録（Unity へ送った日など）でも並べられます。値の無い商品は、どちらの向きでも後ろに並びます。
カテゴリ順・ショップ順・公開日順のときは、まとまりの最初に、名前と件数の札が入ります。入手日順でも入れたいときは、設定の「入手日で並べたときも区切りを表示」を入れます（既定は切）。

## カード

| 部分 | 意味・操作 |
|---|---|
| 画像 | マウスを左右に動かすと、ほかの画像に切り替わります。下の区切りと「2 / 3」で何枚目かが分かります |
| 左上のチェック | 商品を選びます（下の「選んでまとめて操作する」） |
| 名前の下の札 | ユーザータグと属性。入り切らない分は数で出ます |
| 価格・対応 | 払った額と、対応アバターの数 |
| 星 | お気に入り。押すと切り替わります |
| 下の段の札 | 「所持」「未編集」「更新あり」「取り込み中」「見つからない」。入り切らないときは、右の札から色の丸になります（乗せると名前が出ます） |
| 左下の「未所持」の帯 | 手元にファイルが無い商品 |
| 名前の頭の「R-18」 | R-18 の商品。既定では R-18 の商品も一覧に出します。出したくないときは、設定の「R-18 の商品を表示する」を切ります（統計の金額には含めたままです） |

カードを押すと商品ページが開きます。名前の欄にマウスを乗せると、画像の上にタグ・属性などの中身が重なって出ます。

## リスト

一覧の右上の「リスト」で切り替えます。1行に1商品が並び、商品の情報が列にそろいます。

![リストの表示](images/list.png)

| 列 | 中身 |
|---|---|
| 左のチェック | 商品を選ぶ（カードの左上のチェックと同じ） |
| 画像 | マウスを乗せると大きく出ます |
| ★ | お気に入り |
| 名前・ユーザータグ・属性 | カードの名前の下と同じ中身 |
| 払った額・対応 | 払った額と、対応アバターの数 |
| ショップ | ショップ名 |

行を押すと商品ページが開きます。右クリックのメニューは、カードと同じです。

## 右クリックのメニュー

| 項目 | すること |
|---|---|
| BOOTHで開く・リンクをコピー | 商品ページをブラウザで開く・URL をコピーする |
| 商品ページを開く・ショップを開く・編集画面を開く | それぞれの画面へ移る |
| 選ぶ | 商品を選ぶ |
| 改変に追加… | 改変に足す（送らずに足すだけ） |
| 更新の通知を開く・既読にする | 通知の画面でその商品の知らせを開く・既読にする |
| 開く ▸ | エクスプローラで開く…・一時的に展開して開く… |
| Unity ▸ | Unityへ送る…・改変に追加して送る…・Unityで選択… |
| 非表示にする | 検索に出なくする。直後に画面の下の「非表示を解除」で戻せます |

できない操作は押せない形で出て、乗せると理由が出ます。

## 選んでまとめて操作する

カードの左上のチェックで商品を選ぶと、画面の下に操作が出ます。

| ボタン | すること |
|---|---|
| すべて選択・選択を解除 | 一覧の全部を選ぶ・選択をやめる |
| お気に入りに追加 | 選んだ商品をお気に入りにする |
| 改変に追加… | 選んだ商品を改変に足す |
| Unityへ順に送る… | 選んだ商品を1件ずつ Unity へ送る |
| まとめて編集する | 選んだ商品だけを編集の画面で順に開く |
| 既読にする | 選んだ商品の未読の更新を既読にする（未読があるときだけ出ます） |
