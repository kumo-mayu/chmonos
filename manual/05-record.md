# 整理して記録する

ここまでで、取り込んで、探して、Unity へインポートできるようになりました。この章の作業は、どれもしなくても Chmonos は使えます。
自分で付けた分類で探したいとき、気に入った物を印したいとき、どの改変に何を使ったかを残したいときに使ってください。

## ユーザータグと属性を付ける（編集）

左のナビの「編集」を開くと、まだ編集していない商品が1件ずつ出ます。右の欄に入力して「保存して次へ」を押すと、次の商品に進みます。

![編集の画面。左に商品の情報、右にユーザータグ・属性・購入したバリエーションの欄](images/edit.png)

**ユーザータグ**

自分で付ける分類です。「大分類 / 小分類」の2段で付けます（例：「衣装 / ワンピース」「季節 / 夏」）。

1. 「ユーザータグを追加」の欄に大分類（例：衣装）を入れて、Enter を押します
2. できた大分類の枠の「小分類を追加」に、小分類（例：ワンピース）を入れて、Enter を押します

入れ始めると、前に使った名前が候補に出ます。同じ名前を選ぶと、「かわいい」と「可愛い」のように分かれずに済みます。

**属性**

「かわいい 88%」のように、0〜100% の数で付ける評価です。「属性を追加」に名前を入れて足し、スライダーで値を決めます。
追加した属性だけが評価済みになります。追加していない物は「未評価」で、0% とは区別されます。

**購入したバリエーション**

商品のバリエーションのうち、買った物にチェックを入れます。払った額は BOOTH の価格が入るので、違うときだけ書き換えます。入れておくと、検索の価格の条件と統計で使えます。

**編集の画面の操作**

| ボタン | キー | すること |
|---|---|---|
| 保存して次へ | Ctrl+Enter | 右の欄を保存して、次の商品へ進む |
| スキップ | Ctrl+N | 保存せずに次の商品へ進む |
| ← 前へ | Ctrl+P | 前の商品に戻る |
| 終える | | 編集を終える |

左の欄（商品の情報）は、押した時点で保存されます。右の欄は「保存して次へ」で保存します。

1つの商品だけを編集したいときは、商品ページの右上の「編集」を押します。検索でカードを選んでから、画面の下の「まとめて編集する」で、選んだ商品だけを編集することもできます。

## お気に入り・メモ・非表示

- **お気に入り**：カードか商品ページの星を押します。検索の「＋ 条件を追加」の「お気に入り」で絞れます
- **メモ**：商品ページの「メモ」の欄に書きます。押さなくても保存されます。メモは検索欄で探せます
- **非表示**：カードを右クリックして「非表示にする」を選ぶと、検索に出なくなります。統計には含まれます。直後に画面の下に出る「非表示を解除」で戻せます。あとから戻すときは、設定の「隠したもの」で「非表示を解除」を押します

## 改変を記録する

改変は、「どのアバターに、どの商品を、どの順で入れたか」の記録です。写真・メモ・Unity のプロジェクトも一緒に残せます。左のナビの「改変」で見ます。

![改変の画面。左に改変の一覧、右に写真・アバター・Unityプロジェクト・使ったもの](images/modification.png)

**改変を作る**

1. 改変の画面の上の「アバター」を押して、アバターごとの見方にします
2. アバターの行の「改変を作る」を押し、名前を入れて「改変を作る」を押します

商品ページの「Unity ▾」の「改変に追加して送る」から、送るついでに新しい改変を作ることもできます。

**使ったものを足す**

- **送るついでに足す**：商品ページの「Unity ▾」→「改変に追加して送る」で送ると、選んだ改変に入ります。送った順に並ぶので、そのまま導入の順の記録になります
- **商品名で足す**：改変の画面の「使ったものを商品名で探して追加」に名前を入れて、「追加」を押します
- **カードから足す**：検索のカードを右クリックして、「改変に追加…」を選びます
- **Unity のプロジェクトから拾う**：改変に Unity のプロジェクトを紐付けて「読み直す」を押すと、そのプロジェクトに入っている手元の商品が候補に出ます。使った物なら「追加」を押します

**写真・メモ**

写真は、写真の欄の「＋」で選ぶか、ドラッグ＆ドロップか、Ctrl+V で貼り付けます。メモには、貫通の直し方など、次に作るときに要ることを書いておけます。

**記録を使う**

- **作り直す**：「使ったものを順にUnityへ送る」で、使ったものを入れた順に Unity へ送ります
- **VRChat で着替える**：「VRChatのblueprint ID」にアップロードしたアバターのID（avtr_…）を入れておくと、「VRChatで着替える」で VRChat をそのアバターに着替えさせられます。VRChat を起動して、OSC を有効にしておきます
- **似た改変を作る**：右上の「複製」で、使ったものとメモが同じ改変を作ります

## 記録できたかの確かめ

- ユーザータグ：検索の「＋ 条件を追加」の「ユーザータグ」で、付けた大分類が選べれば完了です
- 改変：改変の画面の一覧に、作った改変が出ていれば完了です

第1部はここまでです。各画面のボタンを詳しく知りたいときは、[目次](README.md) の第2部から開いてください。

## うまくいかないとき

| こうなった | 確かめること |
|---|---|
| 編集を開くと「編集するものがありません」と出る | まだ編集していない商品がありません。決まった商品を直すときは、商品ページの「編集」を使います |
| 「読み直す」で何も見つからない | 数えられるのは、zip の中に unitypackage がある商品だけです。見つからない物は、商品名で足します |
| 「VRChatで着替える」で着替わらない | VRChat が起動しているか、OSC が有効か、そのアバターを着られるかを確かめます |
| 「VRChatで着替える」が押せない | blueprint ID が空です。VRChat の SDK でアップロードしたアバターの ID（avtr_ で始まる）を入れます |
