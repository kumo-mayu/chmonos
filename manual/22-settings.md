# 設定

<!-- nav:top -->
[← 目次へ](README.md)　｜　[← 前の記事：タグと属性の管理](21-tags-attributes.md)
<!-- /nav:top -->

左のナビの一番下の「設定」で開きます。変えるとすぐに保存されます。

## 表示

| 項目 | 内容 |
|---|---|
| 表示の色 | 「Windows に合わせる」（既定）・「明るい」・「暗い」 |
| 表示の大きさ | アプリ全体の文字と絵をまとめて大きくする |
| 画面の幅・すべて元の幅に戻す | 一覧と詳細の境目などをドラッグして変えた幅を、元に戻す |
| R-18 の商品を表示する | 既定は入。切ると、R-18 の商品を一覧に出しません（統計の金額には含めます） |
| BOOTHから消えた画像も表示する | 入れると、BOOTH から消えた画像を「削除済」として並べます |

**一覧と検索**

| 項目 | 内容 |
|---|---|
| サムネイルに表示する画像 | カードに出す画像の決め方 |
| 一覧のカードに小分類のタグも表示 | カードのユーザータグを「大分類 / 小分類」で出す |
| 一覧のカードに属性の札を表示・カードに表示する属性 | カードに属性の値を出すか、どの属性を出すか |
| 非表示にしている件数を検索結果に表示 | 隠している商品の数を、件数の横に出す |
| 並べ替えたとき、まとまりごとに区切りを表示 | カテゴリ順・ショップ順・公開日順で、まとまりの最初に札を入れる（既定は入） |
| 入手日で並べたときも区切りを表示 | 入手日順でも月ごとの札を入れる（既定は切。上を切っていると、こちらも出ません） |
| 追加する条件を同じ種類の条件のすぐ下に置く | 絞り込みの条件を足す位置 |
| 検索の履歴に残す件数・履歴を削除 | 検索の履歴の数と、消去 |

**商品ページと編集**

| 項目 | 内容 |
|---|---|
| ギャラリーをマウスを乗せたまま切り替える | 小さな画像に乗せるだけで大きな画像を切り替える |
| 編集画面の上に、続く商品を小さな絵で並べる | 編集の画面の上の帯に、次の商品の画像を出す |

## 操作

| 項目 | 内容 |
|---|---|
| ショートカット | 欄を選んでキーを押すと割り当てられます。Backspace で割り当てを外し、「既定に戻す」で戻します（[キー操作の一覧](23-keys.md)） |
| 編集が終わったら検索に戻る | 編集の画面で全部終えたときに、検索の画面へ戻るか |
| プロジェクトの管理に使うアプリ | 改変の画面のボタンを、VCC と ALCOM のどちらで開くか |
| OSC の送信先のポート | 改変の画面の「VRChatで着替える」で送る先（1〜65535・既定は 9000） |

## 取り込みと取得

**取り込み**

| 項目 | 内容 |
|---|---|
| 起動したとき、監視フォルダの新しいファイルと前回の続きを取り込む | 入れると、起動したときに自動で取り込みます。切っていると、新しいファイルがあることを知らせるだけです |
| ファイルやフォルダをドロップしたら、そのまま取り込みを始める | 切ると、ドロップした物は取り込み対象に並び、「開始」を押すまで始まりません |
| 取り込み元の履歴・監視対象フォルダ | 取り込みの画面と同じ一覧。「外す」「フォルダを追加」 |

**取得と更新**

| 項目 | 内容 |
|---|---|
| 起動したとき、裏で取得を始める | 残りの画像・持っていないアバターの画像・期限の来た商品の情報を、起動したときに取得し始める |
| 商品情報を取り直す間隔 | BOOTH での更新や販売終了に気付くため、商品の情報を取り直す間隔（既定は7日。取得が同じ日に集まらないよう、少しずらします） |
| ショップのバナーを確かめ直す間隔 | ショップのバナーとアイコンを取り直す間隔 |
| 対応アバターを検出し直す間隔 | 対応アバターを見つけ直す間隔 |
| 取り込んだ商品の更新を既定で通知する | 新しく取り込んだ商品の「更新を通知する」の初めの値 |
| 通知に残す件数 | 通知の画面に残す数 |

**画像と通信**

変えると、これから取得する画像から反映されます。

| 項目 | 内容 |
|---|---|
| 画像を取って保存する | 切ると取り込みがかなり速くなり、一覧とギャラリーは文字だけになります |
| BOOTHへの問い合わせ間隔 | BOOTH へのリクエストの間隔（ミリ秒）。1,500 より短くはできません。広げるのは自由です |
| 保存する画像の長辺・画像の品質 | 商品の画像の大きさ（既定は長辺 384 ピクセル）と画質（WebP・40〜100。既定は 80） |
| 改変の写真の長辺・改変の写真を原寸で保存する | 改変の写真の大きさ（既定は長辺 768 ピクセル）。商品の画像とは別の設定です |

## 隠したもの

普段の画面には出さない物の一覧です。ここから元に戻せます。

| 一覧 | 戻し方 |
|---|---|
| 非表示にした商品 | 「解除」（「商品ページを開く」で商品も見られます） |
| 管理対象から除外したファイル | 「解除」。元の場所に同じファイルがあれば、未確定に戻ります |
| 商品から外したファイル | 「戻す」 |

## データ

| 項目 | 内容 |
|---|---|
| 保存先 | 今のデータの保存先。「エクスプローラで開く」「場所を変える」 |
| バックアップを書き出す…・バックアップから戻す… | 商品の記録・設定・改変などを1つの zip にする・戻す（[データの保存先・バックアップ・引っ越し・削除](30-data.md)） |
| 容量 | 画像と商品の情報が使っている量 |
| 見つからないファイル・記録をすべて削除… | 全部の商品から、見つからないファイル・フォルダの記録をまとめて消す |
| すべての設定を既定に戻す | 表示・操作・取り込みの動き・画像・通信の間隔の設定を、既定に戻す。取り込み元・監視対象・商品の記録は戻りません。元に戻せません |

保存しているデータは、すべて普通の JSON です。アプリを介さずに開いて読めます。

## Chmonos（クモノス）について

アプリのバージョン、表記をまたぐ検索に使っている辞書（JMdict・KANJIDIC2）、使っているライブラリとライセンスが出ます。「ライセンスを開く」でライセンスの文を開きます。
不具合を知らせるときは、ここのバージョンを添えてください。
