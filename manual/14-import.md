# 取り込みの画面

ファイルやフォルダを取り込む画面です。左のナビの「取り込み」で開きます。使い方の流れは [アセットを取り込む](02-import.md) にあります。

上から順に、次の欄が並びます。

## ドロップする枠

フォルダかファイルを、ここにドラッグ＆ドロップします。「フォルダを選択」でフォルダを選んでも取り込めます。
ファイルをドロップすると、そのファイルだけを取り込みます。

## 取り込み対象

これから取り込む物の一覧です。設定で「ドロップしたら、そのまま取り込みを始める」をオフにしているときは、ここに並んで、「開始」を押すまで始まりません。

| ボタン | すること |
|---|---|
| 開始 | 取り込みを始める。取り込みの最中は「今の取り込みに追加」になります |
| 中断 | 取り込みを止める。取得した分は残ります |
| 足りない情報を取得 | 取得しきれなかった画像と、期限の来た商品の情報を取得する |
| 続きから進む | 前回、途中で止まった取り込みの続きを進める |
| 続きを捨てる | 前回の続きの記録を捨てる。取り込めた商品とファイルは残ります。元に戻せません |
| 外す | 行を取り込み対象から外す。フォルダとファイルはそのまま残ります |
| エクスプローラで開く | 行の場所を開く |

**進み具合**

![取り込み中の進み具合](images/import-progress.png)

取り込みの最中は、段の名前・件数・棒と、残りの時間の見込みが出ます。

| 見込み | 意味 |
|---|---|
| この段の残り | 今の段が終わるまで |
| 編集できるまで | 商品名・ショップ・説明がそろうまで |
| 画像を取り終わるまで | 全部の画像を取得し終わるまで |

BOOTH から間隔を広げるよう指示があったときは、「取得間隔を n 秒に広げています」と出ます。

## 監視対象

起動したときに、新しいファイルが増えていないかを調べるフォルダです。フォルダを上の枠にドロップすると、監視するかを聞かれます。

- 新しいファイルが見つかると、知らせます。設定の「起動したとき、監視フォルダの新しいファイルと前回の続きを取り込む」を入れると、自動で取り込みます
- 「外す」で監視をやめます。取り込んだ記録はそのままです
- 「知らせなくてよい」を押すと、今あるファイルはこれ以上知らせません。新しいファイルは知らせます

BOOTH で買ったアセットを置いているフォルダを入れてください。Windows の「ダウンロード」フォルダのように、ほかのファイルも入るフォルダを入れると、未確定に大量に並びます。

**見つからないファイルを探す…**

移動したり名前を変えたりして、記録の場所に見つからなくなったファイルを探して、紐付け直します。押すと、探すフォルダを選ぶウィンドウが開きます（監視対象のフォルダが初めから入っています）。ファイルは動かしません。

結果は「見つからないファイルを探した結果」に、紐付け直したファイルと、見つからなかったファイルに分けて出ます。登録したフォルダを移したときは、候補のフォルダが並ぶので、「この場所にする」で場所を変えます。

## 取り込み元の履歴

これまでに取り込んだフォルダとファイルです。並んでいるだけでは取り込みません。

- 「対象に追加」で、今回の取り込み対象に入れます
- 「消す」で、履歴から消します。フォルダとファイルはそのまま残ります

## 使っていない間の取得

取り込みで取得できなかった画像や、持っていないアバターの1枚目の画像を、BOOTH から少しずつ取得している間に出ます。取り込みを始めると、取り込みの方が先に進みます。

## 結果

取り込みが終わると出ます。

| 項目 | 意味 |
|---|---|
| スキャンしたファイル | 見たファイルの数 |
| 中身を確かめた・確かめを省いた | 中身を読んだ数と、前と変わっていないので読まなかった数 |
| 展開先として除外 | zip を展開してできたフォルダとして、取り込まなかった数 |
| 新規に取得・取得済みだった | 新しく BOOTH から取得した商品と、もう持っていた商品の数 |
| 未確定 | 商品が決まらなかった数 |
| 取得した画像 | 取得した画像の枚数 |

| ボタン | すること |
|---|---|
| 未確定を開く | 未確定の画面へ |
| 取り込んだ商品を検索で開く | 取り込み日の新しい順で、検索の画面を開く（ほかの条件は外します） |
| 壊れたzipがある商品を検索で開く | 壊れた zip がある商品だけを、検索の画面で出す |

**展開先とみなしたフォルダ**

zip を展開してできたフォルダは、取り込まずに一覧にします。zip を残すなら、選んで「ごみ箱へ移動」で消して、ディスクの空きを戻せます。消すのは、元の zip と中身が同じフォルダだけです。
