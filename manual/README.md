# Chmonos（クモノス）マニュアル

Chmonos は、BOOTH で買ったアセット（VRChat 向けのアバター・衣装など）を、今のフォルダの並びのまま管理する Windows のアプリです。
このマニュアルは、公開している最新のバージョン（v1.1.0）に、開発中の次のバージョンの内容を足したものです。まだ公開していない動きには「（次のバージョンから）」と書いています。

お使いのバージョンのマニュアルは、次から開けます。

| バージョン | マニュアル |
|---|---|
| v1.1.0 | https://github.com/kumo-mayu/chmonos/tree/manual-v1.1.0/manual |
| v1.0.0 | https://github.com/kumo-mayu/chmonos/tree/v1.0.0/manual |

> 非公式のアプリケーションです。ピクシブ株式会社（BOOTH・pixiv の運営）が作成・配布しているものではありません。
> 「BOOTH」「pixiv」はピクシブ株式会社の登録商標です。

第2部と第3部は、使っていて分からない所が出たときに開く参照用です。

## このマニュアルで解決しないとき

BOOTH ショップのメッセージか、X（[@kumo_mayu79](https://x.com/kumo_mayu79)）の DM でお問い合わせください。
不具合を知らせていただくときは、設定の「このアプリについて」のバージョンと、データの保存先にある `logs\app.log` を添えてもらえると助かります。

## 画面の画像について

画面の画像に写っている商品名・ショップ名・画像は、説明のために作った架空のものです。画像は CC0 の写真を使っています。
