NullPriceFix（購入記録の額の空欄を 0円にそろえる道具）
=====================================================

前の版の Chmonos では、編集画面の「購入したバリエーション」の値段の欄を空欄にすると、
「値段が分からない」として記録していました。今の版（v1.0.0）は、空欄を 0円として記録します。

そのため、前の版で 0円のつもりで空欄にした記録は、今の版では「値段の分からない記録」に見えます。
統計の「払った額の記録が無い商品」に数えられ、検索の「価格」の条件からも外れます。
この道具は、その空欄を 0円に書き換えます。一度だけ使えば十分です。


■ 使い方

  1. Chmonos を閉じます
     （開いていると、この道具は止まります。道具が動いている間は、Chmonos も開きません）

  2. 「1_数えるだけ.bat」をダブルクリックします
     何も書き換えずに、空欄の記録の件数を数えて表示します。
     いちばん上に出る「保存先」が、いつも Chmonos で使っている場所かを確かめてください。

  3. 件数が 1 件以上なら、「2_書き換える.bat」をダブルクリックします
     件数を出して「よろしいですか？ [y/N]」と聞くので、y を入力して Enter を押します。
     y 以外を入力すると、何も書き換えずに終わります。

  どちらも、最後に「続行するには何かキーを押してください」と出たら、キーを押すと閉じます。

  4. Chmonos を開いて、いつも通り使います


■ 何が変わるか

  ・商品の記録（保存先の items フォルダの .json）のうち、値段が空欄の購入記録にだけ、0円を入れます
    ほかの所は変えません
  ・書き換える前の記録を、保存先の中の「backup-null-price-日時」フォルダに写してから書き換えます
  ・何度動かしても同じです（2回目からは「書き換える物はありません」と出ます）
  ・壊れて読めない記録には触りません


■ 元に戻すとき

  Chmonos を閉じて、「backup-null-price-日時」フォルダの中の .json を、
  保存先の items フォルダへ上書きでコピーしてください。


■ Windows の警告が出たとき

  NullPriceFix.exe には電子署名をしていないため、Windows の警告が出ることがあります。

  ・「Windows によって PC が保護されました」と出たときは、「詳細情報」を押すと「実行」のボタンが出ます
  ・「スマート アプリ コントロール」にブロックされたときは、警告の画面から動かす方法がありません。
    この道具を使わなくても Chmonos は動きます。空欄の記録は、編集画面で値段に 0 を入れて直すこともできます


■ 困ったとき

  ・「この場所に商品の記録（items フォルダ）がありません」と出た
      いつもと違う保存先を見ています。Chmonos の設定の「データ」で保存先の場所を確かめ、
      コマンドプロンプトで次のように場所を指定して動かしてください。
        NullPriceFix.exe --store "保存先の場所"
  ・「Chmonos が開いています」と出た
      Chmonos を閉じてから、もう一度動かしてください。

  分からないことがあれば、作者に連絡してください。
