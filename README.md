# Chmonos（クモノス）

BOOTH で買ったアセット（VRChat 向けの衣装・アバターなど）を、今のフォルダの並びのまま管理する Windows のアプリです。

ダウンロードした zip やフォルダなどをアプリのウィンドウにドラッグ＆ドロップすると、どの商品かを特定して記録します。
多くは自動で決まり、決まらない物も候補から選ぶだけです。商品IDを手で打ち込むのは、候補が見つからなかったときだけです。
BOOTH のアカウント情報は入力しません。

> **非公式のアプリケーションです。**pixiv プラットフォーム（BOOTH）を利用して個人が開発したもので、pixiv が作成、配布しているアプリケーションではありません。
> 「BOOTH」「pixiv」はピクシブ株式会社（pixiv Inc.）の登録商標です。

![検索の画面。取り込んだ商品がカードで並び、左に絞り込みの条件がある](manual/images/search.png)

画面の画像に写っている商品名・ショップ名・画像は、説明のために作った架空のものです。

## できること

- zip やフォルダなどをドラッグ＆ドロップすると、商品名・ショップ・画像・説明を BOOTH から取得して記録します。ファイルは移動しません
- 文字で探せます。商品名・ショップ名・メモのほか、検索欄の右の「対象」で説明文やファイルの場所も探せます。
  「オプション」の「別表記でも検索」を入れると、「スカート」で「skirt」、「shark」で「サメ」が見つかるように、かな・漢字・英語をまたいで検索できます
- 「絞り込み」で、条件を組み合わせて商品を絞れます。所持・対応アバター・ユーザータグ・属性・カテゴリ・ショップ・価格・入手日・公開日・改変・ファイルの状態など、たくさんの条件から選んで足していきます。
  同じ種類の条件を重ねたり、当てはまる物を除外したりもでき、組み合わせた条件は名前を付けて保存できます
- 商品の説明やタグから、どのアバターに対応しているかを読み取って入れます。確かでない物だけ「確認待ち」として出るので、合っているかを選びます。自分で足したり外したりもできます
- 改変の記録として、どのアバターにどの衣装をどの順で導入したかを、写真やメモと一緒に保存できます
- 開いている Unity のエディタへ、zip の中の unitypackage をそのままインポートできます（「Unityへ送る」）。zip を自分で展開する必要はありません。
  インポートした商品のフォルダを、Unity の Project ウィンドウで開くこともできます（「Unityで選択」）
- 持っている商品が BOOTH で更新されたり販売終了になったりすると、「通知」に出ます

## はじめかた

1. [GitHub の Releases](https://github.com/kumo-mayu/chmonos/releases)（[BOOTH](https://kumo-mayu.booth.pm/items/8952335) でも配っています）から `Chmonos-v1.0.0.zip` をダウンロードします
2. zip を右クリックして「すべて展開」を選びます。
   **zip の中から直接開かないでください。**一緒に入っている `assets` フォルダ（辞書など）が使われないことがあります
3. 展開したフォルダの `Chmonos.exe` を開きます。インストールは要りません
4. 初回起動時の画面で、データの保存先と、画像を保存するかを選びます。どちらも後から設定で変えられます
5. 管理したい zip やフォルダなどを、アプリのウィンドウにドラッグ＆ドロップします

商品を特定できなかったファイルは「未確定」に並びます。「自動検索」を押すと BOOTH で候補を検索して表示するので、合っている物を選んで「このIDで登録」を押します。商品IDや商品ページの URL を自分で入れても登録できます。

どの商品も、必要なら「編集」でユーザータグなどを入れられます。入れなくても、検索や Unity へのインポートはそのまま使えます。

### Windows の警告が出たとき

`Chmonos.exe` にはコード署名をしていません。そのため、初めて起動するときに Windows の警告が出ることがあります。

- 「Windows によって PC が保護されました」（SmartScreen）と出たときは、「詳細情報」を押すと「実行」のボタンが出ます
- 「スマート アプリ コントロール」にブロックされたときは、警告の画面から起動する方法がありません。起動するには、「Windows セキュリティ」→「アプリとブラウザー コントロール」→「スマート アプリ コントロールの設定」で、スマート アプリ コントロールをオフにします
  - オフにすると、ほかのアプリにもこの保護が働かなくなります。オフにするかはご自身で判断してください
  - 2026年4月の更新（KB5083769）より前の Windows 11 では、一度オフにすると、Windows を再インストールしないとオンに戻せません

## 取り込みに時間がかかる理由

このアプリは、BOOTH へのリクエストを1件ずつ、1.5秒以上の間隔を空けて送ります。BOOTH を運営するピクシブ株式会社のサーバーに負担をかけないためです。

そのため、たくさんの商品を一度に取り込むと時間がかかります。100商品あたり、少なくとも次の時間がかかります（1商品あたりの画像の枚数は、15商品で実測した平均です）。

| そろう物 | 100商品あたりの時間 |
|---|---|
| 商品名・ショップ・説明（ここで探したり編集したりできるようになります） | 約5分以上 |
| 画像（全部） | 約30分以上 |

商品名と説明を先にすべて取得し、画像はそのあとで取得します。取り込みの途中でも、届いた商品から探せます。

途中でアプリを閉じても、取得済みの分は保存されています。次回の起動時に、画像の残りは自動で取得し、商品の情報の残りは画面の下の「続きから進む」で続けられます。

## 通信とアカウント

- BOOTH にはログインしません。アカウント情報やパスワードを入力する画面はありません
- アクセスするのは、ログインせずに閲覧できる商品の情報（商品ページと、その内容の JSON）・ショップのページ・画像です。
  商品の JSON は、BOOTH が公式に文書化している API ではありません。BOOTH の仕様が変わると、情報を取得できなくなる場合があります
- 未確定の画面で「自動検索」を押したときは、ファイル名から作った検索語を BOOTH の検索に送信します
- BOOTH 以外に通信するのは、商品ページの動画の欄を開いたときの YouTube（動画のタイトルとサムネイルの取得）と、新しい版の確認の GitHub（1日1回まで。設定の「新しい版を確かめる」で止められます）だけです
- 起動中は、一定期間確認していない商品の情報をバックグラウンドで再取得します（既定はおよそ1週間ごと）。BOOTH での更新や販売終了を検知するためです
- 取得した説明や画像は、お使いの PC の保存先に置くだけで、外部へは送信しません

## 商品が自動で特定できないとき

アプリは、ダウンロード時にブラウザがファイルに記録するダウンロード元の情報（Zone.Identifier）と、zip 内の文書にある商品の URL を手掛かりにします。

- Chrome・Edge は、商品を特定できる形でダウンロード元を記録します（確認済み）
- Firefox や、Chromium ベースのブラウザ（Vivaldi・Opera など）もダウンロード元を記録しますが、商品を特定できる形かはまだ確認していません

次の場合は、ダウンロード元の情報が残らないか、商品を特定できない形になります。その場合は、ファイル名で BOOTH を検索して候補を表示します。

- Brave でダウンロードした（Brave はダウンロード元の URL を記録しません）
- シークレットウィンドウ・InPrivate・プライベートウィンドウでダウンロードした
- 7-Zip などで展開した中身だけを取り込んだ（展開ソフトの設定によっては情報が失われます）
- USB メモリなどにコピーしたファイル（FAT32・exFAT ではこの情報が保持されません）

最も確実なのは、Chrome か Edge の通常のウィンドウでダウンロードし、zip のまま取り込むことです。

## データの保存先と削除

- データの保存先は、既定で `%LOCALAPPDATA%\Chmonos` です（エクスプローラーのアドレスバーに貼り付けると開けます）
- 保存先は、初回起動時の画面で任意の場所を選べます。あとからは、設定の「データ」の「場所を変える」で変更できます。
  変更するときは、データを新しい場所へ移す（「引っ越す」）か、参照先だけを変えるかを選べます。参照先だけを変えると、今のデータは元の場所に残ります。空のフォルダを選んだ場合は、空のライブラリから始まります
- 設定の「バックアップを書き出す…」で、商品の記録・設定・改変などを1つの zip に保存できます。zip やフォルダなど、お手持ちのファイルそのものは含まれません
- インストーラーが無いため、`Chmonos.exe` を削除してもデータは残ります。すべて削除するときは、保存先のフォルダも削除してください

## 使い方のこつ

画面ごとの詳しい使い方は、[マニュアル](manual/README.md) にあります。

### ファイルの置き方

- フォルダをドラッグ＆ドロップしたときに取り込むのは、BOOTH で配られる形式（zip・rar・画像・PSD・PDF・音声・動画・VRM・VRoid など）と、unitypackage・7z・blend・fbx です。それ以外のファイルも、商品ページの「追加…」から商品に追加できます
- zip のまま持っておくのがおすすめです。zip と同じ場所にある、zip を展開してできたフォルダは、zip と同じ商品として扱います
- zip などのファイルは内容（ハッシュ）で識別するので、移動や名前の変更をしても記録はそのまま使えます。
  フォルダとして登録した物はパスで識別するので、移動すると「見つかりません」になります。取り込みの画面の「見つからないファイルを探す…」で紐付け直せます
- 外付けドライブを取り外している間も、記録は削除されません。接続し直せば元に戻ります
- OneDrive などの「オンラインのみ」のファイルは読み込みません（読み込むとダウンロードが始まるためです）。取り込みたいときは、そのフォルダを「常にこのデバイスに保持する」にしてから取り込み直してください
- ダウンロード中のファイルや、ほかのアプリが開いているファイルは取り込めません。取り込みが終わると、取り込めなかった件数と考えられる原因が結果に表示されるので、原因を解消してから取り込み直してください
- 1つのフォルダ（zip を展開したフォルダなど）に複数の商品のファイルが入っているときは、未確定の画面の「このファイルだけ」で分けて登録できます

### 探す

- 検索画面の左の「絞り込み」で「＋ 条件を追加」を押し、条件を足していきます。条件ごとに、有効・無効を切り替えたり、「除く」にしたりできます
- 条件の組み合わせ方は次のとおりです。画面では「除く」などの言葉で表していますが、中身は AND・OR・NOT の組み合わせです
  - 別々の条件どうしは AND（すべてを満たす商品）でつながります
  - 1つの条件に複数の値（タグやアバターなど）を積んだときは、既定は OR（どれかを満たす商品）です。対応アバター・ユーザータグなどは「すべてを満たす商品のみ（AND）」に切り替えられます。カテゴリ・BOOTH タグ・ショップは OR だけです
  - 同じ種類の条件は複数置けます。カテゴリやタグを2つ置けば「(A または B) かつ (C または D)」が組めます
  - 価格・スキ数・公開日・入手日のような範囲の条件を同じ種類で複数置くと、OR（どれかの範囲に入る商品）でつながります。ほかの種類の条件との間は AND のままです
  - 「除く」はその条件の NOT です（当てはまる商品を結果から外します）。範囲の条件で「除く」を付けた物は、除かない範囲の和から差し引きます
  - ショップ・属性・「最近」と、選択肢から1つを選ぶ条件（所持・お気に入りなど）は、1つしか置けません
- スペースで区切ると、すべての語を含む商品を探します。`-語` でその語を含む物を除き、`"…"` でフレーズ（語順どおりの一致）を探します。`OR`（大文字）でどちらか一方です
- `name:語`（商品名）・`shop:語`（ショップ名）・`tag:語`（BOOTH のタグ）のように、検索する項目を指定することもできます
- 追加した条件は、次回の起動時にも残ります。よく使う条件は「保存した条件」で名前を付けて保存できます

### 記録する

- 購入記録（払った額・買った日・自分用／贈った／貰った）は手動で入力します。額を空欄にすると0円として記録されます。入力しておくと、統計や「払った額」の並べ替えに使えます
- 対応アバターは、商品の説明やタグから自動で入ります。確かでない物だけ「確認待ち」として出るので、合っているかを選んでください。分からない物は「非対応」ではなく「未確認」と出ます
- カテゴリが「3Dキャラクター」になっていないアバターは、商品ページの「アバターとして登録」でアバターとして扱えます
- 商品ページには、自分で撮った画像をドラッグ＆ドロップや貼り付けで追加できます。削除できるのは自分で追加した画像だけです
- 作者が BOOTH の商品ページから外した画像は、手元に残っていても既定では表示しません。設定の「BOOTHから消えた画像も表示する」で表示できます
- 改変を複製すると、写真と VRChat のアバターIDは引き継ぎません

### Unity と VRChat

- Unity へ送る前に、送り先の Unity のエディタを開いておいてください。送ると、Unity の Import Unity Package ウィンドウが開きます
- 確かめている Unity は 2022.3 です
- 改変の「VRChatで着替える」は、VRChat の OSC を有効にしてから使います。アバターの変更を送信するだけで、着替えが完了したかの確認はしていません

### 外す・除外する・削除する

- 「この商品から外す」は、そのファイルをその商品の物ではないとする操作です。ファイルの行は灰色で残ります
- 「管理対象から除外」は、そのファイルをアプリで扱わないようにする操作です。設定の「隠したもの」から戻せます
- 取り込みの画面の「展開先とみなしたフォルダ」で「ごみ箱へ移動」を押すと、zip を展開しただけのフォルダをごみ箱へ移します。
  商品に登録したフォルダや、zip に無いファイルが入ったフォルダは移しません

### キー操作

既定の割り当てです。Ctrl・Alt を使う割り当ては、設定の「操作」で変更できます。

| キー | 操作 |
|---|---|
| Ctrl+F | 画面内を検索（Enter・Shift+Enter で次・前へ、Esc で閉じる） |
| Ctrl+Enter | 編集の「保存して次へ」、未確定の「このIDで登録」 |
| Ctrl+N | 編集で、次の商品へスキップ |
| Ctrl+P | 編集で、前の商品へ戻る |
| Alt+← ／ マウスの戻るボタン | 前の画面へ戻る |
| Alt+→ | 戻った画面から進む |
| Ctrl+プラス ／ Ctrl+マイナス ／ Ctrl+0 | 表示を拡大 ／ 縮小 ／ 100% に戻す |
| Shift+F10 | 右クリックメニューを開く |
| ← → | 商品ページで画像を切り替える |
| Shift+ホイール | 横にスクロール |

### 困ったとき

- 同じ保存先を使うアプリは、同時に2つ起動できません
- 不具合を知らせていただくときは、設定の「このアプリについて」のバージョンと、データの置き場の `logs\app.log` を添えてもらえると助かります
