# Chmonos（クモノス）

BOOTH で買ったアセット（VRChat 向けの衣装・アバターなど）を、今のフォルダの並びのまま整理する Windows のアプリです。

ダウンロードした zip やフォルダをアプリの窓へ落とすと、どの商品かを調べて記録します。
多くは自動で決まり、決まらない物も候補から選ぶだけです。商品IDを手で打ち込むのは、候補が見つからなかったときだけです。
BOOTH のアカウント情報は入力しません。

> **非公式のアプリです。**個人が作ったもので、ピクシブ株式会社（BOOTH・pixiv の運営）が作成・配布しているものではありません。
> 「BOOTH」「pixiv」はピクシブ株式会社の登録商標です。

## できること

- zip・フォルダ・unitypackage を落とすと、商品名・ショップ・画像・説明を BOOTH から取ってきて記録します。ファイルは動かしません
- 商品名・ショップ名・メモから探せます。説明文やファイルの場所も、検索欄の右の「対象」で入れると探せます。
  「オプション」の「別表記でも検索」を入れると、「ゆびわ」で「指輪」、「shark」で「サメ」が見つかるように、かな・漢字・英語をまたいで引けます。
  対応アバター・ユーザータグ・価格・入手日などの条件でも絞り込めます
- どのアバターに対応しているかの候補を、商品の説明から読み取って出します。入れるかどうかは自分で選びます
- 改変の記録として、どのアバターにどの衣装をどの順で入れたかを、写真やメモと一緒に残せます
- 開いている Unity のエディタへ、zip の中の unitypackage を送れます。zip を自分で展開する必要はありません
- 持っている商品が BOOTH で更新されたり販売終了になったりすると、「通知」に出ます

## はじめかた

1. [GitHub の Releases](https://github.com/kumo-mayu/chmonos/releases)（BOOTH でも配っています。【未定：BOOTH の URL】）から `Chmonos-v1.0.0.zip` をダウンロードします
2. zip を右クリックして「すべて展開」を選びます。
   **zip の中から直接開かないでください。**一緒に入っている `assets` フォルダ（辞書など）が使われないことがあります
3. 展開したフォルダの `Chmonos.exe` を開きます。インストールは要りません
4. はじめの窓で、データの保存先と、画像を保存するかを選びます。どちらも後から設定で変えられます
5. 整理したい zip やフォルダを、アプリの窓へ落とします

商品が決まらなかったファイルは「未確定」に並びます。「自動検索」で候補が出るので、合っている物を選んで「このIDで登録」を押します。
最後に「確定したものを編集する」で、ユーザータグなどを入れていきます。

## 取り込みに時間がかかる理由

このアプリは、BOOTH へ1回ずつ、1.5秒以上の間を空けて問い合わせます。BOOTH を運営するピクシブ株式会社のサーバーに負担をかけないためです。

そのため、たくさんの商品を一度に取り込むと時間がかかります。100商品あたり、少なくとも次の時間がかかります（画像の枚数は15商品で測った値です）。

| 何がそろうまで | 100商品あたり |
|---|---|
| 商品名・ショップ・説明（ここまでで探したり編集したりできます） | 約5分以上 |
| 画像まで全部 | 約30分以上 |

アプリは、先に全部の商品の名前と説明を取り、画像はそのあとで取りに行きます。商品名は届いた物から探せて、取り込みの途中でもアプリは使えます。
画像を保存しない設定にすると、全部終わるまでの時間は短くなりますが、使い始められるまでの時間は変わりません。

途中でアプリを閉じても大丈夫です。取れた分は1商品ずつ保存されています。次に起動すると、残りの画像は裏で自動で取りに行きます。商品の情報の残りは、画面の下に出る「続きから進む」を押すと続きから取り込めます（設定の「起動したとき、監視フォルダの新しいファイルと前回の続きを取り込む」を入れておくと、自動で続けます）。

## 通信とアカウント

- BOOTH にはログインしません。アカウント情報やパスワードを入力する所はありません
- 問い合わせるのは、BOOTH の公開されている商品ページ・ショップのページ・画像です
- 未確定の画面で「自動検索」を押したときは、ファイル名から作った語を BOOTH の検索に送ります
- BOOTH のほかに通信するのは、商品ページの動画の欄を開いたときの YouTube（動画の題と絵を取るため）だけです
- 起動しているあいだ、しばらく確かめていない商品の情報を裏で取り直します（既定はおよそ1週間ごと）。BOOTH での更新や販売終了に気づくためです
- 取ってきた説明や画像は、あなたのパソコンの保存先に置くだけで、ほかの所へは送りません

## 商品が自動で決まらないとき

アプリは、ダウンロードしたときにブラウザがファイルに残す「どこから落としたか」の記録と、zip の中の文書にある商品の URL を手掛かりにします。

- Chrome・Edge は、商品が分かる形で記録を残します（確かめています）
- Firefox や、Chrome と同じ作りのブラウザ（Vivaldi・Opera など）も記録を残しますが、商品が分かる形かはまだ確かめていません

次のときは記録が残らないか、商品が分からない形になります。その場合は、ファイル名から BOOTH を検索して候補を出します。

- Brave でダウンロードした（Brave はこの記録に商品の場所を書きません）
- シークレットウィンドウ・InPrivate・プライベートウィンドウでダウンロードした
- 7-Zip などで展開した中身だけを取り込んだ（展開ソフトの設定によっては記録が消えます）
- USB メモリなどへ写したファイル

いちばん確実なのは、Chrome か Edge のふつうの窓でダウンロードして、zip のまま取り込むことです。

## データの置き場と消し方

- データの置き場は、既定で `%LOCALAPPDATA%\Chmonos` です（エクスプローラのアドレス欄に貼ると開けます）
- C ドライブの空きが少ないときは、はじめの窓で別の場所を選べます。後からは、設定の「データ」の「場所を変える」で移せます
- 設定の「バックアップを書き出す…」で、商品の記録・設定・改変などを1つの zip に残せます。zip やフォルダなど、あなたのファイルそのものは入りません
- インストーラが無いので、`Chmonos.exe` を消してもデータは残ります。すべて消すときは、データの置き場のフォルダも消してください

## 作った理由

今までのフォルダでの管理を崩さずに、登録が簡単で、やりたいことが1つのソフトでできる、自分好みのソフトが見つからなかったからです。

また、登録の手間は減らしたい一方で、BOOTH には外のアプリ向けの公式のログインの仕組みが無いので、アカウント情報は扱いたくありませんでした。
