# コメントの例

決まり（コメントは「なぜ」を日本語で書く・数字には根拠も書く）は CLAUDE.md。ここはその例。

何をしているかはコードが語る。書くのは判断の理由。

```csharp
// 悪い例：ハッシュを計算する
// 良い例：フォルダに内容ハッシュを与えると、中の1ファイルを触っただけで
//         別物になり、また未確定として湧いてしまう。831MBを毎回ハッシュする
//         代償も見合わない。同一性はパスで見る
```

数字を書くときは根拠も書く。「30日にした」ではなく
「確かめる間隔が復活期間より長いと原理的に取り逃す。季節ものは1ヶ月ほどしか公開されない」。
