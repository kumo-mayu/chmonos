# 覚えておくと早いこと

コードと spec を触るときの前提。詳しくは各話題の `docs/spec/`。

| | |
|---|---|
| 梯子（取り込みの順序） | ① JSON → ② HTML → ③ 検出 → ④ 1枚目 → ⑤ 残り → ⑥ アイコン → ⑦ 期限 |
| 所持の定義 | ファイルかフォルダを1つ以上持つこと |
| 意味検索はしない | 埋め込みは説明できない。辞書は引いた結果を説明できる |
