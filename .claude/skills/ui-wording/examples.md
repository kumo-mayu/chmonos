# 良い例と悪い例

悪い例は 2026-09-24 の点検の前にあった画面の文。良い例は、決まりに沿った文（「案」の多くは第3段で画面に入った）。
例は型を示すためのもので、そのまま写さない。使うときは、その場の文脈と `SKILL.md` の手順3（正確さ）で確かめる。

## ボタン・メニュー

押すと何が起きるかが分かる句で書く。語は `ui-terms.md`。

| 悪い例 | 良い例 | 直した所 |
|---|---|---|
| 対象に積む（取り込み画面） | 取り込みの対象に追加（案） | 積む → 追加。何の対象かを書く |
| 画像を足す…（商品ページ） | 画像を追加…（案） | 足す → 追加 |
| 今すぐ取り直す | 商品情報を取り直す（今の文） | 何を取り直すかを書く |

## 見出し

名詞で短く。作り手の言葉（手掛かり・積み残し）を使わない。

| 悪い例 | 良い例 |
|---|---|
| 取り込み時の手掛かり（未確定） | 取り込み時に読み取った情報（案） |
| 表示中を全て選択 | すべて選択（案。`ui-terms.md` の動詞の表） |

## 吹き出し（ツールチップ）

ボタンの名前で足りない1点だけ。1〜2文・40字まで。

| 悪い例 | 良い例 | 直した所 |
|---|---|---|
| このフォルダを取り込みの対象に積んで、取り込みを始めます。新しいファイルを探して商品を決めます。画面はこのままで、進み具合は下の帯に出ます（取り込み画面へはそこから移れます）。（フォルダ・84字） | このフォルダを取り込みます。進み具合は下の帯に表示されます。（案・29字） | 仕組みの説明と括弧の補足を削った。何が起きるかと、どこを見ればよいかだけ残した |
| 打った文字と条件の値を戻します（足した条件は残ります）。押す前の条件は検索の履歴に積むので、履歴から戻せます。（検索） | 入力と条件の値をクリアします。前の条件は検索の履歴から戻せます。（案） | 何が起きるかと取り返しの2つにした。積む・足すを使わない |
| 切っているときは、取り込み画面に件数を出して、押してから始めます。起動しただけでBOOTHへの通信が始まるのを避けたいときは切ってください。次に起動したときから効きます。（設定） | オフにすると、取り込み画面で押すまで始まりません。（案） | 何が起きるかの1つにした。「〜を避けたいとき」は使う人が判断することなので削った |
| クリックすると仮のIDを写します（商品ページ） | 仮のIDをコピーします（案） | 写す → コピー。「クリックすると」はボタンなら言わなくて分かる |
| 空欄は未入力（支出に数えない）、0は無料配布です。同じバリエーションを2回買った（自分用に1つ、ギフトに1つなど）ときは［＋］で記録を足します。（編集） | 空欄は未入力、0 は無料です。2回買ったときは［＋］で追加します。（案） | 括弧の補足を3つとも削った。支出に数えないかどうかは、統計の画面の側で書く |

## 窓（確認）の本文

1行目に何が起きるか、2行目に取り返しがつくか。理由と経緯は書かない。

| 悪い例 | 良い例 |
|---|---|
| 捨てた記録は戻せません。続きを取りたくなったら、同じフォルダを取り込み対象に積み直して始めてください。（取り込み） | 記録は元に戻せません。続きは、同じフォルダをもう一度取り込むと始められます。（案） |
| Unity 側で「Cancel」を押してください（「Import」を押すと入りますが、こちらの記録には残りません）。（Unity への送信） | Unity で「Cancel」を押してください。「Import」を押すと、このアプリの記録には残りません。（案） |

## 空表示

次に何をすればよいかを1文で。

| 悪い例 | 良い例 |
|---|---|
| この改変の写真はまだありません。「＋」でまとめて選ぶか、ここへ落とすか、Ctrl+V で貼ってください。（改変） | この改変の写真はまだありません。「＋」かドロップで追加できます。（案） |
| まだどのitemも評価していません（2026-09-09 まで） | この属性を持つ商品はまだありません。編集画面で値を入れると、ここに並びます。（今の文） |

## エラー

事象・原因・対処の順。削るときは原因から削り、次に対処を削る。事象は最後まで残す。

| 悪い例 | 良い例 |
|---|---|
| 思いがけない失敗です。（失敗の文の既定） | 予期しないエラーが発生しました。（案） |
| 落としたファイルやフォルダが見つからず、取り込みを始めませんでした。動かしたか、ドライブがつながっていない可能性があります。場所を確かめて、もう一度落としてください。（取り込み） | 取り込みを始められませんでした。ドロップしたファイルが見つかりません。場所を確かめて、もう一度ドロップしてください。（案） |
| 同じ名前が2つあると、その名前を使う画面が開けません。…どちらも**直し方はこちらで決められない**ので、JSONを開いて片方を消すか、名前を分けてください。（要確認） | 同じ名前が2つあります。JSON を開いて、片方を削除するか名前を変えてください。（案。Markdown の `**` を残さない） |
| 1500ミリ秒より短くはできません（相手のサービスに負担をかけないため）（設定） | 1500 ミリ秒以上で入れてください。（案。理由は docs と CLAUDE.md にある） |
| （良い例） | ディスクの空きが足りません。空きを作ってからもう一度お試しください。（今の文） |

## 進み具合

「〜しています…」と n/N。

| 悪い例 | 良い例 |
|---|---|
| 応答がないので待っています（{s} 秒後に再試行 {n}/{max}） | 応答を待っています。{s} 秒後にもう一度試します（{n}/{max}）（案。数だけの括弧はよい） |
| （良い例） | 読み込んでいます…（今の文） |

## 知らせ（済んだこと）

「〜しました。」の1文。

| 悪い例 | 良い例 |
|---|---|
| {Item.Id} を写しました。 | {Item.Id} をコピーしました。（案） |
| 手元のデータはそのままです。説明文の見出しから読み取る所（対応アバターの検出・検索の手掛かり）だけが痩せます。（主画面） | 手元のデータはそのままです。対応アバターの検出と検索に使う情報が少なくなります。（案） |
| （良い例） | 「{name}」の配布商品との紐付けを外しました。（今の文） |
